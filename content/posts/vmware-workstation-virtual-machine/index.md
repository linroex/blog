<a href="http://www.vmware.com/">VMware</a>這套程式可以讓你的電腦同時開啟兩套以上的作業系統,不是像雙系統那樣,而是真的『同時』可以開啟很多作業系統,有些人可能會覺得一次開那麼多作業系統幹嘛? 吃飽太閒? 以遊戲的角度來看一次開兩套作業系統可以進行所謂的雙視窗,以資安角度來看使用虛擬機可以來幫助資安人員進行一些病毒的檢測,還有你從網路上下載了一些程式,可是不確定程式有沒有毒時,VMware就能幫上你的忙


<!--more-->


目前虛擬機這塊市場主要由<a href="http://www.vmware.com/">VMware</a>.<a href="http://www.virtualbox.org/">VirtualBox</a>.<a href="http://www.microsoft.com/windows/virtual-pc/">Virtual PC</a>瓜分,其中只有VMware是付費的,不過VMware雖然是付費的,可是它的市占率卻是這三款虛擬機裡面最高的,以我的想法是覺得付費的應該市占率最少0.0,不過Windows就是一個很大的例外的說....  話說回來VMware跟Windows不能相提並論,購買VMware這套程式是真的物超所值,因為他的功能實在比其他兩套好很多,例如效能方面它就比<a href="http://www.microsoft.com/windows/virtual-pc/">Virtual PC</a>好上幾千倍,而且它可以讓你使用Directx,這是其他兩套虛擬機所不可及的

有一個觀念需要導正,很多人以為虛擬機這類程式會內建作業系統,實際上是虛擬機會幫你開出一個新的虛擬電腦,你必須要自己去安裝作業系統,還有太舊的電腦是跑不動虛擬機的,因為你要同時執行兩套作業系統所以效能上會消耗很大

<strong>以下我會教大家如何去下載試用版的VMware Workstation以及安裝VMware Workstation</strong>

<strong> </strong>

<strong> </strong>
<h2>下載試用版VMware Workstation</h2>
1.請先連線到VMware官網,點選【Support &amp; Downloads】,然後點選Product Downloads底下的VMware Workstation

<a href="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_212800.jpg"><img class="alignnone size-large wp-image-3436" title="2010-07-10_212800" src="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_212800-550x334.jpg" alt="" width="550" height="334" /></a>

2.把瀏覽器捲軸拉到底下,你會看到Download按鈕,看你電腦是Windows還是Linux就選擇相應的Download按鈕

<a href="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_213028.jpg"><img class="alignnone size-large wp-image-3437" title="2010-07-10_213028" src="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_213028-550x334.jpg" alt="" width="550" height="334" /></a>

3.要下載試用版的VMware必須要先註冊一組VMware的帳號,如果你有的話直接在左邊那裡登入,然後接續看第5步教學,如果沒有的話就按一下【Register】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_213426.jpg"><img class="alignnone size-large wp-image-3438" title="2010-07-10_213426" src="{{< param imageBase >}}/wp-content/uploads/2010/07/2010-07-10_213426-550x334.jpg" alt="" width="550" height="334" /></a>

4.把相關資料填一填,然後按【continue】
