<a href="http://www.vmware.com/">VMware</a> is a program that lets your computer run two or more operating systems at the same time. It's not like dual-booting, where you pick one at startup. You can really have many operating systems running simultaneously. Some people may wonder why anyone would run so many operating systems at once. Do you have nothing better to do? From a gaming perspective, running two operating systems at once enables a so-called dual-window setup. From a security perspective, virtual machines help security staff test for viruses. And if you've downloaded a program from the internet and aren't sure whether it's safe, VMware can help you out.


<!--more-->


The virtual machine market is mainly split among <a href="http://www.vmware.com/">VMware</a>, <a href="http://www.virtualbox.org/">VirtualBox</a>, and <a href="http://www.microsoft.com/windows/virtual-pc/">Virtual PC</a>. Only VMware is paid. Even so, its market share is the highest of these three. In my view, a paid product should have a market share of at least 0.0, but Windows is a huge exception, haha.... That said, VMware and Windows can't be compared. VMware is really worth the money, because its features are much better than the other two. For example, its performance is thousands of times better than <a href="http://www.microsoft.com/windows/virtual-pc/">Virtual PC</a>, and it lets you use DirectX, which the other two can't do.

There's a misconception to clear up. Many people think virtual machine software comes with an operating system built in. In reality, it creates a new virtual computer for you, and you have to install the operating system yourself. Also, very old computers can't run virtual machines well, because running two operating systems at once consumes a lot of resources.
