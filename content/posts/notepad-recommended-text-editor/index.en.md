Almost everyone who writes programs or web pages uses a text editor, because sometimes you just want to open a file to look at its code, and opening it in Dreamweaver or Visual Studio takes too long. Some people use the Notepad that comes with Windows, or Vim, which is famous on Linux. Others install a text editor they find online. Today's pick, <strong><a href="http://notepad-plus-plus.org/" target="_blank">Notepad++</a></strong>, is a very well-known and powerful text editor.


<!--more-->
Notepad++ is one of the programs that always stays running on my computer. It's really good: it's free, it supports Traditional Chinese, and you can install lots of plugins. For example, Zen Coding, which I wrote about before, has a Notepad++ version. It also supports basic syntax highlighting and encoding conversion. It has a built-in "Run" feature, too. For example, if you're writing a web page and want to view it in a browser, you can just press a shortcut key. Or if you're writing Python or C++ code, you can press Run to automatically send the code to the compiler, or do other things. This needs to be set up yourself, though. There are plenty of tutorials online~

On top of that, Notepad++ can also fold and unfold code blocks, which helps keep your code neat and easy to read.

Installation is very simple. Just keep clicking Next 0.0
<h2>How to Install Plugins</h2>
Newer versions of Notepad++ have a built-in Plugins Manager, which you can use to install plugins directly into Notepad++. If the plugin you want doesn't appear there, you can also manually put the plugin files into the Plugins folder in the Notepad++ root directory.

1. Click "Plugins" -> "Plugin Manager" -> "Show Plugin Manager"

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_181806.jpg"><img class="alignnone size-large wp-image-732" title="2011-08-26_181806" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_181806-540x329.jpg" alt="" width="540" height="329" /></a>

2. Under "Available," select the feature you want to install, then click "Install"

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182053.jpg"><img class="alignnone size-large wp-image-734" title="2011-08-26_182053" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182053-540x369.jpg" alt="" width="540" height="369" /></a>

&nbsp;

3. You can also remove an installed plugin through Plugin Manager. Go to the "Installed" tab, select the plugin you want to remove, then click "Remove"

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182554.jpg"><img class="alignnone size-large wp-image-735" title="2011-08-26_182554" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182554-540x369.jpg" alt="" width="540" height="369" /></a>
<h2>How to Install a New Theme</h2>
Notepad++ has more than ten built-in themes that you can use right away. Of course, you can also write your own. Themes use the XML format. You can refer to the theme files in the theme folder in the Notepad++ root directory, then write the style you like.

1. To change the Notepad++ theme, it's simple: select "Settings" -> "Style Configurator"

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183000.jpg"><img class="alignnone size-large wp-image-736" title="2011-08-26_183000" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183000-540x329.jpg" alt="" width="540" height="329" /></a>

2. In the "Select theme" section, choose the one you like, then click "Save & Close." You can preview the styles as you choose, and they apply immediately.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183157.jpg"><img class="alignnone size-large wp-image-737" title="2011-08-26_183157" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183157-540x303.jpg" alt="" width="540" height="303" /></a>
<h2>The Ultimate Trick for Installing Plugins and Themes!</h2>
Sometimes the plugin you want doesn't appear in Plugin Manager, or you want to install a theme you downloaded from the internet. What do you do? It's actually very simple XD. Select "Settings" -> "Import," then select the item you want to import, and you're done~
