プログラムやウェブページを書く人なら、ほぼ全員がテキストエディタを使っているはずです。コードを確認するためにファイルを開きたいだけのときに、Dreamweaver や Visual Studio で開くと時間がかかってしまうからです。Windows に標準で付いているメモ帳を使う人もいれば、Linux で有名な Vim を使う人もいます。また、インターネットで見つけたテキストエディタをインストールする人もいます。今回ご紹介する <strong><a href="http://notepad-plus-plus.org/" target="_blank">Notepad++</a></strong> は、非常に有名で機能の強力なテキストエディタです。


<!--more-->
Notepad++ は、私のパソコンで常に起動している常駐プログラムの一つです。本当に使いやすく、無料で繁体字中国語にも対応しており、多くのプラグインをインストールできます。たとえば、以前ご紹介した Zen Coding にも Notepad++ 版があります。構文ハイライトや文字コードの変換などの基本機能にも対応しています。また、「実行」機能も内蔵されています。たとえば、ウェブページを書いていてブラウザで確認したいときは、ショートカットキーを押すだけです。Python や C++ のコードを書いているときは、実行を押せばコードが自動的にコンパイラへ送られ、ほかの処理も行えます。ただし、この部分は自分で設定する必要があります。ネット上にはたくさんのチュートリアルがあります～

さらに、Notepad++ ではコードを折りたたんだり展開したりでき、コードをすっきり見やすく整理できます。

<h2>Notepad++ の特徴</h2>
<ul>
	<li>オープンソース、多言語対応、無料</li>
	<li>拡張機能やテーマをインストールできる</li>
	<li>タブモード。ブラウザのタブに似ています</li>

	<li>自動補完機能</li>
</ul>
インストールはとても簡単で、「次へ」を押し続けるだけです 0.0
<h2>プラグインのインストール方法</h2>
新しいバージョンの Notepad++ には Plugins Manager が内蔵されており、そこから直接 Notepad++ にプラグインをインストールできます。目的のプラグインがそこに表示されない場合は、プラグインのファイルを Notepad++ のルートディレクトリにある Plugins フォルダーへ手動で入れることもできます。

1. 「プラグイン」→「Plugin Manager」→「Show Plugin Manager」をクリックします

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_181806.jpg"><img class="alignnone size-large wp-image-732" title="2011-08-26_181806" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_181806-540x329.jpg" alt="" width="540" height="329" /></a>

2. 「Available」で、インストールしたい機能を選択し、「Install」をクリックします

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182053.jpg"><img class="alignnone size-large wp-image-734" title="2011-08-26_182053" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182053-540x369.jpg" alt="" width="540" height="369" /></a>

&nbsp;

3. Plugin Manager からインストール済みのプラグインを削除することもできます。「Installed」タブに移動し、削除したいプラグインを選択して「Remove」をクリックします

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182554.jpg"><img class="alignnone size-large wp-image-735" title="2011-08-26_182554" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_182554-540x369.jpg" alt="" width="540" height="369" /></a>
<h2>新しいテーマのインストール方法</h2>
Notepad++ には 10 種類以上のテーマが内蔵されており、すぐに使えます。もちろん、自分で作成することもできます。形式は XML です。Notepad++ のルートディレクトリにある theme フォルダー内のテーマファイルを参考にして、好みのスタイルを書いてください。

1. Notepad++ のテーマを変更するのはとても簡単です。「設定」→「Style Configurator」を選択します

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183000.jpg"><img class="alignnone size-large wp-image-736" title="2011-08-26_183000" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183000-540x329.jpg" alt="" width="540" height="329" /></a>

2. 「Select theme」の部分で好みのテーマを選び、「Save & Close」をクリックすれば完了です。テーマを選びながらスタイルを確認でき、すぐに適用されます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183157.jpg"><img class="alignnone size-large wp-image-737" title="2011-08-26_183157" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_183157-540x303.jpg" alt="" width="540" height="303" /></a>
<h2>プラグインとテーマを入れる最後の裏技！</h2>
Plugin Manager に目的のプラグインが表示されない場合や、ネットからダウンロードしたテーマをインストールしたい場合はどうすればよいでしょうか。実はとても簡単です XD。「設定」→「インポート」を選択し、インポートしたいものを選べば完了です～
