I'm sure you've noticed the new sticker at the bottom of the sidebar on this site, which mentions a program called IE8. IE8 is Microsoft's latest browser. It was originally supposed to come out together with Windows 7, but Microsoft has always liked to release its browser before the operating system, and IE7 with Vista was the same. But that's a digression~ In this post I want to introduce Microsoft's IE8. From my own experience, Microsoft has finally woken up this time! The features it introduces are also worth a look. Several of them aren't even in Firefox (maybe the next Firefox update will add them). And Microsoft, which has always ignored the rules and acted like a big shot, actually follows the W3C CSS 2.1 standard. Looks like Microsoft has learned to humble itself before its users^^
