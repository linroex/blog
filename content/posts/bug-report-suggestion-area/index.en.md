I've been using Firefox lately, so I hadn't noticed that this blog has problems when it's opened in Internet Explorer.

For example, page script errors, or the sidebar sinking to the bottom, and so on.

To give other visitors a better environment,

I'd like readers who run into these problems to report them here.

The report format is as follows:

Operating system:

Screen resolution:

Computer type: (laptop or desktop)

Time: (when the problem occurred)
<!--more-->


Browser: (the browser you use)

Describe the problem: (explain what happened in as much detail as you can)

Fill in the information above and reply.

Thank you for your cooperation.

If you have any criticism or advice for this site, please feel free to leave a comment here as well.
