<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">As the saying goes, the tall tree catches the wind. WordPress is the most widely used blogging platform in the world, so it's also a prime target for hackers everywhere. Strengthening your WordPress security is something every blogger has to do. WordPress releases security updates every so often, but keeping your site safe also depends on you. A Japanese organization once studied computer incidents (computers being attacked) and found that a large share of them came from user mistakes rather than from problems with the system itself. So in this post, I'll borrow an article from the Chinese blog <a href="http://www.williamlong.info/archives/1617.html">Moonlight Blog</a> to show you how to check whether your WordPress installation is secure enough.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">
<!--more-->

</span></p>

<blockquote>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">The following content is quoted from <a href="http://www.williamlong.info/archives/1617.html">http://www.williamlong.info/archives/1617.html</a></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>1. Upgrade WordPress to the latest version</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">In general, newer versions of WordPress are more secure. They fix known security problems, and major version upgrades may fix even more critical issues. </span> <span onmouseover="_tipon(this)" onmouseout="_tipoff()">(For example, older versions of WordPress had a serious remv.php vulnerability that could leave you open to DDoS attacks. Upgrading to the latest 2.7 release fixes this problem.)</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>2. Hide your WordPress version</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">Edit your header.php template and remove the WordPress version information. That way, hackers can't check the page source to see whether you're running the latest version.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>3. Change your WordPress username</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">Every hacker knows that WordPress's administrator account is "admin" and has administrator privileges, so that's the account they'll target. Create a new user, give it administrator privileges, and then delete the old admin account. This keeps hackers from guessing your administrator username.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><span style="color: #ff0000;">Blogger's note</span></span></p>

<li><span style="color: #ff0000;">If you change it manually, remember to edit the wp-config.php settings as well.</span></li>

<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>4. Change your WordPress user password</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">After you install WordPress, the system emails you a random password. Change it. That password is only 6 characters long, so change it to a complex password of at least 10 characters, mixing letters, numbers, and symbols as much as possible.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>5. Prevent directory listing of WordPress folders</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">By default, WordPress installs plugins under /wp-content/plugins/. Normally, browsing that directory lists all the installed plugin names. That's bad, because hackers can use known plugin vulnerabilities to attack. You can prevent this by putting an empty index.html file in that directory. Of course, editing the Apache .htaccess file achieves the same thing.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>6. Protect the wp-admin folder</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">You can protect the WordPress admin folder by restricting access to specific IP addresses. All other IP addresses get a "forbidden" message. The downside is that you can only manage your blog from one or two places. </span> <span onmouseover="_tipon(this)" onmouseout="_tipoff()">Also, put a new .htaccess file in the wp-admin directory so that the .htaccess file in the root directory can't be replaced.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>7. Protection against search engines</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">Many WordPress system files don't need to be indexed by search engines, so edit your robots.txt file and add the line "Disallow: /wp-*"</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><span style="color: #ff0000;">Blogger's note: The robots.txt file lives in your site's root directory, and it determines which files search engines are allowed to index.</span></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>8. Install the Login Lockdown plugin</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><a style="text-decoration: underline; color: #4e0a13;" href="http://goo.gl/h4ap " target="_blank">This plugin</a> records the IP addresses and times of failed login attempts. If failed logins from one IP address exceed a certain threshold, the system blocks that IP address from trying to log in again.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><strong>9. WordPress database security</strong></span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()">Don't use the default wp_ prefix for your database tables. Install a database backup plugin. No matter how well you protect your site, you should still back up your database regularly. Plugins such as WordPress Database Backup can make regular backups easy.</span></p>
<p style="margin-top: 10px; margin-right: 0px; margin-bottom: 15px; margin-left: 0px; word-break: break-all; padding: 0px;"><span onmouseover="_tipon(this)" onmouseout="_tipoff()"><span style="color: #ff0000;">Blogger's note: If you didn't change the wp_ prefix during installation, you can edit the database manually or use </span><a href="https://coder.tw/?p=2222"><span style="color: #ff0000;">Wordpress Security Scan</span></a><span style="color: #ff0000;"> to change it.</span></span></p>
