This version of the Microsoft 2010 IME hasn't changed the interface much. That's so people who used the Microsoft IME 2007 don't have a hard time switching over (example: my mom....). At first I thought it didn't have any new features, but after typing this post, my opinion changed. The Microsoft 2010 IME has really improved its smart word selection (which is probably why this post has fewer typos XD). The 2007 Microsoft IME used to make a lot of typos, and I never understood what Microsoft was thinking. It would often spit out really strange words = = But Microsoft Office IME 2010 doesn't have that problem. Also, Microsoft Office IME 2010 is free, so no need to worry about the BSA coming to your door one day ^^

Maybe some of you used to download the Office main program from Microsoft's website and then separate the IME out of it? This time there's no need for that hassle, because Microsoft officially offers a direct download for the 2010 IME, so you can just go grab it~~~

<h2>Adding Input Methods to the Microsoft 2010 IME</h2>
After installing the Microsoft 2010 IME on my laptop, I only had New Phonetic and New Cangjie. So what if I want to use New Quick? Here's how~~

1. Right-click the input method toolbar and select Settings.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-07_184323.jpg"><img class="alignnone size-full wp-image-3670" title="2010-08-07_184323" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-07_184323.jpg" alt="" width="339" height="160" /></a>

2. Click Add, select the input method you want to add, and click OK.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-07_184512.jpg"><img class="alignnone size-large wp-image-3671" title="2010-08-07_184512" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-07_184512-550x305.jpg" alt="" width="550" height="305" /></a>

3. Click OK to save the changes.
