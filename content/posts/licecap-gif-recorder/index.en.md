The GIF format nearly disappeared for a while, but recently, with the rise of Facebook and Twitter, more and more people use GIFs to make animations or as stickers in Messenger. I use them for the tutorial videos in my blog posts. GIFs have the advantages of small files and quick loading on web pages. For certain rough motions, GIFs work very well for tutorials. Today I want to share <a href="http://www.cockos.com/licecap/">LICEcap</a>, which can record your screen to make GIF files. It supports Mac and Windows and has a simple interface. All the recent GIFs on my blog were recorded with <a href="http://www.cockos.com/licecap/">LICEcap</a>.

Using LICEcap is very simple. When you open it, you'll see a program that is just a frame. Don't be suspicious, that is LICEcap! Drag its border to surround the area you want to record. Whatever is inside the frame will be recorded.

After you press "Record," it asks for parameters such as where to save the file and how often to take a capture. Once you've set those, press "Save" and recording starts right away. Now you can do what you need to show. When you're done, press "Stop" and it saves automatically.

It feels a bit unfamiliar the first time, because most screen recording software records first and saves afterward. LICEcap saves the file first. When you press Stop, no confirmation screen or dialog box appears, so sometimes you're not sure whether you were recording (lol).

Keep these points in mind when recording a GIF:
<ol>
 	<li>After recording starts, wait 1-2 seconds before you act. When your action is finished, also wait 1-2 seconds before you press Stop.</li>
 	<li>Because of how GIFs work, you can slow the motions down a little.</li>
 	<li>GIFs have no sound, you know!</li>
</ol>
After recording, if you're a Mac user and want to preview the result, select the file and press the Space bar. Be careful not to open it directly, because a GIF is actually many image frames stitched together. If you open a GIF in Preview, you'll only see a bunch of separate images.
