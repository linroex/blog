GIF という形式はしばらく姿を消していましたが、最近は Facebook や Twitter の普及によって、アニメーションを作ったり Messenger のスタンプとして使ったりする人が増えてきました。私自身は、ブログ記事のチュートリアル動画として GIF を使っています。GIF は、ファイルが小さくウェブページで素早く読み込めるという利点があります。動きがざっくりしたものであれば、チュートリアルに GIF を使うのはとても向いています。今日紹介したいのは <a href="http://www.cockos.com/licecap/">LICEcap</a> です。画面を録画して GIF ファイルを作れるツールで、Mac と Windows に対応しており、操作もシンプルです。私のブログで最近使っている GIF は、すべて <a href="http://www.cockos.com/licecap/">LICEcap</a> で録画したものです。

LICEcap の使い方はとても簡単です。起動すると、枠だけのプログラムが表示されます。驚かないでください、それが LICEcap です！ 枠のふちをドラッグして、録画したい範囲を囲んでください。枠の内側が録画される部分になります。

「Record」を押すと、ファイルの保存先や、どれくらいの間隔でキャプチャするかといったパラメーターを聞かれます。設定を終えたら「Save」を押すと、すぐに録画が始まります。ここで操作を行えば OK です。録画が終わったら「Stop」を押すと、自動的に保存されます。

最初は少し戸惑うかもしれません。ほとんどの録画ソフトは、録画してから保存する仕組みですが、LICEcap は先に保存先を決める設計だからです。Stop を押しても、確認画面やダイアログは一切表示されません。そのため、本当に録画されていたのか分からなくなることがあります（笑）。

GIF を録画するときは、次の点に注意してください。
<ol>
 	<li>録画を開始したら、1〜2 秒待ってから操作を始めてください。操作が終わったあとも、1〜2 秒待ってから Stop を押してください。</li>
 	<li>GIF の仕組み上、動きは少しゆっくりめにすると良いでしょう。</li>
 	<li>GIF には音声がありません！</li>
</ol>
録画が終わったら、Mac ユーザーの方は効果をプレビューしたいときに、ファイルを選んでスペースキーを押してください。ファイルを直接開くのは避けてください。GIF は実際には多数の画像ファイルをつなぎ合わせたものなので、Preview で GIF を開くと、ばらばらの画像が並んでいるように見えるだけだからです。
