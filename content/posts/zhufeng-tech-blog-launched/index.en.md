It's been a busy day. From getting the site set up yesterday to getting the domain bound today, it's been about 24 hours~ I hereby officially announce: the Zhufeng Tech Blog is live~

The Zhufeng Tech Blog is a branch site of the Wind Chaser blog. The site owner is the same person, but the articles on the Zhufeng Tech Blog will be more in-depth, focusing on technical topics like programming languages and web design. Currently the posting frequency is about two articles a week; if I have time it'll be more, but it won't drop below two a week. Also, as for ads on the Zhufeng Tech Blog, I can guarantee that there won't be any ads for the first six months, because the funding for the next six months is definitely enough to keep the site running, and the ad revenue from the main site is still sufficient.

Also, the Zhufeng Tech Blog currently uses the following for file storage: Google Docs, Box.net, 4Shared, and Dropbox. Images are also hosted on my own server. I think with this kind of high-spec setup there shouldn't be any more problems with files or images failing to load... If I have extra ad revenue in the second half of the year, I'll rent a cheaper VPS dedicated to hosting the various file links on the site: examples, project files, and so on. I'll also open it up for other users. As for the details, we'll see in the second half of the year.
<h2>About reposting articles:</h2>
To put it simply: reposting articles is fine, but please include a link to the original site, don't claim it as your own article (work), and please don't steal images. Thanks :)
<h2>About anonymous comments:</h2>
For now I still allow comments without logging in, but when you comment please make sure not to put in a fake email address. If I find that your email is fake, your comment will be removed. Don't count on getting away with it — this site uses a comment moderation system. If you want to talk trash, you're welcome to, but please don't do it anonymously. Thanks.
<h2>About site check frequency:</h2>
Site check frequency means how often the site's links and images are checked for broken links. Currently I plan to do a minor check every six months (automated scanning with a program) and a major check once a year (manual check). Also, this site has the Broken Link Checker plugin installed, which automatically checks the validity of links and images once a week.
