Google Desktop is one of the programs I install every time I reinstall my computer. It matters to me even more than Yahoo! Messenger! Simply put, Google Desktop is a file search and management program. You can find the files you need by searching for keywords. Windows has this feature built in too, but honestly the built-in Windows search is... slow and awful. It can take me 30 seconds to get results for a file, while Google Desktop returns results in just 1 to 3 seconds! Google Desktop isn't only for searching files, either. It has a built-in sidebar where you can add small gadgets such as Google Calendar, a to-do list, news, weather, and more. You can even write your own gadgets and put them in the sidebar~


<!--more-->


So why is Google Desktop search so fast? It uses idle time on your computer to build an index of everything stored on it. When you search, it doesn't actually go hunting through the hard drive for files. Instead, it searches that index. Of course, that's much faster than the search tool built into Windows.

<h2>Configuring Google Desktop</h2>
Sometimes you may want Google Desktop to search only certain file types, such as documents only. Or you may want it to search not just local files, but also data in your Google account (like Google Docs, Gmail, and so on). If so, refer to the following to adjust the settings.

1. Go to Start → All Programs → Google Desktop → Google Desktop Options.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185400.jpg"><img class="alignnone size-full wp-image-4775" title="2011-02-19_185400" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185400.jpg" alt="" width="411" height="485" /></a>

2. Under "Search Types," you can choose which file formats to search. I also recommend checking "Remove items when deleted."

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185627.jpg"><img class="alignnone size-large wp-image-4776" title="2011-02-19_185627" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185627-520x432.jpg" alt="" width="520" height="432" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185646.jpg"><img class="alignnone size-large wp-image-4777" title="2011-02-19_185646" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_185646-520x432.jpg" alt="" width="520" height="432" /></a>

3. Under "Search Locations," you can specify folders you don't want searched. For example, the C:WINDOWS folder can be added here, since the files you need usually aren't stored there. Besides C:WINDOWS, there may be other folders you don't want searched, so go ahead and add them to Search Locations~

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_190045.jpg"><img class="alignnone size-large wp-image-4778" title="2011-02-19_190045" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-19_190045-520x432.jpg" alt="" width="520" height="432" /></a>

4. When you're done, click "Save Preferences."
