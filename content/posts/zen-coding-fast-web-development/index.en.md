I think many people are like me: when building a web page, they don't like dragging out the layout directly in DW, and instead prefer to open Notepad and write the HTML by hand～ The upside of this approach is that it sharpens your skills XD, but the downside is that development is a bit slow (actually, once you get used to working this way, you're faster than you would be with DW... XD). Today I want to introduce Zen Coding to you — it can make you write web pages N times faster! You can write web pages directly using CSS-style syntax～

<span class="Apple-style-span" style="color: #000000; font-weight: bold;">How to Use</span>

I'll use Notepad++ as the example here. The shortcuts in other editors aren't necessarily the same as Notepad++'s, so please check the Wiki on the official site (<a href="http://code.google.com/p/zen-coding/w/list">http://code.google.com/p/zen-coding/w/list</a>) or read the information shown after installation.

1. First download the Zen Coding made for Notepad++ and install it.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233.jpg"><img class="alignnone size-large wp-image-715" title="2011-08-22_212233" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233-540x380.jpg" alt="" width="540" height="380" /></a>

2. Open Notepad++ and you can start following the <a href="http://zen-coding.googlecode.com/files/ZenCodingCheatSheet.pdf" target="_blank">cheat sheet</a>～ Also, the expand shortcut in Notepad++ is "Ctrl+E"; press it to expand the short code into HTML. Here are some common usages:
<ul>
	<li>Generate a div tag with id=a: #a</li>
	<li>Generate 10 li tags: li*10</li>
	<li>Generate 10 li tags with class=an incrementing number: li.$*10</li>
</ul>
P.S. The $ here means the incrementing number, and "." in CSS means class
<ul>
	<li>Generate a ul and then generate 5 li tags: ul>li*5</li>
</ul>
P.S. The ">" symbol here means that after generating the ul, you generate li*5 inside the ul

Those are the common usages, but the cheat sheet has many more. Besides generating HTML, it can do CSS too～ First create a style tag, then type keywords inside the style tag and CSS is generated instantly～
<ul>
	<li>Quickly generate "float:;": fl</li>
	<li>Quickly generate "float:left;": fl:l</li>
	<li>Quickly generate "display:none;": d:n</li>
	<li>Quickly generate "margin:auto;": m:a</li>
</ul>
