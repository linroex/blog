きっと多くの人と同じように、私も Web ページを書くときは、DW（Dreamweaver）でデザイン画面をドラッグして組み立てるより、Notepad を開いて HTML を直接書くほうが好きです～ この方法の良いところは、自分の腕を磨けることです（XD）。ただ、欠点は開発のスピードがやや遅いことです（とはいえ、この書き方に慣れると DW より速くなるんですけどね…XD）。今日は Zen Coding を紹介します。これを使うと、Web ページを書く速度が何倍にも上がります！ CSS の記述のような書き方で、そのまま Web ページを書けるんですよ～


<!--more-->

<span class="Apple-style-span" style="color: #000000; font-weight: bold;">使い方</span>

ここでは Notepad++ を例に説明します。ほかのエディターではショートカットキーが Notepad++ と同じとは限らないので、公式サイトの Wiki（<a href="http://code.google.com/p/zen-coding/w/list">http://code.google.com/p/zen-coding/w/list</a>）で調べるか、インストール後に表示される情報をご覧ください。

1. まず Notepad++ 用の Zen Coding をダウンロードして、インストールします

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233.jpg"><img class="alignnone size-large wp-image-715" title="2011-08-22_212233" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233-540x380.jpg" alt="" width="540" height="380" /></a>

2. Notepad++ を開いたら、<a href="http://zen-coding.googlecode.com/files/ZenCodingCheatSheet.pdf" target="_blank">クイックガイド</a>に沿って始められます～ また、Notepad++ での展開ショートカットは「Ctrl+E」です。このキーを押すと、略記（短縮コード）が HTML に展開されます。よく使う例をいくつか紹介します：
<ul>
	<li>div タグを生成し、id=a を指定する：#a</li>
	<li>li タグを 10 個生成する：li*10</li>
	<li>li タグを 10 個生成し、class に連番を指定する：li.$*10</li>
</ul>
P.S. ここでの「$」は連番を意味し、「.」は CSS でのクラスを意味します。
<ul>
	<li>ul を生成したあと、その中に li タグを 5 個生成する：ul>li*5</li>
</ul>
P.S. ここでの「>」は、ul を生成したあと、その ul の中に li*5 を生成することを表します。

以上がよく使う例です。クイックガイドにはほかにも多くの例が載っていて、HTML だけでなく CSS も生成できます～ まず style タグを作成し、その中にキーワードを入力すると、CSS をすばやく生成できます～
<ul>
	<li>「float:;」をすばやく生成する：fl</li>
	<li>「float:left;」をすばやく生成する：fl:l</li>
	<li>「display:none;」をすばやく生成する：d:n</li>
	<li>「margin:auto;」をすばやく生成する：m:a</li>
</ul>
