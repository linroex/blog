<span class="Apple-style-span" style="color: #000000; font-weight: bold;">使用教學</span>

此處以Notepad++做介紹，其他編輯器的快捷鍵未必跟Notepad++相同，請自行到官網的Wiki查詢（<a href="http://code.google.com/p/zen-coding/w/list">http://code.google.com/p/zen-coding/w/list</a>）或是看安裝完之後的資訊

1.先下載Notepad++專用的Zen Coding，然後把它安裝好

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233.jpg"><img class="alignnone size-large wp-image-715" title="2011-08-22_212233" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-22_212233-540x380.jpg" alt="" width="540" height="380" /></a>

2.開啟Notepad++，然後你就可以照者<a href="http://zen-coding.googlecode.com/files/ZenCodingCheatSheet.pdf" target="_blank">快速教學</a>開始進行囉～ 另外Notepad++的展開快捷鍵是「Ctrl+E」，按下快捷鍵就可以把短碼展開成HTML，這裡介紹一些常見的用法：
<ul>
	<li>產生div tag，並且指定id=a：#a</li>
	<li>產生10個li tag：li*10</li>
	<li>產生10個li tag，並且指定class=流水號：li.$*10</li>
</ul>
P.S.這裡的$就是流水號的意思，然後「.」在CSS裡面就是class的意思
<ul>
	<li>產生ul之後在產生li tag 5個：ul>li*5</li>
</ul>
P.S.這裡的「>」符號代表產生ul之後，在ul裡面產生li*5

上面是常見的用法，另外快速教學裡還有很多，除了可以產生HTML以外，CSS也可以的說～ 首先要建立一個style tag，然後再style tag裡面輸入關鍵字就可以快速產生CSS了～
<ul>
	<li>快速產生「float:;」：fl</li>
	<li>快速產生「float:left;」：fl:l</li>
	<li>快速產生「display:none;」：d:n</li>
	<li>快速產生「margin:auto;」：m:a</li>
</ul>
