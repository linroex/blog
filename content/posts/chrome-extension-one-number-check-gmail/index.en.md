This post introduces a Chrome extension called One Number. It checks Gmail, Google Reader, and Google Voice for new messages. Many similar tools exist in the Chrome Extensions gallery, but I especially like One Number because it combines Gmail, Google Reader, and Google Voice in one place. Unlike <a href="https://chrome.google.com/extensions/detail/mihcahmgecmbnbcchbopgniflfhgnkff?hl=zh-TW">Google Mail Checker</a>, which only checks Gmail for new mail, One Number's author, mzzt.net, is verified by Google, so you do not need to worry too much about viruses.
<h2>
<!--more-->
How to Use One Number</h2>
Step 1: Go to <a href="http://goo.gl/iYcT">http://goo.gl/iYcT</a> and click Install to finish the installation.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150620.jpg"><img class="alignnone size-large wp-image-3868" title="2010-10-24_150620" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150620-550x309.jpg" alt="" width="550" height="309" /></a>

Step 2: After installing, you also need to log in so that One Number can get the information it needs (whether there are new messages). Click the One Number icon, then click Log in and enter your account and password.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150925.jpg"><img class="alignnone size-large wp-image-3869" title="2010-10-24_150925" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150925-511x400.jpg" alt="" width="511" height="400" /></a>

Step 3: After you log in, One Number checks for new messages at regular intervals. You can also click Refresh to have One Number check manually.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_151100.jpg"><img class="alignnone size-large wp-image-3870" title="2010-10-24_151100" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_151100-550x272.jpg" alt="" width="550" height="272" /></a>

Step 4: When a new message arrives, the One Number icon changes from gray to color. Click the button to see which service has new messages. It also shows how many new messages there are.
