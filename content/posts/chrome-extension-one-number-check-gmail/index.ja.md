この記事では、Chrome の拡張機能「One Number」を紹介します。この拡張機能は、Gmail、Google Reader、Google Voice に新着メッセージがあるかどうかを確認してくれます。同じような拡張機能は Chrome の拡張機能ストアにたくさんありますが、私は Gmail、Google Reader、Google Voice を一つにまとめてくれる One Number が特に気に入っています。Gmail の新着メールしか確認できない <a href="https://chrome.google.com/extensions/detail/mihcahmgecmbnbcchbopgniflfhgnkff?hl=zh-TW">Google Mail Checker</a> とは違います。また One Number の作者 mzzt.net は Google の認証を受けているため、ウイルスの心配もあまりいりません。
<h2>
<!--more-->
One Number の使い方</h2>
1.まず <a href="http://goo.gl/iYcT">http://goo.gl/iYcT</a> のページを開き、インストールボタンを押せばインストール完了です

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150620.jpg"><img class="alignnone size-large wp-image-3868" title="2010-10-24_150620" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150620-550x309.jpg" alt="" width="550" height="309" /></a>

2.インストールしたら、ログインも必要です。One Number が新着メッセージの情報を取得できるように、One Number のアイコンをクリックし、「Log in」を押してアカウントとパスワードを入力してください

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150925.jpg"><img class="alignnone size-large wp-image-3869" title="2010-10-24_150925" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_150925-511x400.jpg" alt="" width="511" height="400" /></a>

3.ログインすると、One Number が一定間隔で新着メッセージを確認します。「Refresh」を押せば、手動で確認させることもできます

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_151100.jpg"><img class="alignnone size-large wp-image-3870" title="2010-10-24_151100" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-24_151100-550x272.jpg" alt="" width="550" height="272" /></a>

4.新着メッセージが届くと、One Number のアイコンがグレーからカラーに変わります。ボタンをクリックすると、どのサービスに新着があるかを確認できます。新着メッセージの件数も表示されます
