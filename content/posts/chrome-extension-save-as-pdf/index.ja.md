気に入ったコンテンツをブックマークしておいても、サイトが閉鎖されたり記事が削除されたりすると、ブックマークしていても記事は見られなくなってしまいます。そんなときは、PDF として保存するのがよい選択です。オフラインで読みたいときにも PDF はぴったりです～


<!--more-->


Save as PDF は、pdfcrowd.com が提供している Chrome 拡張機能です。閲覧中の Web ページをすばやく pdfcrowd.com のサーバーに送り、PDF に変換してから、パソコンにダウンロードできるようにします。また HTML to PDF の API も提供しているので、開発者の方は試してみてください～ pdfcrowd.com が存続している限りは、この機能を長く使えるはずです（笑）
<h2>Save as PDF の情報</h2>
<ul>
	<li>インストール URL：<a href="https://chrome.google.com/webstore/detail/kpdjmbiefanbdgnkcikhllpmjnnllbbc">https://chrome.google.com/webstore/detail/kpdjmbiefanbdgnkcikhllpmjnnllbbc</a></li>
	<li>本記事執筆時のバージョン：1.6</li>
	<li>作者：pdfcrowd.com</li>
</ul>
<h2>使い方</h2>
Save as PDF をインストールすると、右上にアイコンが表示されます。ボタンを押すと、閲覧中の Web ページが自動的に PDF として保存されます～

<a href="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103833.jpg"><img class="alignnone size-large wp-image-5748" title="2011-09-03_103833" src="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103833-520x363.jpg" alt="" width="520" height="363" /></a>

アイコンがくるくる回転します。これは PDF への変換処理を行っていることを示しています。処理が終わると、保存先を尋ねられます。
