Sometimes you bookmark content you like, but if the site goes down or the article is removed, the bookmark is useless and you can no longer read the article. In that case, saving it as a PDF is a good choice. PDFs are also a great fit when you want to read offline~


<!--more-->


Save as PDF is a Chrome extension from pdfcrowd.com. It quickly sends the web page you are viewing to the pdfcrowd.com server, converts it to PDF, and then lets you download the file to your computer. It also offers an HTML to PDF API, so developers can give it a try~ As long as pdfcrowd.com stays online, this feature should keep working, I hope XD

	<li>Version at the time of writing: 1.6</li>
	<li>Author: pdfcrowd.com</li>
</ul>
<h2>How to Use</h2>
After you install Save as PDF, its icon appears in the upper-right corner. Click the button, and it automatically saves the web page you are viewing as a PDF~

<a href="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103833.jpg"><img class="alignnone size-large wp-image-5748" title="2011-09-03_103833" src="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103833-520x363.jpg" alt="" width="520" height="363" /></a>

The icon starts spinning, which means it is processing the PDF conversion request. When it finishes, it asks where you want to save the file.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103942.jpg"><img class="alignnone size-large wp-image-5749" title="2011-09-03_103942" src="{{< param imageBase >}}/wp-content/uploads/2011/09/2011-09-03_103942-520x422.jpg" alt="" width="520" height="422" /></a>

The result looks pretty good, and the text does not get blurry when you zoom in.
