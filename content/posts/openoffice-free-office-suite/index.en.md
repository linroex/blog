Did you know that Microsoft Office isn't the only software that can handle word processing? Plenty of other programs can do the same job, and OpenOffice is one of the best of them. OpenOffice is nearly identical to Microsoft Office in function. It can handle word processing, presentations, spreadsheets, databases, and more. Most importantly, it's free. It also supports extensions, so you can install plugins that add features and make it fit your needs even better.


<!--more-->


Some people feel that OpenOffice's features can't match Microsoft's, and I admit that's true. But in practical terms, the features OpenOffice lacks are not used very often. Also, OpenOffice supports extensions, and you can install plugins to add features, so you could say OpenOffice's functionality is unlimited. For that reason, I personally think that if you have a limited budget or simply don't want to spend money, you should use OpenOffice.
<h2>OpenOffice Features</h2>
<ul>
	<li>Free and open source</li>
	<li>Full-featured, with support for extensions</li>
	<li>Multilingual interface built in, with good support for Traditional Chinese</li>
	<li>Supports multiple operating systems</li>
</ul>
<h2>OpenOffice Information</h2>
<ul>
	<li>Official website: <a href="http://zh.openoffice.org/new/index.html">http://zh.openoffice.org/new/index.html</a></li>
	<li>Company: Oracle</li>
	<li>Download page: <a href="http://download.openoffice.org/index.html">http://download.openoffice.org/index.html</a></li>
	<li>Supported languages: Multiple languages (including Traditional Chinese)</li>
</ul>
<h2>Included OpenOffice Software</h2>
<ul>
	<li>Writer → word processing, similar to Word</li>
	<li>Calc → spreadsheets, similar to Excel</li>
	<li>Impress → presentations, similar to PowerPaint</li>
	<li>Draw → drawing (I've never used it)</li>
	<li>Base → databases, similar to Access</li>
	<li>Math → formulas (I've never used it)</li>
</ul>
<h2>OpenOffice Installation Tutorial</h2>
1.First, go to the <a href="http://download.openoffice.org/index.html">download page</a> and download the main OpenOffice program

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205617.jpg"><img class="alignnone size-large wp-image-4275" title="2010-12-22_205617" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205617-520x315.jpg" alt="" width="520" height="315" /></a>

2.After the download finishes, open the installer and click 【Next】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205823.jpg"><img class="alignnone size-full wp-image-4276" title="2010-12-22_205823" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205823.jpg" alt="" width="503" height="361" /></a>

3.Because the downloaded file is large, the program has to be extracted before it can be installed. This step sets where the extracted files are temporarily stored. By default they go on the desktop, but you can click 【Browse】 to change the location.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205934.jpg"><img class="alignnone size-full wp-image-4277" title="2010-12-22_205934" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_205934.jpg" alt="" width="503" height="361" /></a>

4.Extracting...

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_210010.jpg"><img class="alignnone size-full wp-image-4278" title="2010-12-22_210010" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_210010.jpg" alt="" width="503" height="361" /></a>

5.Once extraction finishes, the installer starts automatically. Just click 【Next】.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211130.jpg"><img class="alignnone size-full wp-image-4279" title="2010-12-22_211130" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211130.jpg" alt="" width="504" height="382" /></a>

6.Enter your user name and click 【Next】. The 【Organization】 field is optional.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211309.jpg"><img class="alignnone size-full wp-image-4280" title="2010-12-22_211309" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211309.jpg" alt="" width="504" height="382" /></a>

7.Keep the default settings and click 【Next】. If you only want to install certain components of OpenOffice instead of all of them, click 【Custom】.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211404.jpg"><img class="alignnone size-full wp-image-4281" title="2010-12-22_211404" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211404.jpg" alt="" width="504" height="382" /></a>

8.Click 【Install】, and the system will automatically install OpenOffice and make the related settings.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211534.jpg"><img class="alignnone size-full wp-image-4282" title="2010-12-22_211534" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211534.jpg" alt="" width="504" height="382" /></a>

9.Installation complete

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211802.jpg"><img class="alignnone size-full wp-image-4283" title="2010-12-22_211802" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_211802.jpg" alt="" width="504" height="382" /></a>

10.After installation, go to the Start menu (All Programs), open the OpenOffice.org folder, and run the openoffice.org program. You can also open it directly from the desktop. This program helps you quickly configure OpenOffice.

11.Click 【Continue】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_212330.jpg"><img class="alignnone size-large wp-image-4286" title="2010-12-22_212330" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_212330-520x333.jpg" alt="" width="520" height="333" /></a>

12.Enter your information

<a href="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_212526.jpg"><img class="alignnone size-large wp-image-4287" title="2010-12-22_212526" src="{{< param imageBase >}}/wp-content/uploads/2010/12/2010-12-22_212526-520x333.jpg" alt="" width="520" height="333" /></a>

14.This step asks whether you want to register. Registering doesn't affect the program's functions. If you have time, go ahead and register. Otherwise, choose the option not to register and click 【Finish】.
