FireFox3.5終於出來了,我也要趕快去下載XD,因為我現在用的這個也還是RC而已,話說這次FireFox3.5改版有啥差別呢?
<!--more-->
以下是官網的資訊
<ul>
	<li>提供超過 7 0 種語言支援。</li>
	<li>支援 HTML5 &lt;video&gt; 和 &lt;audio&gt; 元素，包括對 Ogg Theora 編碼影像和 Vorbis 編碼聲音的原生支援。</li>
	<li>增進您控制個人隱私資料的工具，包括私密瀏覽模式。</li>
	<li>更好的網頁應用程式效能，使用新的 TraceMonkey JavaScript 引擎。</li>
	<li>地理定位功能可以將您的地理位置資訊分享給網站。</li>
	<li>原生的 JSON 支援 和 網頁工作執行緒。</li>
	<li>Gecko 排版引擎的加強，包括預測解析以加速頁面描繪。</li>
	<li>支援新的網頁技術，例如：動態下載字型、CSS 媒體型態查詢、新的變形與屬性、JavaScript 查詢選擇器、HTML5 本地端儲存及離線應用程式儲存、&lt;canvas&gt; 文字、ICC 設定檔，以及 SVG 變形特效。</li>
</ul>
