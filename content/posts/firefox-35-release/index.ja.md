Firefox 3.5 がついに登場しました。私もすぐにダウンロードしなければ、XD。今使っているのはまだ RC 版なのです。それにしても、今回の Firefox 3.5 のアップデートで何が変わったのでしょうか？
<!--more-->
公式サイトの情報は以下のとおりです：
<ul>
	<li>70 以上の言語に対応。</li>
	<li>HTML5 の &lt;video&gt; と &lt;audio&gt; 要素をサポートし、Ogg Theora でエンコードされた映像と Vorbis でエンコードされた音声もネイティブにサポート。</li>
	<li>プライベートブラウズモードを含め、個人のプライバシーデータを管理するツールを強化。</li>
	<li>新しい TraceMonkey JavaScript エンジンにより、ウェブアプリケーションのパフォーマンスを向上。</li>
	<li>位置情報機能により、自分の位置情報をウェブサイトと共有可能。</li>
	<li>ネイティブの JSON サポートと Web Worker に対応。</li>
	<li>Gecko レイアウトエンジンを強化し、ページの描画を速める予測パースを追加。</li>
	<li>動的フォントのダウンロード、CSS メディアクエリ、新しい変形と属性、JavaScript の querySelector、HTML5 のローカルストレージとオフラインアプリケーションストレージ、&lt;canvas&gt; のテキスト、ICC プロファイル、SVG の変形エフェクトなど、新しいウェブ技術に対応。</li>
</ul>
