Firefox 3.5 is finally out, and I'm rushing to download it XD. The version I'm using right now is still just an RC. So what's different in this update?
<!--more-->
Here is the official information:
<ul>
	<li>Support for more than 70 languages.</li>
	<li>Supports the HTML5 &lt;video&gt; and &lt;audio&gt; elements, including native support for Ogg Theora-encoded video and Vorbis-encoded audio.</li>
	<li>Tools to help you control your personal privacy data, including Private Browsing mode.</li>
	<li>Better web app performance with the new TraceMonkey JavaScript engine.</li>
	<li>Geolocation lets you share your location with websites.</li>
	<li>Native JSON support and Web Workers.</li>
	<li>Improvements to the Gecko layout engine, including predictive parsing to speed up page rendering.</li>
	<li>Support for new web technologies, such as downloadable fonts, CSS media queries, new transforms and attributes, JavaScript querySelector, HTML5 local storage and offline application storage, &lt;canvas&gt; text, ICC color profiles, and SVG transform effects.</li>
</ul>
