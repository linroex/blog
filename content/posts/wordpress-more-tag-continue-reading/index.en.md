Today I'm going to teach you a handy little trick: the more tag. Anyone who has just set up WordPress has probably noticed that WordPress doesn't have a built-in feature to display only a few lines of a post, so every post shows up in full on the homepage, which makes the homepage look pretty ugly. In fact, there is a way to insert a continue reading tag, and it's built into WordPress. I have to admit, when I first started I used it as an `&lt;hr&gt;` tag XD

Let's take a look at what it does first!

Using this continue reading feature is actually very simple.

When you're writing a post, switch to the "Preview" view

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/2009-07-07_135235.jpg"><img class="alignnone size-full wp-image-1550" title="2009-07-07_135235" src="{{< param imageBase >}}/wp-content/uploads/2009/07/2009-07-07_135235.jpg" alt="2009-07-07_135235" width="278" height="144" /></a>

Then press the shortcut "Alt+Shift+T"

and you'll see a very faint line.

That's the continue reading tag.
