<a href="http://www.mediacoderhq.com/" target="_blank"><strong>MediaCoder</strong> </a>is a very handy video converter. It runs on Windows, Linux, and Mac, and it's free. But those aren't the main point. The real highlight is that it can use the GPU (graphics card) to do the conversion work. This technique is called GPGPU. With it, you're much less likely to run into the problem of CPU usage spiking past 100% and the computer crashing during conversion, and conversion is ridiculously fast. I often convert videos while playing online games, and everything runs smoothly.


<!--more-->
That said, GPGPU is only useful if your graphics card supports it. In general, if you have integrated graphics, skip this feature and just use the CPU, which is more practical. But if you have a mid-to-high-end graphics card, I strongly recommend turning it on!

So when would you use this software? For example, some people like to watch videos on an iPad or iPhone, but those devices are picky about formats. Or maybe you recorded a video and want to upload it to YouTube, but the original file is too big. In cases like these, you can convert it with MediaCoder first.

<h2>Tutorial</h2>
1. First, go to the <a href="http://www.mediacoderhq.com/download.htm" target="_blank">download page</a> and download MediaCoder. The download link is surprisingly hard to find....

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170429.jpg"><img class="alignnone size-large wp-image-5726" title="2011-08-26_170429" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170429-520x380.jpg" alt="" width="520" height="380" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170513.jpg"><img class="alignnone size-large wp-image-5727" title="2011-08-26_170513" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170513-520x446.jpg" alt="" width="520" height="446" /></a>

2. Install MediaCoder. The process is just clicking "Next" over and over....

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171357.jpg"><img class="alignnone size-full wp-image-5728" title="2011-08-26_171357" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171357.jpg" alt="" width="503" height="389" /></a>

Be careful during installation: it will ask whether you want to install the TuneUp plugin. I recommend declining.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171434.jpg"><img class="alignnone size-full wp-image-5729" title="2011-08-26_171434" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171434.jpg" alt="" width="503" height="389" /></a>

3. After installing, run it. The first time you use it, a "Welcome to MediaCoder" window appears. Check "Skip this screen on startup" and then click "Start now".

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171800.jpg"><img class="alignnone size-large wp-image-5730" title="2011-08-26_171800" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171800-520x370.jpg" alt="" width="520" height="370" /></a>

4. The default interface is English, so you need to switch it to Chinese manually. Click "Options" -> "Use Interface Language" in that order, then select Traditional Chinese.

P.S. Actually, I thought it only had an English interface until I read <a href="http://www.freegroup.org/2011/05/mediacoder/" target="_blank">Pseric</a>'s article and found out there was a Chinese version....

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172359.jpg"><img class="alignnone size-large wp-image-5731" title="2011-08-26_172359" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172359-520x488.jpg" alt="" width="520" height="488" /></a>

You need to restart the program after making this change for the interface to show up in Chinese.

5. Now you can start converting. Click "File" to add the files you want to convert. You can add many at once, or add an entire folder. You can even give it a video URL, and it will download and convert the video for you XD

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172723.jpg"><img class="alignnone size-large wp-image-5732" title="2011-08-26_172723" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172723-520x488.jpg" alt="" width="520" height="488" /></a>

After adding your files, set where the output files will be saved. By default they go to the same location as the input files, but I recommend setting up a dedicated folder, which is more convenient.

"File" -> "Set Output Folder"

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172908.jpg"><img class="alignnone size-large wp-image-5733" title="2011-08-26_172908" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172908-520x488.jpg" alt="" width="520" height="488" /></a>

After setting the output folder, select "Video" in the lower-left corner and check "GPU". This will turn on GPGPU computing and automatically choose the decoder you need.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173220.jpg"><img class="alignnone size-large wp-image-5734" title="2011-08-26_173220" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173220-520x488.jpg" alt="" width="520" height="488" /></a>

Press F5, or go to "Job" -> "Start Conversion," to begin converting.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173905.jpg"><img class="alignnone size-large wp-image-5735" title="2011-08-26_173905" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173905-520x488.jpg" alt="" width="520" height="488" /></a>

6. The GPU temperature shoots up during conversion XDD

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_174243.jpg"><img class="alignnone size-large wp-image-5736" title="2011-08-26_174243" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_174243-381x500.jpg" alt="" width="381" height="500" /></a>

In my testing, the compression ratio with GPU computing seemed to be somewhat worse.
<h2>Thoughts</h2>
MediaCoder really is a great program. I think many people have been through the same experience: the computer ends up with a pile of conversion programs installed, because some of them only support a handful of formats, or they're so slow that you end up fuming. I've been through that too, which is why I hate converting video XDD But MediaCoder was like a rainbow after the storm!! It supports a lot of formats, and at least every format I use is covered! Conversion is also fast to an absurd degree. The most amazing part is that even while the CPU is at 100% during conversion, the computer can still do other things without stuttering. <del>Though... I'm not sure whether that's because my computer is powerful or because the program is great...</del> (Kidding aside, MediaCoder is really great. Even my mom's laptop can convert videos smoothly now.)
