<a href="http://www.mediacoderhq.com/" target="_blank"><strong>MediaCoder</strong> </a>は、とても使いやすい動画変換ソフトです。Windows、Linux、Mac で動作し、しかも無料です。ただ、これらは本題ではありません。重要なのは、GPU（グラフィックボード）を使って変換作業ができることです。この技術は GPGPU と呼ばれています。この技術を使えば、変換中に CPU 使用率が100%を超えてパソコンがフリーズする、といった問題に遭いにくくなります。しかも変換速度は驚くほど速いです。私はよく動画を変換しながらオンラインゲームをしていますが、どちらもスムーズに動いています。


<!--more-->
ただし、GPGPU は便利なものの、お使いのグラフィックボードが対応しているかどうかによります。一般的には、内蔵 GPU（内顯）の場合はこの機能をオフにして CPU で変換するほうが現実的です。一方、中〜高性能のグラフィックボードなら、ぜひこの機能をオンにすることを強くおすすめします！

では、このソフトはどんなときに使うのでしょうか。たとえば、iPad や iPhone で動画を見たい人がいますが、こうした機器は対応する形式が限られています。また、動画を撮影して YouTube にアップロードしたいのに、元のファイルが大きすぎる、ということもあるでしょう。そんなときは、まず MediaCoder で変換すればよいのです。

<h2>使い方</h2>
1. まず、<a href="http://www.mediacoderhq.com/download.htm" target="_blank">ダウンロードページ</a>から MediaCoder をダウンロードします。ダウンロードリンクはなかなか見つけにくいのです……。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170429.jpg"><img class="alignnone size-large wp-image-5726" title="2011-08-26_170429" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170429-520x380.jpg" alt="" width="520" height="380" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170513.jpg"><img class="alignnone size-large wp-image-5727" title="2011-08-26_170513" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_170513-520x446.jpg" alt="" width="520" height="446" /></a>

2. MediaCoder をインストールします。手順は「Next」を押し続けるだけです……。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171357.jpg"><img class="alignnone size-full wp-image-5728" title="2011-08-26_171357" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171357.jpg" alt="" width="503" height="389" /></a>

インストール中、TuneUp というプラグインをインストールするか聞かれます。インストールしないことをおすすめします。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171434.jpg"><img class="alignnone size-full wp-image-5729" title="2011-08-26_171434" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171434.jpg" alt="" width="503" height="389" /></a>

3. インストールが終わったら起動します。初めて使うと「Welcome to MediaCoder」というウィンドウが表示されます。「Skip this screen on startup」にチェックを入れ、「Start now」をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171800.jpg"><img class="alignnone size-large wp-image-5730" title="2011-08-26_171800" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_171800-520x370.jpg" alt="" width="520" height="370" /></a>

4. 初期設定の画面は英語なので、手動で中国語に切り替える必要があります。「Options」→「Use Interface Language」の順にクリックし、繁体字中国語を選択します。

P.S. 実は私も、英語の画面しかないと思い込んでいました。<a href="http://www.freegroup.org/2011/05/mediacoder/" target="_blank">Pseric</a> さんの記事を読んで、中国語版があると知ったのです……。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172359.jpg"><img class="alignnone size-large wp-image-5731" title="2011-08-26_172359" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172359-520x488.jpg" alt="" width="520" height="488" /></a>

設定したあとは、プログラムを再起動すると中国語で表示されます。

5. ここまで来たら、変換を始められます。「File」をクリックして変換したいファイルを追加します。一度にたくさん追加することも、フォルダごと追加することもできます。さらに、動画の URL を渡せばダウンロードと変換までまとめて行ってくれます XD

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172723.jpg"><img class="alignnone size-large wp-image-5732" title="2011-08-26_172723" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172723-520x488.jpg" alt="" width="520" height="488" /></a>

ファイルを追加したら、出力先を設定します。初期設定では入力ファイルと同じ場所に保存されますが、専用のフォルダを指定しておくと便利でおすすめです。

「File」→「Set Output Folder」

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172908.jpg"><img class="alignnone size-large wp-image-5733" title="2011-08-26_172908" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_172908-520x488.jpg" alt="" width="520" height="488" /></a>

出力フォルダを設定したら、左下の「Video」を選んで「GPU」にチェックを入れます。これで GPGPU による計算が有効になり、必要なデコーダーが自動的に選ばれます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173220.jpg"><img class="alignnone size-large wp-image-5734" title="2011-08-26_173220" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173220-520x488.jpg" alt="" width="520" height="488" /></a>

F5 キーを押すか、「Job」→「Start Conversion」を選ぶと変換が始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173905.jpg"><img class="alignnone size-large wp-image-5735" title="2011-08-26_173905" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_173905-520x488.jpg" alt="" width="520" height="488" /></a>

6. 変換中、GPU の温度がぐんぐん上がります XDD

<a href="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_174243.jpg"><img class="alignnone size-large wp-image-5736" title="2011-08-26_174243" src="{{< param imageBase >}}/wp-content/uploads/2011/08/2011-08-26_174243-381x500.jpg" alt="" width="381" height="500" /></a>

実際に試したところ、GPU による計算では圧縮率がやや落ちるようでした。
<h2>感想</h2>
MediaCoder は本当に素晴らしいソフトです。多くの人が同じ経験をしているのではないでしょうか。パソコンに変換ソフトをいくつもインストールしてしまう、という経験です。対応している形式が少なかったり、変換がとても遅くてイライラしたりするからです。私も同じ経験をしたので、動画の変換は大嫌いでした XDD ところが MediaCoder は、まるで嵐のあとの虹のように見えたのです！！ 多くの形式に対応していて、少なくとも私がよく使う形式はすべてカバーしています！ しかも変換速度は非現実的なほど速いです。いちばん驚いたのは、変換中に CPU 使用率が100%になっているのに、ほかの作業も同時にでき、もたつかないことです。<del>ただ……これは私のパソコンの性能が良いからなのか、ソフトが優秀だからなのか、よくわかりません……</del>（冗談はさておき、MediaCoder は本当に優れています。うちの母のノートパソコンでも、今ではすいすい動画を変換できるようになりました。）
