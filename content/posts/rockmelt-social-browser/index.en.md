Besides the browsers we all know, like Opera, IE, Firefox, and Chrome, there's a group of less famous browsers that use one of the four browsers mentioned earlier as their core, then improve the interface or features on their own. For example:
TheWorld Browser and today's RockMelt both belong to this category.

Today's RockMelt is a social browser built on the Chromium core. You can think of Chromium as basically Chrome, with no big difference between them. What sets RockMelt apart is that it's a social browser: it's integrated with Facebook and Twitter, so you can use those two social tools right inside the browser. Because it's built on Chromium, it has almost all of Chrome's features too. For example, extensions and themes work. However, RockMelt doesn't support sync, which is a major shortcoming.


<!--more-->
RockMelt is still in beta, so you need an invitation to use it. It also has to be linked to a Facebook account, so even if you download the installer directly, you can't use RockMelt. Below I'll give a brief introduction to this browser. If you've received an invitation, come take a look. If you haven't, you can still look at the pictures to satisfy your curiosity XD.

<h2>Conclusion</h2>
If RockMelt could combine Plurk, instant messaging, and Skype, I think my whole life would move onto it. As it stands, it's already quite good, though it has some small bugs. For example, clicking the extensions button makes the window flicker constantly, and there are also problems when you click on RSS sites. I think these will be fixed in the next version. I find RockMelt quite useful, and I'm looking forward to more new features in the next version (hoping for instant messaging...)
