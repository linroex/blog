Ubuntu 9.04 のこのアップデートは、Windows 7 を強く意識したものに見えます。Windows 7 が登場してまもないうちに Ubuntu が更新され、多くの機能が Windows 7 によく似ていて、それ以上かもしれません！！ Ubuntu に対応するプログラムが少なければ、今ごろいちばん有名な OS になっていたかもしれません~~

Ubuntu を簡単に紹介すると、Linux 系の OS で、ソースコードが公開されているため、自分で中身を変更できます。さらに無料で、安定性は Windows シリーズを大きく上回ります。Ubuntu では一度でもクラッシュを見るのは稀です XD ただし、市場で Ubuntu に対応しているプログラムは少なく、特にゲームはほとんどありません。そのため Ubuntu は Windows のように大量のユーザーを集めることができていません。一方で、Ubuntu は約半年ごとに新バージョンが出るため、更新は速いです。また今回の Ubuntu 9.0.4 では、W7 に負けない魅力的なインターフェースが加わりました！！

注：Kgame さんのご指摘に感謝します。実は Ubuntu の視覚効果は、標準搭載ではなく GNOME をインストールしたことによるものです。
<h2><strong>Ubuntu の特徴</strong></h2>
<ol>
	<li>無料</li>
	<li>多言語対応（繁体字中国語を含む）</li>
	<li>6 か月ごとに新バージョンをリリース</li>
	<li>よく使われる無料ソフトを内蔵（OpenOffice など）</li>
	<li>64 ビットのコンピューターに対応</li>
	<li>Live 機能あり（CD に焼けば、インストールせずにそのまま使える）</li>
	<li>仮想デスクトップを 4 つ内蔵</li>
	<li>W7 に匹敵するインターフェース</li>
</ol>

<h2><strong>Ubuntu のダウンロード手順</strong></h2>
1.<a href="http://www.ubuntu-tw.org/modules/tinyd0/index.php?id=7">ダウンロードページ</a>にアクセスします。

2.バージョンの選択で「<strong>Ubuntu 9.04 <span class="version" style="display: none;">デスクトップ版</span>（最新版）</strong>」を選びます。ダウンロードのミラーは近いものを適当に選んでください :)

3.「ダウンロードを開始」をクリックします

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_194209.jpg"><img class="alignnone size-full wp-image-1150" title="2009-05-27_194209" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_194209.jpg" alt="2009-05-27_194209" width="695" height="365" /></a>

また、お使いのコンピューターが 64 ビットの場合は、ページを下にスクロールすると自動選択のオプションがあるので、64bit にチェックを入れてからダウンロードをクリックしてください～～～～

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_194611.jpg"><img class="alignnone size-full wp-image-1151" title="2009-05-27_194611" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_194611.jpg" alt="2009-05-27_194611" width="401" height="154" /></a>

ダウンロードできたら、CD に焼き込むだけです。
<h2>Ubuntu のインストール手順</h2>
1.BIOS を CD から起動するように設定します。設定方法が分からない方は、この記事を参照してください：<a href="https://coder.tw/?p=2290">[BIOS を CD から起動するには？（再インストールに必須）]</a>

2.キーボードの矢印キーで【中文（繁體）】（繁体字中国語）を選び、Enter を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201648.jpg"><img title="2010-01-18_201648" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201648-469x400.jpg" alt="" width="469" height="400" /></a>

3.数秒待つと画面が中国語に切り替わります。切り替わったら、もう一度矢印キーで【Ubuntu のインストール】を選びます。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201821.jpg"><img title="2010-01-18_201821" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201821-467x400.jpg" alt="" width="467" height="400" /></a>
<img title="次のページ…" src="https://coder.tw/wp-includes/js/tinymce/plugins/wordpress/img/trans.gif" alt="" />

4.Ubuntu がインストールに必要なファイルを読み込んでいます。少々お待ちください。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202031.jpg"><img title="2010-01-18_202031" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202031-467x400.jpg" alt="" width="467" height="400" /></a>

5.読み込みが終わると、インストールを始められます。まず、ここで言語を設定します。【中文（繁體）】を選び、【次へ】をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202253.jpg"><img title="2010-01-18_202253" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202253-473x400.jpg" alt="" width="473" height="400" /></a>

6.タイムゾーンを設定します。通常はデフォルトのままで問題ありません。設定できたら【次へ】をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202436.jpg"><img title="2010-01-18_202436" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202436-479x400.jpg" alt="" width="479" height="400" /></a>

<!--nextpage-->

7.キーボードのレイアウトを設定します。台湾の場合は通常【USA→USA】です。デフォルトのまま【次へ】をクリックしてください。【USA→USA】かどうか不安な場合は、下の入力欄で実際にキーを押して、表示される文字と一致するか確認してください。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202841.jpg"><img title="2010-01-18_202841" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202841-479x400.jpg" alt="" width="479" height="400" /></a>

8.ディスクのパーティション分割ツールを起動中です。ほかの操作はしないでください。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203014.jpg"><img title="2010-01-18_203014" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203014-479x400.jpg" alt="" width="479" height="400" /></a>

9.Ubuntu をインストールするパーティションを選びます。ハードディスクが 1 台だけならそれを選びます。2 台ある場合は注意してください。現在の OS があるディスクにインストールすると、既存の OS が消去される可能性があります。初心者には【ディスク全体を消去して使用する】を選んで【次へ】をクリックすることをおすすめします。最もトラブルが起きにくい方法です。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203201.jpg"><img title="2010-01-18_203201" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203201-479x400.jpg" alt="" width="479" height="400" /></a>

10.プログラムを読み込み中です.....

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203257.jpg"><img title="2010-01-18_203257" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203257-479x400.jpg" alt="" width="479" height="400" /></a>

11.ここではいくつかの情報を入力します。名前は英字でのみ入力してください。また、パスワードも必ず設定してください。入力しないと Ubuntu はこの段階を先に進めてくれません ^^ パスワードを設定したあとで忘れるのが心配な方もいるかもしれませんが、かといって設定しないわけにもいきません。その場合は、下の【自動ログイン】にチェックを入れると、ログイン時にパスワードを入力しなくて済みます。

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203438.jpg"><img title="2010-01-18_203438" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203438-479x400.jpg" alt="" width="479" height="400" /></a>

12.ここでシステムが、入力された情報に誤りがないか確認します。問題がなければ【インストール】をクリックしてください。

<h3>まとめ：</h3>
実は、私が <a href="http://www.ubuntu.com/">Ubuntu</a> と出会ったのは、家のパソコンが一度壊れたのがきっかけでした。母が「直せたらパソコンをあげる」と言ったのです（後で分かったのですが、それは騙しでした = =）。そこで真剣にパソコンに何が起きたのかを調べたところ、再インストールが必要だと分かりました。しかし、Windows XP は有料の OS で、学生で貧乏だった私にはとても買えません（ただの貧乏学生だったので XD）。さらに、家のネット回線ではダウンロードも遅すぎました（当時のダウンロード速度は 56KB...）。そこで最終的に、無料の OS である <a href="http://www.ubuntu.com/">Ubuntu</a> を使うことにしました。Linux は今後の流れなので、早めに覚えておくのも悪くないと考えたのです。それに、当時 <a href="http://www.ubuntu.com/">Ubuntu</a> を試したことには、もうひとつ良い点がありました。ゲーム好きの習慣を改めることができたのです。Ubuntu では大半のゲームが動かないからです。
