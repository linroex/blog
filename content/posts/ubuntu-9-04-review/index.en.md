Ubuntu 9.04 looks like this update is aimed squarely at Windows 7. Ubuntu was updated not long after Windows 7 came out, and many of its features are very similar to Windows 7, maybe even better!! If not for the small number of programs that support Ubuntu, it might be the most famous operating system by now~~

A quick introduction to Ubuntu: it's a Linux operating system, which means its source code is public, so you can modify its contents yourself. It's also free, and its stability far exceeds the Windows family. On Ubuntu, seeing a crash even once is rare XD However, few programs on the market support Ubuntu, especially games. There are almost no games that support Ubuntu, so Ubuntu hasn't been able to attract a huge user base like Windows does. Also, Ubuntu releases a new version about every six months, so its updates come quickly. And this Ubuntu 9.0.4 release adds a rather attractive interface that can compete with W7!!

Note: Thanks to Kgame for the correction. In fact, Ubuntu's visual effects come from installing GNOME, not from the base system.
<h2><strong>Ubuntu Features</strong></h2>
<ol>
	<li>Free</li>
	<li>Multiple languages (including Traditional Chinese)</li>
	<li>A new version every 6 months</li>
	<li>Includes common free software (OpenOffice, etc.)</li>
	<li>Supports 64-bit computers</li>
	<li>Live mode (just burn it to a CD and you can use it without installing)</li>
	<li>Four built-in virtual desktops</li>
	<li>An interface that rivals W7</li>
</ol>

<h2><strong>Ubuntu Download Guide</strong></h2>
1. Go to the <a href="http://www.ubuntu-tw.org/modules/tinyd0/index.php?id=7">download page</a>.

2. For the version, select "<strong>Ubuntu 9.04 <span class="version" style="display: none;">Desktop Edition</span> (latest version)</strong>". Pick any download mirror nearby :)

3. Click "Start download"

Also, if your computer is 64-bit, scroll down the page to the automatic options, check 64bit, and then click download~~~~

Once it's downloaded, just burn it to a CD.
<h2>Ubuntu Installation Guide</h2>
1. Set the BIOS to boot from CD. If you're not sure how, see this article: <a href="https://coder.tw/?p=2290">[How to set the BIOS to boot from CD? (essential for reinstalling a computer)]</a>

2. Use the arrow keys to select Traditional Chinese, then press Enter.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201648.jpg"><img title="2010-01-18_201648" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201648-469x400.jpg" alt="" width="469" height="400" /></a>

3. Wait a few seconds for the interface to switch to Chinese. Once it does, use the arrow keys again to select [Install Ubuntu].

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201821.jpg"><img title="2010-01-18_201821" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_201821-467x400.jpg" alt="" width="467" height="400" /></a>
<img title="Next page…" src="https://coder.tw/wp-includes/js/tinymce/plugins/wordpress/img/trans.gif" alt="" />

4. Ubuntu is loading the files needed for installation. Please wait a moment.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202031.jpg"><img title="2010-01-18_202031" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202031-467x400.jpg" alt="" width="467" height="400" /></a>

5. Once loading is done, you can start the installation. First, this is where you set the language. Select Traditional Chinese, then click [Forward].

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202253.jpg"><img title="2010-01-18_202253" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202253-473x400.jpg" alt="" width="473" height="400" /></a>

6. Set your time zone. The default is usually fine. When you're done, click [Forward].

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202436.jpg"><img title="2010-01-18_202436" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202436-479x400.jpg" alt="" width="479" height="400" /></a>

7. Set the keyboard layout. Keyboards in Taiwan are usually [USA→USA], so keep the default and click [Forward]. If you're not sure your layout is [USA→USA], test it in the box below by checking whether the keys you press match the characters that appear.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202841.jpg"><img title="2010-01-18_202841" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_202841-479x400.jpg" alt="" width="479" height="400" /></a>

8. The disk partitioning tool is opening. Don't press anything else.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203014.jpg"><img title="2010-01-18_203014" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203014-479x400.jpg" alt="" width="479" height="400" /></a>

9. Choose the partition where you want to install Ubuntu. If you have only one hard drive, install to that one. If you have two, be careful: if you install onto the drive that holds your current operating system, that system may be erased. I recommend beginners select [Erase and use the entire disk] and click [Forward], which is the least likely to cause problems.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203201.jpg"><img title="2010-01-18_203201" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203201-479x400.jpg" alt="" width="479" height="400" /></a>

10. Loading the program.....

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203257.jpg"><img title="2010-01-18_203257" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-18_203257-479x400.jpg" alt="" width="479" height="400" /></a>

11. Enter some information here. Note that the name must be in English, and you must set a password. Ubuntu won't let you past this step without one ^^ Some people worry about forgetting the password after setting it, but you can't skip it either. In that case, check [Log in automatically] below, and you won't need to type the password to log in.

A password that's too weak won't work either ▼▼

<h3>Wrap-up:</h3>
The truth is, I first got to know <a href="http://www.ubuntu.com/">Ubuntu</a> because our home computer broke down once. My mom said that if I could fix it, she'd give me the computer (I later found out it was a scam = =). So I seriously looked into what had happened to the computer, and found that it needed to be reinstalled. But everyone knows Windows XP is paid software, and there was no way I could afford it (I was just a poor student XD). Downloading it over our home internet was too slow too (back then, download speeds were 56KB...). So in the end I decided to use <a href="http://www.ubuntu.com/">Ubuntu</a>, a free operating system. Anyway, Linux is the trend of the future, so learning it early was no bad thing. Another benefit of trying <a href="http://www.ubuntu.com/">Ubuntu</a> at the time was that it cured my habit of playing games, because most games don't run on Ubuntu.
