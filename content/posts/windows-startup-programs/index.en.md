Plenty of computer experts will tell you not to set too many startup programs, because it makes the computer slow. That may have been true in the past, but with today's much more powerful hardware, having a few programs launch at startup is actually convenient. Just don't go overboard. It depends on your hardware XD

In this post, I want to show everyone how to add programs to startup on Windows XP. It's really simple. Just follow the pictures below and you'll definitely get it :)


<!--more-->


1. Click Start - All Programs - Startup.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185437.jpg"><img class="alignnone size-full wp-image-1248" title="2009-06-09_185437" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185437.jpg" alt="2009-06-09_185437" width="408" height="629" /></a>

2. Right-click the Startup entry and select "Open."

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185459.jpg"><img class="alignnone size-full wp-image-1249" title="2009-06-09_185459" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185459.jpg" alt="2009-06-09_185459" width="242" height="370" /></a>

3. Drag every program you want to run automatically at startup into that folder.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185740.jpg"><img class="alignnone size-full wp-image-1250" title="2009-06-09_185740" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_185740.jpg" alt="2009-06-09_185740" width="640" height="480" /></a>

That's it! Now restart your computer and see whether the programs you put in the folder launch automatically. One more thing, my dear readers: it's best not to drag the main program file itself into the folder. Instead, create a shortcut to the program and drag the shortcut in.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_190029.jpg"><img class="alignnone size-full wp-image-1251" title="2009-06-09_190029" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-09_190029.jpg" alt="2009-06-09_190029" width="115" height="245" /></a>← Right-click the file you want to make a shortcut for and select "Create Shortcut."
