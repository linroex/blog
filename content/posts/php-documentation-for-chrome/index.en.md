PHP is a fairly easy language to learn. It isn't difficult in itself, and there are plenty of resources for it. In particular, the official PHP website provides a reference of PHP functions, where you can look up any PHP function. It's quite similar to Microsoft's MSDN. Today I want to introduce a Chrome extension that puts the search feature of the official PHP docs into your browser, so you can look up PHP functions more conveniently~


<!--more-->

<h2>PHP for Chrome Extension Info</h2>
<ul>
	<li>Name: PHP documentation - PHP.net</li>
	<li>Author: www.wixiweb.fr</li>
	<li>Download page: <a href="http://goo.gl/YK0Hf">http://goo.gl/YK0Hf</a></li>
	<li>Platform: Google Chrome</li>
</ul>
<h2>Tutorial</h2>
1. Go to the download page and install the extension.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_110843.jpg"><img class="alignnone size-large wp-image-523" title="2011-05-29_110843" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_110843-540x406.jpg" alt="" width="540" height="406" /></a>

2. After installing, click the PHP button in the upper-right corner of the browser and enter the keyword of the function you're looking for.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_111218.jpg"><img class="alignnone size-large wp-image-524" title="2011-05-29_111218" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_111218-540x405.jpg" alt="" width="540" height="405" /></a>

It will show suggested options.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_111545.jpg"><img class="alignnone size-large wp-image-525" title="2011-05-29_111545" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_111545-540x406.jpg" alt="" width="540" height="406" /></a>

3. Press Search, and it will open the detailed documentation on PHP.net for you~
