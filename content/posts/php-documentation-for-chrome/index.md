PHP其實是一個蠻好學習的語言，除了因為他本身就不難以外，還有他的資源其實也是很多的，尤其是PHP官方網站還有提供一份PHP函式文件，你可以去官網查詢任何PHP的函式，就很類似微軟的MSDN，今天要跟大家介紹一個Chrome外掛，他把PHP官網的文件搜尋功能做成了外掛，讓你可以更方便的查詢PHP Function～

<!--more-->

<h2>PHP for Chrome外掛資訊</h2>
<ul>
	<li>程式名稱：PHP documentation - PHP.net</li>
	<li>作者：www.wixiweb.fr</li>
	<li>下載頁面：<a href="http://goo.gl/YK0Hf">http://goo.gl/YK0Hf</a></li>
	<li>適用平台：Google Chrome</li>
</ul>
<h2>使用教學</h2>
1.到下載頁面將此外掛安裝好

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_110843.jpg"><img class="alignnone size-large wp-image-523" title="2011-05-29_110843" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-29_110843-540x406.jpg" alt="" width="540" height="406" /></a>

2.安裝好之後，按一下瀏覽器右上角的PHP按鈕，然後輸入你要找的函式關鍵字
