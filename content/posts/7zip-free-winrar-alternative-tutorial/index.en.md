Still paying for the expensive WinRAR? Don't be silly! 7-Zip is your best choice. 7-Zip is a compression and decompression program that supports its own distinctive 7z archive format. On top of that, it also supports the various formats WinRAR supports. And best of all, 7-Zip is free! 7-Zip also supports Traditional Chinese, so you don't need to worry about not understanding English.

<h2>Features of 7-Zip</h2>
<ul>
	<li>Supports Unicode file names (you can still extract files even if the file names are garbled)</li>
	<li>Very small, only 840KB.</li>
	<li>7-Zip can compress files into: ZIP, 7z, GZIP, BZIP2 and TAR.</li>
	<li>7-Zip can extract these formats: <strong>ZIP</strong>, <strong>RAR</strong>, CAB, <strong>ISO</strong>, ARJ, LZH, CHM, WIM, Z, CPIO, RPM, DEB and NSIS.</li>
</ul>
<h2 style="font-size: 1.5em;">Part 1. Installing 7-Zip</h2>
1. Open the installer. If a security warning appears, just click Run.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223513.jpg"><img class="alignnone size-full wp-image-2073" title="2009-10-18_223513" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223513.jpg" alt="2009-10-18_223513" width="386" height="348" /></a>

2. Set the installation location. I usually keep the default and let it detect the location automatically. Unless you have special needs, just click Install.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223730.jpg"><img class="alignnone size-full wp-image-2074" title="2009-10-18_223730" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223730.jpg" alt="2009-10-18_223730" width="402" height="314" /></a>

3. The installation will start now. When the screen below appears, the installation is complete. Click Finish.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224128.jpg"><img class="alignnone size-full wp-image-2075" title="2009-10-18_224128" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224128.jpg" alt="2009-10-18_224128" width="402" height="314" /></a>
<h2>Part 2. Compressing Files</h2>
1. Select the files you want to compress, right-click them, and choose 7-Zip → Add to archive...

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224524.jpg"><img class="alignnone size-full wp-image-2076" title="2009-10-18_224524" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224524.jpg" alt="2009-10-18_224524" width="447" height="432" /></a>

2. A window for adding to an archive will pop up. In the "..." field you can choose where to save the archive, and the archive format menu lets you pick the compression method. Basically, if the other person has 7-Zip installed, use the 7z format. Otherwise, I recommend zip, because every extraction program can open zip files.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224827.jpg"><img class="alignnone size-full wp-image-2077" title="2009-10-18_224827" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224827.jpg" alt="2009-10-18_224827" width="439" height="386" /></a>

3. You can also set a password, so only people who know it can open the file. The "Encrypt file names" option controls whether people without the password can see the original file names. If you check it, the file names will be hidden. For the encryption method, just pick any option. Those are cryptography details we don't need to worry about XD

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225052.jpg"><img class="alignnone size-full wp-image-2078" title="2009-10-18_225052" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225052.jpg" alt="2009-10-18_225052" width="439" height="385" /></a>

4. For the other settings, adjust them to your needs! Once you're done, click OK and compression will start.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225227.jpg"><img class="alignnone size-full wp-image-2079" title="2009-10-18_225227" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225227.jpg" alt="2009-10-18_225227" width="439" height="385" /></a>

<h2>Part 3. Extracting Files</h2>
The previous part covered compressing files with 7-Zip. This part shows you how to extract files. First, right-click the file you want to extract, then choose 【7-Zip】 → 【Extract Here】.
