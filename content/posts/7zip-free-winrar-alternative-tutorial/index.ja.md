<h2>7-Zip の特徴</h2>
<ul>
	<li>Unicode のファイル名に対応（ファイル名が文字化けしていても解凍できます）</li>
	<li>ファイルサイズが非常に小さく、わずか 840KB です。</li>
	<li>7-Zip で圧縮できる形式: ZIP、7z、GZIP、BZIP2、TAR。</li>
	<li>7-Zip で解凍できる形式: <strong>ZIP</strong>、<strong>RAR</strong>、CAB、<strong>ISO</strong>、ARJ、LZH、CHM、WIM、Z、CPIO、RPM、DEB、NSIS。</li>
</ul>
<h2 style="font-size: 1.5em;">一. 7-Zip のインストール手順</h2>
1. インストーラーを開きます。セキュリティの警告が出たら「実行」をクリックしてください。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223513.jpg"><img class="alignnone size-full wp-image-2073" title="2009-10-18_223513" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223513.jpg" alt="2009-10-18_223513" width="386" height="348" /></a>

2. インストール先を設定します。私はいつも初期設定のままにして、自動で検出させています。特別な事情がなければ、そのまま Install を押せば大丈夫です。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223730.jpg"><img class="alignnone size-full wp-image-2074" title="2009-10-18_223730" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_223730.jpg" alt="2009-10-18_223730" width="402" height="314" /></a>

3. インストールが始まります。下の画面が表示されたらインストール完了です。Finish を押してください。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224128.jpg"><img class="alignnone size-full wp-image-2075" title="2009-10-18_224128" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224128.jpg" alt="2009-10-18_224128" width="402" height="314" /></a>
<h2>二. ファイルの圧縮</h2>
1. 圧縮したいファイルを選び、右クリックして「7-Zip → 圧縮ファイルに追加...」を選びます。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224524.jpg"><img class="alignnone size-full wp-image-2076" title="2009-10-18_224524" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224524.jpg" alt="2009-10-18_224524" width="447" height="432" /></a>

2. 「圧縮ファイルに追加」のウィンドウが開きます。「...」の欄で圧縮ファイルの保存先を選べ、圧縮形式のメニューで圧縮方式を選べます。基本的には、相手が 7-Zip を入れている場合は 7z 形式を使い、そうでなければ zip をおすすめします。zip はどの解凍ソフトでも開けるからです。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224827.jpg"><img class="alignnone size-full wp-image-2077" title="2009-10-18_224827" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_224827.jpg" alt="2009-10-18_224827" width="439" height="386" /></a>

3. パスワードを設定すると、パスワードを知っている人だけがファイルを開けるようになります。「ファイル名を暗号化」は、パスワードを知らない人に元のファイル名を見せるかどうかの設定です。チェックを入れると、ファイル名は表示されなくなります。暗号化方式はどれを選んでも構いません。暗号理論の細かい話なので、気にしなくて大丈夫です XD

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225052.jpg"><img class="alignnone size-full wp-image-2078" title="2009-10-18_225052" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225052.jpg" alt="2009-10-18_225052" width="439" height="385" /></a>

4. そのほかの設定は、用途に合わせて変更してください！ 設定が終わったら OK を押すと、圧縮が始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225227.jpg"><img class="alignnone size-full wp-image-2079" title="2009-10-18_225227" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225227.jpg" alt="2009-10-18_225227" width="439" height="385" /></a>

5. 圧縮中と圧縮完了後の画面

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225243.jpg"><img class="alignnone size-medium wp-image-2080" title="2009-10-18_225243" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225243-300x138.jpg" alt="2009-10-18_225243" width="300" height="138" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225348.jpg"><img class="alignnone size-full wp-image-2081" title="2009-10-18_225348" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-18_225348.jpg" alt="2009-10-18_225348" width="104" height="87" /></a>

設定画面を使いたくない場合は、ファイルを右クリックして「7-Zip → "xxxxx.7z" に追加」または「"xxxxx.zip" に追加」を選べば、すぐに圧縮ファイルを作れます。
