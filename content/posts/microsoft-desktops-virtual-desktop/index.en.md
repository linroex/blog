<strong>Desktops</strong> is a very practical <strong><span style="color: #ff0000;">virtual desktop</span></strong> program. It was developed by Microsoft, so you don't need to worry too much about compatibility. Personally, I really like using Desktops, because <strong>Desktops</strong> can open up to 4 windows at once, and the computer doesn't slow down much. That means you can quietly write a report while chatting on instant messaging! Also, <strong>Desktops</strong> doesn't need to be installed, so you can put it on a USB flash drive and use it anywhere.

Update (12/12): Lately, something called a <span style="color: #ff0000;"><strong>boss key</strong></span> has become very popular. Desktops can also work as a <span style="color: #ff0000;"><strong>boss key</strong></span> program. A boss key is a shortcut that hides whatever you shouldn't let your boss see when he walks over to check on your work. So <strong>Desktop</strong>s is also a great fit as a <strong><span style="color: #ff0000;">boss key</span></strong>.

<blockquote>You might not know what a virtual desktop is. Simply put, multiple desktops let you open several desktops on the same computer. The principle is that it just adds a few more explorer.exe processes. Since explorer.exe handles desktop-related information, all you have to do is control explorer.exe to add more desktops. Still don't understand? Then download <strong>Desktops</strong> and give it a try!</blockquote>

<h2>Tutorial</h2>
<span style="color: #000000;">To use</span> Desktops v1.0, the first step is of course to download it. Got it downloaded? Then let Tingfeng walk you through using Desktops!

1. Open the Desktops main program.

2. Click Agree.

<a href="{{< param imageBase >}}/wp-content/uploads/2008/12/2009-06-27-13.jpg"><img class="alignnone size-full wp-image-1463" title="2009-06-27-13" src="{{< param imageBase >}}/wp-content/uploads/2008/12/2009-06-27-13.jpg" alt="2009-06-27-13" width="474" height="325" /></a>

3. Choose the keyboard shortcut for switching windows, then click OK.

My shortcut: Control with F1, F2, F3, F4

<a href="{{< param imageBase >}}/wp-content/uploads/2008/12/2009-06-27-14.jpg"><img class="alignnone size-full wp-image-1464" title="2009-06-27-14" src="{{< param imageBase >}}/wp-content/uploads/2008/12/2009-06-27-14.jpg" alt="2009-06-27-14" width="380" height="290" /></a>

4. The program will then hide in the lower-right corner. Now you can switch windows by pressing the shortcut keys you set. For example, to switch to the first window, press Ctrl+F1.
