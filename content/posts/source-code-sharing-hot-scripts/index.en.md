&nbsp;When you're writing code, you often need to look for source code to use as a reference, right?<br/>
Here's a website that is said to be the largest source code sharing site in the world.<br/>
I don't think it's really the largest, but it's definitely among the top two :)<br/>
URL: http://www.hotscripts.com/<br/>
<br/>
When you enter this website, you'll see the category page.<br/>
The categories are organized by programming language.<br/>
The main ones are PHP, CGI, ASP, Perl, Java Scripts<br/>
.AJAX, C & C++, Ruby On Rails (RoR), Python, and so on, with source code for each.<br/>
You can pick the language you want to use and then browse through it slowly.<br/>
Or you can use the search function in the upper-right corner.<br/>
But don't type Chinese.<br/>
Because this is a foreign website, there isn't much Chinese code.<br/>
You can also search within certain categories,<br/>
or search everything (the one that says All...........).<br/>
Just select it from the dropdown menu in the search box.<br/>
