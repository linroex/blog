&nbsp;相信各位在寫程式時都常需要去找尋原始碼來參考吧<br/>
這裡介紹一個網站,據聞是全世界最大的原始碼分享網站<br/>
我想應該沒有最大啦,不過數一數二倒是真的:)<br/>
網址http://www.hotscripts.com/<br/>
<br/>
這個網站一進去你就會看到他的分類頁面<br/>
是依程式語言做分類<br/>
主要有PHP, CGI,  ASP, Perl, Java Scripts<br/>
.AJAX, C & C++, Ruby On Rails(RoR), Python 等等的程式原碼<br/>
你可以選一個擬再用的語言然後再進去慢慢找<br/>
或是利用右上角的搜尋功能找<br/>
不過可別打中文阿<br/>
因為這是外國的網站,所以中文的程式也很少<br/>
還有它可以針對某些分類做搜尋<br/>
或全部搜尋(All...........的那個)<br/>
在搜尋器的下拉式選單選擇即可<br/>
