Like many people, I'm used to handling documents and reports in Google Docs, and over time it piles up a lot of material. So what if one day you want to back up all your Google Docs files to your computer? Google Docs doesn't offer an export service, only downloads. If you have just a few files, you can download them one by one, but if you have a lot, it gets to be a real hassle. Here I recommend a program called GDocBackup.


<!--more-->


GDocBackup can back up all your Google Docs files, and it can also convert formats. If your account is a Google Apps account, it's supported too~ Let's walk through how to use this program.

<h2>GDocBackup Tutorial</h2>
1. First, go to the download links above, download GDocBackup, and install it.

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_1206231.jpg"><img class="alignnone  wp-image-5951" title="2012-01-24_120623" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_1206231.jpg" alt="" width="453" height="350" /></a>

2. Once it's installed, run it. The first time you use it, a Config window opens automatically. Enter your Google account and password there. Note that "Remember" must be checked for the password to be entered.

Backup Directory sets where the backed-up files are saved.

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121054.jpg"><img class="alignnone size-full wp-image-5952" title="2012-01-24_121054" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121054.jpg" alt="" width="442" height="472" /></a>

If the Config screen doesn't appear when you start GDocBackup, you can open Config manually from "Action" in the upper-left corner of the program.

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121236.jpg"><img class="alignnone size-large wp-image-5953" title="2012-01-24_121236" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121236-520x271.jpg" alt="" width="520" height="271" /></a>

3. You can also click the "Export format" tab to set the format for backups. The default is Microsoft Office formats, but you can change them to open formats such as odt or ods. PDFs can be changed to jpg, png, and so on.

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121503.jpg"><img class="alignnone size-full wp-image-5954" title="2012-01-24_121503" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121503.jpg" alt="" width="442" height="472" /></a>

4. Once everything is set, click "Save" to save the settings, then click "Exec" to start the backup~

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121717.jpg"><img class="alignnone size-large wp-image-5955" title="2012-01-24_121717" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121717-520x271.jpg" alt="" width="520" height="271" /></a>

During the backup, this area shows the files that have already been backed up. There's a progress bar at the top so you can estimate how long it will take.

<a href="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121752.jpg"><img class="alignnone size-large wp-image-5956" title="2012-01-24_121752" src="{{< param imageBase >}}/wp-content/uploads/2012/01/2012-01-24_121752-520x336.jpg" alt="" width="520" height="336" /></a>

5. Backup complete
