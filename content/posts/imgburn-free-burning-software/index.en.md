You've probably all heard of Nero, but I bet few of you have heard of ImgBurn, a burning program. That doesn't mean ImgBurn is inferior to Nero. In fact, it's precisely because ImgBurn is free software that fewer people know about it. How so? Free software can't advertise the way companies that sell paid software do. It can only spread through bloggers' recommendations and word of mouth, so few people hear about it. ImgBurn doesn't have as many features as Nero, but it's very suitable for ordinary users, because its built-in features are already more than enough for regular users. Unless you're a very professional burner (is that even a job?), ImgBurn is more than enough.

<h2>3. Turning a CD into an Image File (ISO)</h2>
So what is an image file? An image file is basically a compressed copy of a disc. It packs everything on a disc into a single file, which makes it easy to share the contents online or pass them to friends. Some people also want to make disc-to-disc copies, and for that they can use an ISO file as an intermediate step: first compress the CD into an ISO, then burn that ISO onto the target disc. In the next two sections, I'll show you how to create and burn ISO files with ImgBurn.
<!--nextpage-->
1. Open ImgBurn

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_192445.png"><img title="2010-01-25_192445" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_192445-454x400.png" alt="" width="454" height="400" /></a>

2. Choose 【Read disc to image file】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201138.png"><img class="alignnone size-large wp-image-2576" title="2010-01-25_201138" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201138-500x346.png" alt="" width="500" height="346" /></a>

3. Under 【Source】, select the drive you'll use to create the ISO, then under 【Destination】, set where the ISO file will be saved.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201530.png"><img class="alignnone size-large wp-image-2577" title="2010-01-25_201530" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201530-500x346.png" alt="" width="500" height="346" /></a>

4. Click the big button at the bottom to start reading the disc and creating the ISO.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201724.png"><img class="alignnone size-large wp-image-2578" title="2010-01-25_201724" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_201724-500x346.png" alt="" width="500" height="346" /></a>

5. The ISO file is done!

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_202012.png"><img class="alignnone size-large wp-image-2579" title="2010-01-25_202012" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_202012-500x349.png" alt="" width="500" height="349" /></a>
<h2>4. Burning an Image File with ImgBurn</h2>
In the previous section, we covered how to create ISO files. In this section, I'll show you how to burn an ISO file onto a CD. Sometimes when you download files online, you'll get ISO files too, and you can follow this section to burn them.

1. Open ImgBurn and choose 【Write image file to disc】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_202647.png"><img class="alignnone size-large wp-image-2580" title="2010-01-25_202647" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_202647-500x346.png" alt="" width="500" height="346" /></a>

2. Under 【Source】, select the location of the ISO file, then under 【Destination】, set the burner you'll use.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_203010.png"><img class="alignnone size-large wp-image-2581" title="2010-01-25_203010" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_203010-500x346.png" alt="" width="500" height="346" /></a>

3. If you're burning an ISO for an operating system such as Ubuntu, I recommend slowing down the burn speed, as it has a higher success rate.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_203511.png"><img class="alignnone size-large wp-image-2582" title="2010-01-25_203511" src="{{< param imageBase >}}/wp-content/uploads/2010/01/2010-01-25_203511-500x346.png" alt="" width="500" height="346" /></a>
