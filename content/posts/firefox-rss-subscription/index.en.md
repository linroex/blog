Did you know that Firefox has a great feature: you can subscribe to RSS feeds directly, without installing any add-on, and it loads pretty quickly? I'm not sure when this feature was introduced, I only recently discovered it :: ) Enough chatter, let's get straight to how to subscribe to a website's RSS feed with Firefox

1. Open Firefox and go to the website you want to subscribe to

2. In the toolbar, click 【Bookmarks】 → 【Subscribe to This Page】 in that order

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_200800.jpg"><img class="alignnone size-full wp-image-1153" title="2009-05-27_200800" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_200800.jpg" alt="2009-05-27_200800" width="440" height="215" /></a>

3. It will take you to a page. Ignore the content there and click 【Subscribe Now】 directly

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_201147.jpg"><img class="alignnone size-full wp-image-1154" title="2009-05-27_201147" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_201147.jpg" alt="2009-05-27_201147" width="639" height="266" /></a>

4. In the "New Live Bookmark" dialog, click OK

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_2012261.jpg"><img class="alignnone size-full wp-image-1156" title="2009-05-27_2012261" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_2012261.jpg" alt="2009-05-27_2012261" width="285" height="148" /></a>

That completes adding the RSS feed.

Next, all you need to do is click the button with the symbol <a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_201455.jpg"><img class="alignnone size-full wp-image-1157" title="2009-05-27_201455" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-27_201455.jpg" alt="2009-05-27_201455" width="22" height="22" /></a> on your browser to see new messages!

Isn't this trick pretty neat? With this method, you no longer need to open a separate program to check RSS. You can read web pages and check messages right in the browser. However, it has one drawback: it only shows titles, not the article content, so you still have to click through to the website to read an article = = Still, RSS was already very convenient, so this feature feels a bit redundant. Or rather, it's just too convenient! It makes me feel like we are gradually regressing. Maybe in ten years, we'll operate computers just by talking to them XD
