Anyone who uses 7-Zip has probably wondered whether 7-Zip could change its skin the way Firefox and other programs do, because seeing the same look every day gets really boring~~ Today's program, 7-Zip Theme Manager 1.1, can change 7-Zip's look. It has many built-in themes, but the program itself is in English, so some people may not like that............... I'll make a Chinese version one of these days!

<h2>How to Use</h2>
This program doesn't need to be installed. You just extract it and you're good to go.

1. After extracting, run the 7zTM.exe file.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_183350.jpg"><img class="alignnone size-full wp-image-1437" title="2009-06-26_183350" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_183350.jpg" alt="2009-06-26_183350" width="61" height="71" /></a>

2. When it opens, set the language to 【English】 and click OK.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_183539.jpg"><img class="alignnone size-full wp-image-1438" title="2009-06-26_183539" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_183539.jpg" alt="2009-06-26_183539" width="273" height="111" /></a>

3. 7-Zip Theme Manager automatically detects where the main 7-Zip program is installed. Just click 【Yes(Y)】 once.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184047.jpg"><img class="alignnone size-full wp-image-1439" title="2009-06-26_184047" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184047.jpg" alt="2009-06-26_184047" width="419" height="160" /></a>

4. Now you can start choosing the style you want! The blue box on the right is the preview area, and the red box on the left is the selection area.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184301.jpg"><img class="alignnone size-full wp-image-1440" title="2009-06-26_184301" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184301.jpg" alt="2009-06-26_184301" width="500" height="370" /></a>

5. Happy with your choice? Then click Activate theme to finish changing the look.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184435.jpg"><img class="alignnone size-full wp-image-1441" title="2009-06-26_184435" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-26_184435.jpg" alt="2009-06-26_184435" width="619" height="458" /></a>

Open 7-Zip to see if there's a difference.
