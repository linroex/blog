<strong><a href="http://tools.google.com/dlpage/cloudconnect">Google Cloud Connect</a></strong> は、Google が設計した Microsoft Office 用の小さなプログラムです。Microsoft Office と Google Docs を接続し、文書をクラウドの Google Docs に保存したり、Microsoft Office の中から直接オンラインで共同作業したりできます。残念なのは、Microsoft Office の中で Google Docs の文書を直接編集できないことです。もしそれができれば最高なのに、と思います。正直に言えば、Google Docs はとても便利なのですが、よく落ちますし、機能が少なすぎるのです……


<!--more-->

<h2>Google Cloud Connect の機能</h2>
<ul>
	<li>Office にオンラインでの共同作業、クラウドバックアップ、バージョンの復元機能を追加します</li>
</ul>

<h2>Google Cloud Connect の使い方</h2>
1. まず Word を開くと、中に新しい項目が追加されていることが分かります（実は Google Cloud Connect は Word、Excel、PowerPoint に自動的にインストールされます。ここでは分かりやすいように Word を例にご説明します）。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195237.jpg"><img class="alignnone size-large wp-image-4935" title="2011-03-19_195237" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195237-520x311.jpg" alt="" width="520" height="311" /></a>

2. 左側の Google Cloud Connect ボタンをクリックし、【Google Cloud Connect Setting】を選択します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195403.jpg"><img class="alignnone size-large wp-image-4937" title="2011-03-19_195403" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195403-520x311.jpg" alt="" width="520" height="311" /></a>

3. 【Login】をクリックして、Google アカウントでログインします。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195529.jpg"><img class="alignnone size-large wp-image-4938" title="2011-03-19_195529" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195529-520x274.jpg" alt="" width="520" height="274" /></a>

4. Google アカウントのメールアドレスとパスワードを入力し、【ログイン】をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195624.jpg"><img class="alignnone size-large wp-image-4939" title="2011-03-19_195624" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195624-448x500.jpg" alt="" width="448" height="500" /></a>

5. 【アクセスを許可】をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195732.jpg"><img class="alignnone size-large wp-image-4940" title="2011-03-19_195732" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_195732-448x500.jpg" alt="" width="448" height="500" /></a>

6. 上記の手順が終わると、Google Docs との接続が完了します。次に、同期の方法を設定します。自動で同期するか、Sync ボタンをクリックしたときだけ同期するかを選べます。
<ul>
	<li>Automatically-&gt;自動同期</li>
	<li>Manually-&gt;手動同期</li>
</ul>
<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200144.jpg"><img class="alignnone size-large wp-image-4941" title="2011-03-19_200144" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200144-520x358.jpg" alt="" width="520" height="358" /></a>

7. 設定が終わったら、Sync をクリックして同期できます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200445.jpg"><img class="alignnone size-large wp-image-4942" title="2011-03-19_200445" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200445-520x347.jpg" alt="" width="520" height="347" /></a>

アップロード中です ↓↓

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200540.jpg"><img class="alignnone size-large wp-image-4943" title="2011-03-19_200540" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200540-520x347.jpg" alt="" width="520" height="347" /></a>

アップロードが完了すると、そのファイルの URL が表示されます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200628.jpg"><img class="alignnone size-large wp-image-4944" title="2011-03-19_200628" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_200628-520x347.jpg" alt="" width="520" height="347" /></a>

8. 先ほど同期したファイルが、Google Docs に表示されます。
