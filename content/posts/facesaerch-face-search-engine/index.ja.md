Facesaerch は、キーワードを入力すると画像を探し出してくれる検索エンジンです。画像の検索には Google の API を使っていて、個人的にはとても不思議に感じます。ただ、中国語の検索には対応していないようで、中国語で入力するとなかなか見つかりませんでした。また、精度もあまり高くありません（有名な人ほど見つけやすいです）＝＝。とはいえ、試しに私のニックネームである linroex を入力してみたところ、なんと私の写真が出てきました :)

URL：<a href="http://www.facesaerch.com/">http://www.facesaerch.com/</a>

使い方：まず Facesaerch のサイトにアクセスし、赤い枠の中にキーワードを入力して、Search をクリックすると検索が始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_101454.jpg"><img class="alignnone size-full wp-image-1169" title="2009-05-31_101454" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_101454.jpg" alt="2009-05-31_101454" width="640" height="461" /></a>

検索された画像が多い場合は、マウスホイールを回して目的の画像を探すか、下のバーをマウスでドラッグしてください。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_101629.jpg"><img class="alignnone size-full wp-image-1170" title="2009-05-31_101629" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_101629.jpg" alt="2009-05-31_101629" width="1024" height="738" /></a>

どこから来た画像なのか知りたい場合は、画像をダブルクリックすると、提供元のサイトが表示されます！！

個人的には、この検索エンジンを使う機会はごくまれだと思います。学校のレポートを作成したときくらいでしょうか！ 画像を探すにはなかなか便利です。また、顔の検索にしか対応していないのも注意点です。地名などほかのものを入力してみたことがありますが、何も見つかりませんでした！
