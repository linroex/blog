<strong>FSCapture</strong> is a very good screenshot program. It's small but mighty, as you can see from the screenshots. This site's personal top pick for a screenshot program is also <strong>FSCapture</strong>. Besides being tiny, it supports many capture methods and has a built-in editor (though not as powerful as PicPick's editor). <strong>FSCapture</strong> can also add a watermark automatically when taking screenshots. On top of these features, <strong>FSCapture</strong> has one thing PicPick doesn't: it can name image files automatically. In PicPick, you have to name every file by hand each time you save, which is a hassle. In FSCapture v5.3, however, you can set up a file name template first.

(The latest version of PicPick now supports file name templates too.)

<h2>Hotkey Setup Tutorial</h2>
I'm sure everyone is familiar with hotkeys, so I'll skip the small talk and go straight to how to set them up~

1. Open FSCapture, click the button on the right side of the program, and select "Settings"

2. Once you open the FSCapture settings area, you'll see a section called "Hotkeys" (see Figure A-1). Set them there. It's simple: click the white area once, a box will pop up, and then press the hotkey you want to use on your keyboard (see Figure A-2)

<h2>Editor Tutorial</h2>
In this part, I'll take you through an actual screenshot and show you how to process it in the editor.

1. To take screenshots with FSCapture, first set up the hotkeys as described in the previous post. Then click the second button on the right side of the program and choose "To Editor" (this way, the editor opens automatically after each capture)

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-06.jpg"><img class="alignnone size-full wp-image-1710" title="FSCapture-06" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-06.jpg" alt="FSCapture-06" width="227" height="252" /></a>

2. Open the program you want to capture, then press the hotkey to take a screenshot. After a successful capture, an editor will open. Here are its main features.
<h4>2-1. Resize &amp; Sharpen:</h4>
Sometimes, after taking a screenshot, you'll find the image is too large to upload online. In that case, go to Edit - Resize to change it.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-07.jpg"><img class="alignnone size-full wp-image-1712" title="FSCapture-07" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-07.jpg" alt="FSCapture-07" width="386" height="553" /></a>

Enter the width and height ↓↓↓

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-08.jpg"><img class="alignnone size-full wp-image-1711" title="FSCapture-08" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-08.jpg" alt="FSCapture-08" width="285" height="187" /></a>

2. After changing the width and height, you may notice the image has become blurry. In that case, use Edit - Sharpen/Blur to fix it

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-09.jpg"><img class="alignnone size-full wp-image-1713" title="FSCapture-09" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-09.jpg" alt="FSCapture-09" width="450" height="619" /></a>

<h3>Delayed Screenshot Setup Tutorial</h3>
Delayed screenshots are one of FSCapture's biggest highlights. They let you set how long to wait after pressing the screenshot key before the capture is actually taken. At first glance, that might seem pointless, but people who take a lot of screenshots know that many programs hide themselves as soon as you take a shot, so you can't capture them. That's where delayed screenshots come in: press the screenshot hotkey first, then bring up the program that's hiding.

1. Open the settings area

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-13.jpg"><img class="alignnone size-full wp-image-1717" title="FSCapture-13" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-13.jpg" alt="FSCapture-13" width="228" height="313" /></a>

2. Set the delay you want under "Delay before capture", then click "OK" to save

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-141.jpg"><img class="alignnone size-full wp-image-1719" title="FSCapture-14" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-141.jpg" alt="FSCapture-14" width="500" height="380" /></a>

3. Next, open the program you want to capture, then press the hotkey. Some programs may minimize themselves automatically, so just bring them back up within the time limit you set

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-14.jpg"></a>
<h3>File Name Template &amp; Auto-Save Setup Tutorial</h3>
The file name template works best combined with automatic saving, because it lets you save a photo right after taking it without opening the editor.

P.S. If you don't have any special needs, the default file name template is fine.

1. As with most settings, first open "Settings"

<img title="FSCapture-13" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-13.jpg" alt="FSCapture-13" width="228" height="313" />

2. Enter the pattern you want in the file name template field. That may be hard to follow in words, so you can click the "?" button next to it to see the explanation

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-15.jpg"><img class="alignnone size-full wp-image-1720" title="FSCapture-15" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-15.jpg" alt="FSCapture-15" width="550" height="366" /></a>

3. After that, click the "..." next to "Output folder" to choose the folder where auto-saved files will go. (You can also change the file format used for auto-saved files.)

<a href="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-161.jpg"><img class="alignnone size-full wp-image-1722" title="FSCapture-16" src="{{< param imageBase >}}/wp-content/uploads/2009/07/FSCapture-161.jpg" alt="FSCapture-16" width="550" height="419" /></a>

4. Once that's done, go back to the small toolbar interface, click the second-to-last button, and choose "To File (Auto-Save)" from the menu
