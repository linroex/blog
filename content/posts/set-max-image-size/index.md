利用一個css的語法可以達到設定圖片最大寬度跟高度的效果


<pre lang="css">最大寬度:

標籤名稱 img{

max-width:寬度值

}

最大高度:

標籤名稱 img{

max-height:高度值

}
</pre>

另外高度(寬度)值的那裡可以使用百分比來表示

這些語法可以幫助你讓網誌的圖片不要超出範圍

不過這個語法在IE6上面是無效的
