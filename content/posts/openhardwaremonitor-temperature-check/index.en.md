After a painful experience where my graphics card gave off a burning smell and I found out it had died, I realized the hardware temperature program I was using wasn't enough. It could only detect CPU temperature. So I went looking for something else and found OpenHardwareMonitor. It can read the temperatures of many components in your computer, such as the hard drive, graphics card, CPU, and motherboard, and it can also plot temperature changes as a chart or export them to a file.

<h2>OpenHardwareMonitor Features:</h2>
<ul>
	<li>Plots temperature changes as a chart</li>
	<li>Monitors the temperature of multiple hardware components (hard drive, graphics card, CPU, motherboard)</li>
	<li>Still being updated, with support for many newer hardware devices (including CPUs from both AMD and Intel)</li>
</ul>
<h2>OpenHardwareMonitor Tutorial:</h2>
1.Open the OpenHardwareMonitor main program. It starts a bit slowly, so give it a moment.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_200608.jpg"><img class="alignnone size-large wp-image-4682" title="2011-02-08_200608" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_200608-520x312.jpg" alt="" width="520" height="312" /></a>

2.The main window shows the temperatures of the hardware in your computer, along with other hardware information such as CPU clock speed and motherboard model.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_201105.jpg"><img class="alignnone size-large wp-image-4683" title="2011-02-08_201105" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_201105-282x500.jpg" alt="" width="282" height="500" /></a>

3.Checking hardware temperatures is fairly easy. But what if you want to plot the temperature changes as a chart? Click 【View】→【Show Plot】 on the toolbar at the top.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_201404.jpg"><img class="alignnone size-full wp-image-4684" title="2011-02-08_201404" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_201404.jpg" alt="" width="486" height="464" /></a>

4.After you turn on Show Plot, you'll notice a new box at the bottom of the program. You'll also see small checkboxes in front of each temperature value. Checking one causes that temperature to be drawn in the large box at the bottom.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_202055.jpg"><img class="alignnone size-large wp-image-4685" title="2011-02-08_202055" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_202055-282x500.jpg" alt="" width="282" height="500" /></a>

For example, if I want to show the temperatures of the 4 CPUs (I have a quad-core), I check the box in front of CPU, and the temperature changes then appear below.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_202324.jpg"><img class="alignnone size-large wp-image-4686" title="2011-02-08_202324" src="{{< param imageBase >}}/wp-content/uploads/2011/02/2011-02-08_202324-426x500.jpg" alt="" width="426" height="500" /></a>

5.You can also set it to start automatically when Windows starts. To do this, click 【Options】→【 Run On Windows Startup 】 on the toolbar at the top.
