Here's a useful tip to share~

From now on, it's best to compile your VB programs with the Ctrl+F5 shortcut.

Because the compiled file is smaller.

Also, if you compile your program with Ctrl+F5,

the compiled program is placed in the binRelease folder inside the project folder.
