甚麼是影子系統?相信大家都有看過學校或網咖的電腦每次只要重開機,電腦就會變得很乾淨,所以非預設的檔案都會刪光光,這功能是因為網咖有裝還原卡這種硬體設備,在這裡要介紹的影子系統可以讓你擁有與還原卡相同的效果但卻不用花錢去買還原卡,而且使用上比還原卡更簡易,有了影子系統就不用擔心電腦中毒的問題了,反正電腦重開就能恢復正常~
<h2><span style="font-weight: normal; font-size: 13px;">在這篇文章中我們要介紹的影子系統是Returnil Virtual System(以下簡稱RVS)


<!--more-->


<strong>Returnil Virtual System使用教學:</strong>

1.先到<a href="http://www.returnilvirtualsystem.com/returnil-system-safe">RVS官網</a>下載主程式

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113126.jpg"><img class="alignnone size-large wp-image-3804" title="2010-09-19_113126" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113126-503x400.jpg" alt="" width="503" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113126.jpg"></a>
2.等RVS下載完之後開啟你下載下來的主程式,然後按【執行】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113551.jpg"><img class="alignnone size-large wp-image-3805" title="2010-09-19_113551" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113551-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113551.jpg"></a>
3.這裡是選擇你的程式介面的語言,按【OK】即可,這套程式還沒有繁體中文介面

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113639.jpg"><img class="alignnone size-large wp-image-3806" title="2010-09-19_113639" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113639-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_113639.jpg"></a>
4.這是歡迎畫面,就只是告訴你RVS是甚麼東西的畫面而已,按【Next】即可進入下一步驟

<img class="alignnone size-large wp-image-3808" title="2010-09-19_115414" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115414-492x400.jpg" alt="" width="492" height="400" />
5.選擇【I accept the terms in the license agreement】然後按【Next】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115529.jpg"><img class="alignnone size-large wp-image-3809" title="2010-09-19_115529" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115529-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115529.jpg"></a>
6.這個畫面是設定你程式要安裝在哪裡,直接按【Next】就可以了

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115707.jpg"><img class="alignnone size-large wp-image-3810" title="2010-09-19_115707" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115707-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115707.jpg"></a>
7.按【Install】就可以開始安裝了

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115758.jpg"><img class="alignnone size-large wp-image-3811" title="2010-09-19_115758" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115758-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_115758.jpg"></a>
<!--nextpage-->
8.安裝完成,按一下【Finish】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120220.jpg"><img class="alignnone size-large wp-image-3812" title="2010-09-19_120220" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120220-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120220.jpg"></a>
9.接者它會開啟一個視窗,選擇【Free version】然後在下面輸入你的名字跟信箱(名字建議用英文),最後按一下【Next】即可

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120602.jpg"><img class="alignnone size-large wp-image-3813" title="2010-09-19_120602" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120602-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120602.jpg"></a>
10.取消勾選【Perform Quick Scan of my system】然後按【Next】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120849.jpg"><img class="alignnone size-large wp-image-3814" title="2010-09-19_120849" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120849-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120849.jpg"></a>
11.按一下【Finish】就算完成全部安裝動作了

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120927.jpg"><img class="alignnone size-large wp-image-3815" title="2010-09-19_120927" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120927-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_120927.jpg"></a>
12.系統會要求你重新開機,按【Yes】就會重開了

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121102.jpg"><img class="alignnone size-large wp-image-3816" title="2010-09-19_121102" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121102-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121102.jpg"></a>
13.重開機之後按【開始-&gt;所有程式(程式集)-&gt;Returnil-&gt;Returnil System Safe 2011】就可以執行RVS

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121521.jpg"><img class="alignnone size-large wp-image-3817" title="2010-09-19_121521" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121521-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121521.jpg"></a>
14.開啟RVS之後選擇右側的【Virtual Mode】,然後按一下【Start Virtual Mode】就會開啟還原卡模擬(影子)的功能囉

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121818.jpg"><img class="alignnone size-large wp-image-3818" title="2010-09-19_121818" src="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121818-492x400.jpg" alt="" width="492" height="400" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/09/2010-09-19_121818.jpg"></a>
P.S.如果你希望一開機就是還原卡模式,那你可以把【Start Virtual Mode when I start Windows】打勾
