Opera is a browser that stands alongside Firefox and IE. Opera's strengths are that it uses very few system resources when it starts and its files are small, so it's great for keeping on a USB flash drive. Opera's stability is also just as good as Firefox's. Opera also has strong support for CSS syntax, supporting most of it, unlike IE, which doesn't support a whole bunch of syntax.

Tutorial

1.Open the installer. It first runs a program that loads some files.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160701.jpg"><img class="alignnone size-full wp-image-1293" title="2009-06-13_160701" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160701.jpg" alt="2009-06-13_160701" width="285" height="123" /></a>

2.Select the Traditional Chinese option (the entry starting with "C"), then click OK.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160806.jpg"><img class="alignnone size-full wp-image-1294" title="2009-06-13_160806" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160806.jpg" alt="2009-06-13_160806" width="384" height="151" /></a>

3.Next, it runs a few more things, and then you'll see the nicely designed Opera installation screen.

4.Click "Start setup", then "I accept", then "Next", in that order.
