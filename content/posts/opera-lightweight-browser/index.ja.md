Opera は、Firefox や IE と並び称されるブラウザです。Opera の特徴は、起動時に消費するシステムリソースが非常に少なく、ファイルサイズも小さいことです。そのため USB メモリに入れて持ち歩くのにも非常に向いています。また、安定性も Firefox に決して劣りません。さらに Opera は CSS 構文への対応度が高く、ほとんどの構文をサポートしています。一方、IE は多くの構文に対応していません。

ソフトの特徴
<ul>
	<li>容量が小さく、システムリソースの消費が少ない</li>
	<li>高い安定性</li>
	<li>持ち歩きに向いている</li>
	<li>タブ機能を内蔵</li>
	<li>多言語に対応</li>
</ul>
ソフトの基本情報

公式サイト：<a href="http://www.opera.com/">http://www.opera.com/</a>

ダウンロード：<a href="http://www.opera.com/download/get.pl?id=32024&amp;thanks=true&amp;sub=true">http://www.opera.com/download/</a>

使い方

1.インストーラーを開きます。まず、いくつかのファイルを読み込むプログラムが実行されます。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160701.jpg"><img class="alignnone size-full wp-image-1293" title="2009-06-13_160701" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160701.jpg" alt="2009-06-13_160701" width="285" height="123" /></a>

2.「C中文(繁體)」（繁体字中国語）を選択して、【OK】をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160806.jpg"><img class="alignnone size-full wp-image-1294" title="2009-06-13_160806" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160806.jpg" alt="2009-06-13_160806" width="384" height="151" /></a>

3.その後もいくつかの処理が実行され、Opera の美しいインストール画面が表示されます。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160954.jpg"><img class="alignnone size-full wp-image-1295" title="2009-06-13_160954" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_160954.jpg" alt="2009-06-13_160954" width="504" height="386" /></a>

4.「開始設定」（開始設定）→「同意する」（我接受）→「次へ」（下一步）の順にクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161112.jpg"><img class="alignnone size-full wp-image-1296" title="2009-06-13_161112" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161112.jpg" alt="2009-06-13_161112" width="504" height="386" /></a><a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161124.jpg"><img class="alignnone size-full wp-image-1297" title="2009-06-13_161124" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161124.jpg" alt="2009-06-13_161124" width="504" height="386" /></a><a href="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161151.jpg"><img class="alignnone size-full wp-image-1298" title="2009-06-13_161151" src="{{< param imageBase >}}/wp-content/uploads/2009/06/2009-06-13_161151.jpg" alt="2009-06-13_161151" width="504" height="386" /></a>

5.最後に【インストール】（安裝）をクリックすれば完了です。インストールが終わったら【終了】（結束）をクリックすると、Opera を開けるようになります。

まとめ：少し試してみたところ、Opera は本当にかなり速いです。ただ、文字の表示の「美しさ」は、正直あまり感心できませんでした。気になる方はご自分で試してみてください。表示される文字が、一部太く、一部細くなってしまうのです。これは私の環境だけの問題なのか、そうでないのかはわかりません= =　また、Opera のほかの使い方も、少しずつ紹介していく予定です。実は私も、このブラウザを使い始めたばかりなので。
