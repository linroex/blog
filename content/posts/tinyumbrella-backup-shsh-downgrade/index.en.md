Sometimes when you want to downgrade your iPad or iPhone (hereafter iOS Device), you find that the downgrade keeps failing. This is because newer iOS devices have a built-in protection mechanism that blocks you from downgrading the device. This design exists to prevent users from jailbreaking. When a new iOS version comes out, some people accidentally tap update... Usually the latest iOS version cannot be jailbroken, so users who have updated can only downgrade in order to jailbreak. This is when a big problem appears: you cannot downgrade...... The TinyUmbrella introduced today is software that can help you downgrade successfully. It can back up something called SHSH for you. Once you have backed up the SHSH, you can downgrade successfully~

<h2>TinyUmbrella Tutorial</h2>
1. First, download TinyUmbrella, connect your iOS device to the computer, and then run TinyUmbrella. Some messages will appear; ignore them and click "OK."

<a href="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_155323.jpg"><img class="alignnone size-large wp-image-5490" title="2011-07-26_155323" src="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_155323-520x158.jpg" alt="" width="520" height="158" /></a>

2. The left side lists the iOS devices currently connected to the computer. Select the device whose SHSH you want to back up, then click "Save SHSH."

P.S. Actually, Connected Devices and Recent Devices are basically the same.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_155937.jpg"><img class="alignnone size-large wp-image-5492" title="2011-07-26_155937" src="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_155937-520x363.jpg" alt="" width="520" height="363" /></a>

3. By default, the shsh files are saved to "C:Users[your-username].shsh". For example, my computer's user name is linroex, so my shsh files are saved to C:Userslinroex.shsh.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_160216.jpg"><img class="alignnone size-large wp-image-5493" title="2011-07-26_160216" src="{{< param imageBase >}}/wp-content/uploads/2011/07/2011-07-26_160216-520x393.jpg" alt="" width="520" height="393" /></a>

4. If you want to save the shsh files to a different folder, click "show All SHSHs" on the left, then select "Advanced." There is a "Save SHSH Directory" option, where you can set the save location.
