<strong>Windows 7（Win7）</strong>の紹介記事は、ネット上にほとんど同じ内容のものがすでにたくさんあるので、ここでは簡単に触れておきます。<strong>Windows 7</strong> は Microsoft が最近リリースしたオペレーティングシステムで、多くの点で Vista より優れています（もともと Windows 7 は Vista を救うためにつくられたようなものですから）。リソースもあまり消費しません。たとえば私が仮想マシン（VirtualBox）に <strong>Windows 7</strong> を入れたときは、メモリを 1GB しか割り当てませんでしたが、まったくもたつくことなく動きました。ただ、<strong>Windows 7</strong> はそれほどリソースを使わないとはいえ、本当に古いパソコンにはインストールしないことをおすすめします XD。また <strong>Windows 7（Win7）</strong> は、XP や Vista の欠点も数多く改善されており、ファイルの検索速度もかなり速くなりました。
<h3>Windows 7 の特徴：</h3>
<ol>
	<li>DirectX 11 に対応</li>
	<li>64 ビット CPU を完全サポート</li>
	<li>リソースを使いすぎずに、より多くの Aero エフェクトに対応</li>
	<li>UAC による保護がより充実</li>
	<li>Windows XP 互換モードを内蔵</li>
</ol>

<!--more-->

<h3>Windows 7 のシステム要件</h3>
<ul>
	<li>1 GHz 以上の 32 ビット（x86）または 64 ビット（x64）プロセッサ</li>
	<li>1 GB RAM（32 ビット）または 2 GB RAM（64 ビット）</li>
	<li>使用可能なハードディスク容量 16 GB（32 ビット）または 20 GB（64 ビット）</li>
	<li>WDDM 1.0 以降のドライバーに対応した DirectX 9 グラフィックデバイス</li>
	<li>パソコンが Windows 7 にアップグレードできるか心配ですか？ <a href="http://www.microsoft.com/downloads/details.aspx?displaylang=zh-tw&amp;FamilyID=1b544e90-7659-4bd9-9e51-2497c146af15">Windows 7 Upgrade Advisor </a>を試してみてください。</li>
</ul>
<span style="color: #ffffff;">.</span>
<h3>Windows 7 のインストール手順</h3>
昨日たまたまチェコのフォーラムを見ていたら、<strong>Windows 7（Win7）</strong>の改造版（クラック版）がすでに出回っていることがわかりました。しかもエンタープライズ版です。つまり、認証はまったく必要ありません。そこでダウンロードして、手順を書くことにしました。<strong>Windows 7</strong> が欲しい方は、ご自分で探してください。フォーラムがどこかはすでに書いてしまいましたが、これ以上書くと、ネットのおまわりさんが来てしまいそうなので…… 前置きはこのくらいにして、<strong>Windows 7</strong> のインストール方法を説明します。

注：<strong>Windows 7（Win7）</strong>には、いわゆるエンタープライズの評価版（私が使ったのは正式版です）があり、90 日間試用できます。新しもの好きの方はすぐにダウンロードしてください。（90 日たったら、また戻ってきて解除してくださいね XD）

1. まず起動の順番を CD から起動するように設定し、ディスクを入れてからパソコンを起動します（前置きが長くてすみません）。

CD から起動する設定方法がわからない方は、こちらの記事を参考にしてください <a href="https://coder.tw/?p=2290">https://coder.tw/?p=2290</a>

2. パソコンが Windows 7 のインストールファイルを読み込み始めます。

読み込み中……

3. Windows 7 のセットアップ画面が表示されたら、下の図のように設定値を選び、「次へ」をクリックします（基本的には初期設定のままで構いません）。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213220.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213220" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213220_thumb.jpg" alt="2009-11-28_213220" width="504" height="379" border="0" /></a>

4. 「今すぐインストール」をクリックします。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213233.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213233" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213233_thumb.jpg" alt="2009-11-28_213233" width="504" height="422" border="0" /></a>

5. セットアッププログラムを起動しています。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213242.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213242" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213242_thumb.jpg" alt="2009-11-28_213242" width="504" height="420" border="0" /></a>

7. インストールの種類を選択します。既存の OS からアップグレードして、ファイルを残したい場合は、最初の項目を選んでください。ただ、ここではインストール方法を説明するので、もちろん「カスタム」を選びます。

8. 次に、Windows 7 をインストールするパーティションを選択します。デュアルブートにするつもりでなければ、元の XP や Vista が入っているハードディスクをフォーマットしてから上書きでインストールするのがおすすめです。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_2136311.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213631-1" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_2136311_thumb.jpg" alt="2009-11-28_213631-1" width="504" height="419" border="0" /></a>

9. Windows 7 のインストールが始まります。この部分はかなり時間がかかります。当時は仮想マシンにインストールしたので、さらに長く待つことになりました XD

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213835.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213835" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213835_thumb.jpg" alt="2009-11-28_213835" width="504" height="421" border="0" /></a>

10. インストールの途中でパソコンは自動で再起動します。そのままにしておいてください。<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_215527.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_215527" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_215527_thumb.jpg" alt="2009-11-28_215527" width="504" height="421" border="0" /></a>

11. 再起動が終わると、パソコンは自動的に Windows 7 のセットアップ画面に戻ります。インストールに失敗したと思わないでください。インストールディスクがまだドライブに入ったままで、起動の順番をハードディスクに戻していないためです。この場合は、もう一度再起動してから、ディスクを取り出してください。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213220.jpg"><img title="2009-11-28_213220" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213220_thumb.jpg" alt="2009-11-28_213220" width="504" height="379" border="0" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221535.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_221535" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221535_thumb.jpg" alt="2009-11-28_221535" width="504" height="422" border="0" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221548.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_221548" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221548_thumb.jpg" alt="2009-11-28_221548" width="504" height="422" border="0" /></a>

14. タイムゾーンを設定します。台湾は UTC+8 です。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221559.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_221559" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_221559_thumb.jpg" alt="2009-11-28_221559" width="504" height="422" border="0" /></a>

<h3>まとめ：</h3>
Vista は実は Windows 7 の一部だったという噂を聞いたことがあるかもしれません。当時は Windows XP の売り上げが落ち込んでいて、Microsoft も長いあいだ新しい OS を出していませんでした。そこで Vista を Windows 7 から切り離して、独立した OS として出したというのです。でも急いで作ったため、Vista にはたくさんのバグがありました。そのため Microsoft は後になって、完成版の Vista、つまり Windows 7 を出した、という話です。これがどういう意味かわかりますか？ Vista を買った人はかわいそうだ、ということです。未完成で欠陥のある製品を買わされたことになるのですから。この噂が本当かどうかはわかりませんが、Windows 7 が Vista よりずっと使いやすいのは確かです。少なくとも、UAC の警告がしょっちゅう出てきて私を邪魔することはありませんから ^^
