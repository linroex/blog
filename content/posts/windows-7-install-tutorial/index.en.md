There are already many nearly identical introductions to <strong>Windows 7 (Win7)</strong> online, so I'll keep this brief. <strong>Windows 7</strong> is Microsoft's recent operating system. In many ways it's better than Vista (after all, Windows 7 was basically made to rescue Vista). It doesn't use many resources, either. For example, when I installed <strong>Windows 7</strong> in a virtual machine (VirtualBox), I only gave it 1 GB of memory and it still ran without any lag. That said, even though <strong>Windows 7</strong> doesn't consume much, I still recommend not installing it on a really old computer XD. <strong>Windows 7 (Win7)</strong> also fixes many of the shortcomings of XP and Vista, and file search is much faster too.
<h3>Windows 7 Features:</h3>
<ol>
	<li>Supports DirectX 11</li>
	<li>Full support for 64-bit CPUs</li>
	<li>Supports more Aero effects without consuming too many resources</li>
	<li>Better UAC protection</li>
	<li>Built-in Windows XP compatibility mode</li>
</ol>

<!--more-->

<h3>Windows 7 System Requirements</h3>
<ul>
	<li>1 GHz or faster 32-bit (x86) or 64-bit (x64) processor</li>
	<li>1 GB RAM (32-bit) or 2 GB RAM (64-bit)</li>
	<li>16 GB of available hard disk space (32-bit) or 20 GB (64-bit)</li>
	<li>DirectX 9 graphics device with WDDM 1.0 or higher driver</li>
	<li>Still worried your computer can't be upgraded to Windows 7? Try the <a href="http://www.microsoft.com/downloads/details.aspx?displaylang=zh-tw&amp;FamilyID=1b544e90-7659-4bd9-9e51-2497c146af15">Windows 7 Upgrade Advisor </a>.</li>
</ul>

<h3>Windows 7 Installation Tutorial</h3>
Yesterday I happened to browse a Czech forum and found that a cracked version of <strong>Windows 7 (Win7)</strong> was already out, and it was even the Enterprise edition. In other words, I wouldn't have to go through any activation at all. So I downloaded it and decided to write a tutorial. If you want <strong>Windows 7</strong>, go find it yourself. I've already said which forum it was, and if I say any more, the internet police will come after me : ) Enough chatter. Here's how to install <strong>Windows 7</strong>.

Note: <strong>Windows 7 (Win7)</strong> has a so-called Enterprise evaluation edition (mine was the full release) that lets you try it for 90 days. If you want a taste, go download it now. (After the 90 days are up, come back and crack it XD.)

1. First, set the boot order to start from the CD, then put the disc in and start the computer (so many words, I know).

If you don't know how to set CD boot, you can refer to this article <a href="https://coder.tw/?p=2290">https://coder.tw/?p=2290</a>

8. Next, choose the partition where you want to install Windows 7. Unless you want a dual-boot setup, it's generally recommended to format the drive that has your old XP or Vista system and install over it.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_2136311.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213631-1" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_2136311_thumb.jpg" alt="2009-11-28_213631-1" width="504" height="419" border="0" /></a>

9. Installation of Windows 7 begins. This part takes quite a while. I installed it in a virtual machine at the time, so I had to wait even longer XD.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213835.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_213835" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_213835_thumb.jpg" alt="2009-11-28_213835" width="504" height="421" border="0" /></a>

Ignore it.<a href="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_215527.jpg"><img style="display: inline; border: 0px;" title="2009-11-28_215527" src="{{< param imageBase >}}/wp-content/uploads/2009/11/20091128_215527_thumb.jpg" alt="2009-11-28_215527" width="504" height="421" border="0" /></a>

11. After the restart, the computer will go back to the Windows 7 setup screen. Don't assume the installation failed. It's just that the installation disc is still in the drive and you haven't switched the boot order back to the hard drive. In that case, restart the computer again, then take the disc out.
