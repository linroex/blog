有關於<strong>Windows 7(Win7)</strong>的介紹網路上已經有很多幾乎相同的文章了,因此在這邊站長就簡單的講一下<strong>Windows 7</strong>吧!<strong>Windows 7</strong>是微軟最近推出的作業系統,在很多方面都比Vista好(畢竟Windows 7本來就是用來拯救Vista的),需要耗費的資源也不多,像站長用虛擬機(Vurtual Box)裝<strong>Windows 7</strong>也只分1G的記憶體都沒有leg,不過雖然<strong>Windows 7</strong>沒有很耗費資源但還是建議各位別拿太舊的電腦來裝XD,另外<strong>Windows 7(Win7)</strong>也改正了很多以往在XP.Vista的缺點,在檔案搜尋速度上也加快不少。
<h3>Windows 7特色:</h3>
<ol>
	<li>支援DirectX 11</li>
	<li>完整支援64位元CPU</li>
	<li>支援更多種Aero特效但不耗費過多資源</li>
	<li>UAC防護更完美</li>
	<li>內建Windows XP相容模式</li>
</ol>

<!--more-->

<h3>Windows 7系統需求</h3>
<ul>
	<li>1 GHz 或更快的 32 位元 (x86) 或 64 位元 (x64)處理器</li>
	<li>1 GB RAM (32 位元) 或 2 GB RAM (64 位元)</li>
	<li>16 GB 可用硬碟空間 (32 位元) 或 20 GB (64 位元)</li>
	<li>使用 WDDM 1.0 或更高版本驅動程式的 DirectX 9 繪圖裝置</li>
	<li>還是擔心電腦無法升級至Windows 7? 試試 <a href="http://www.microsoft.com/downloads/details.aspx?displaylang=zh-tw&amp;FamilyID=1b544e90-7659-4bd9-9e51-2497c146af15">Windows 7 Upgrade Advisor </a>吧。</li>
</ul>

<h3>Windows 7安裝教學</h3>
昨天剛好去捷克論壇逛一下就發現原來<strong>Windows 7(Win7)</strong>的破X版已經出來了,而且還是企業版,也就是說我完全不用去驗證,因此就把它下載下來寫教學嚕,大家如果要<strong>Windows 7</strong>的話就自己去找吧,我已經講出來是在哪個論壇的說,在講下去網路警察會來抓我 : ) 廢話不多說,下面就來講解如何安裝<strong>Windows 7</strong>

註:<strong>Windows 7(Win7)</strong>有所謂的企業測試版(我是正式版)可以讓你試用90天,想嚐鮮的快去下載吧(90天過了以後再來破解XD)
