<h2>1. How do I convert a Word file to PDF?</h2>
For this round, the university application portfolio has to be submitted online as a PDF file. But most students make their portfolios in Word, so they run into a file format problem. If you're using Word 2007 or later, it's easy, because the program has a built-in export to PDF feature. But what if you're using Word 2003 or earlier? You can use the following software to convert Word to PDF format.
<ul>
	<li><span style="line-height: 15px;">doPDF: <a href="http://www.dotblogs.com.tw/caubekimo/archive/2011/05/23/25797.aspx" target="_blank">http://www.dotblogs.com.tw/caubekimo/archive/2011/05/23/25797.aspx</a></span></li>
	<li>PDFCreator: <a href="http://briian.com/?p=487" target="_blank">http://briian.com/?p=487</a></li>
</ul>
After converting, don't rush to upload and submit the file. I strongly recommend checking whether the PDF differs from the original Word file, for example whether images have shifted or the layout has broken. These conversion programs can't guarantee a 100% identical conversion, and sometimes the formatting breaks, so it's worth checking.
<h2>2. What should I do if the image files are too large?</h2>
The portfolio submission system limits files to 10M, so many students have run into the "image file too large" problem. If you run into this, you can follow the steps below:
<ol>
	<li>When scanning, don't set the resolution too high. Also, if the certificate itself doesn't have many colors, you can consider scanning in grayscale mode.</li>
	<li>After scanning into a file, use the JPG format, and reduce the file size by using the "Resize" function.</li>
	<li>If these two methods still don't solve the problem, you can try the RIOT program to compress the image files (<a href="http://playpcesor.blogspot.com/2010/05/riot.html" target="_blank">http://playpcesor.blogspot.com/2010/05/riot.html</a>)</li>
</ol>
About the first point, I'd like to add a note. If your portfolio is going to be printed, don't set the scanning resolution too low, or it will look bad.
<h2>3. What if the PDF file is too large?</h2>
If you've tried compressing the images but the PDF is still over 10M, the problem may be the settings you used when exporting the file. Check the PDF conversion program you're using, and try lowering the resolution of the PDF and converting it again. After converting, remember to manually check whether the resolution has become too low. You need to find a balance between resolution and file size. If you still can't get it under the limit, that means you have too much material... For example, I personally think awards from elementary and junior high school don't need to be included in the portfolio. Professors probably aren't very interested in what you did when you were little!
