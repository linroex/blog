実は、これらの小技は、Linux 向けのプレーンテキストエディタ「vi」を学んでいたときに最初に知ったものです。その後、ほかのテキストエディタ（文字が入力できる場所なら何でも～）で試したところ、どこでも同じように使えることがわかりました。こうした小技を使えば、文書の処理スピードがかなり上がります。また、最近 TQC の中英打（中国語・英語のタイピング）試験の準備をしているのですが、これらの技を練習しておくと、中英打にもある程度役立つのです。


<!--more-->
前置きが長くなりましたが、まだどんな小技なのかを説明していませんでした。実は、「ショートカット」キーのことにすぎません。

<strong>その行の先頭の文字に移動</strong>
<ul>
	<li>キーボードのキー：home</li>
</ul>
<strong>その行の末尾の文字に移動</strong>
<ul>
	<li>キーボードのキー：end</li>
</ul>
次のテクニックは、文書の編集だけでなく、ウェブを見るときにもとても便利です～

<strong>次のページに移動</strong>
<ul>
	<li>キーボードのキー：PageDown</li>
</ul>
<strong>前のページに移動</strong>
<ul>
	<li>キーボードのキー：PageUp</li>
</ul>
<strong>ページの最下部に移動</strong>
<ul>
	<li>キーボードのキー：下向きキー＋End</li>
</ul>
<strong>ページの最上部に移動</strong>
<ul>
	<li>キーボードのキー：上向きキー＋Home</li>
</ul>
<h2>あとがき：</h2>
これらの小技が中英打に役立つ理由は、誤字を直しやすくなるからです。ときには、一行まるごと打ち終えてから、最初の文字を打ち間違えていたことに気づくこともあります。そんなとき、どうすればよいでしょう？ マウスでクリックするのでは遅すぎます！ Home キーを押せば、最初の文字に戻って修正できます。マウスを使うよりも確実に速いです。特に中英打は時間との勝負ですから～ 打つのが速いほど高得点になります xD また、この小技を知っている人はあまり多くないようです。私も vi を学んでいたときに初めて知ったのです。
