其實這些技巧最早是我在學習vi這套Linux下的純文字編輯器時知道的，後來在一些其他的文字編輯器（泛指一切能輸入文字的地方～）上試驗發現其實是互通的，透過這些小技巧可以讓你的處理文件速度便會好多，還有最近要考TQC的中英打，把這些技巧練熟其實也一定程度上對中英打有幫助


<!--more-->
前面廢話很多，但都沒有講到是什麼小技巧，其實就是「快捷」鍵而已啦

<strong>回到該行第一個字</strong>
<ul>
	<li>鍵盤上的：home</li>
</ul>
<strong>回到該行最後一個字</strong>
<ul>
	<li>鍵盤上的：end</li>
</ul>
接下來下面的技巧，不只在編輯文件時可以用到，在瀏覽網頁時也是很方便的～

<strong>移到下一頁</strong>
<ul>
	<li>鍵盤上的：PageDown</li>
</ul>
<strong>移到上一頁</strong>
<ul>
	<li>鍵盤上的：PageUp</li>
</ul>
<strong>移到頁面最底</strong>
<ul>
	<li>鍵盤上的：方向鍵（下）+End</li>
</ul>
<strong>移到頁面最頂</strong>
<ul>
	<li>鍵盤上的：方向鍵（上）+Home</li>
</ul>
<h2>後話：</h2>
會說這些小技巧對中英打有幫助的原因就是在於改錯字，有時候你打完一整行的字以後卻發現第一個字打錯了，這時候要怎麼辦？用滑鼠點就太慢了啦！按一下Home鍵就可以去修改第一個字了，這速度絕對比用滑鼠來的快，尤其中英打就是跟時間在競賽阿～ 打字越快就越高分xD，而且這些技巧其實知道的人並不多的說，我也是在學習vi的時候才知道的
