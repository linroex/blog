When I write articles on Windows and need to capture the screen, I usually use <a href="https://coder.tw/?p=1695">FSCapture</a>. But lately I have been writing some articles about Ubuntu, and I need to take screenshots for them. Ubuntu has a built-in screenshot function, but honestly it is very inconvenient. It doesn't save automatically, and the image format is always PNG. For someone like me who is used to FSCapture, that is hard to get used to. So I asked a netizen online whether there was any other screenshot software. A netizen nicknamed Sanmiao Wei recommended Shutter and even sent me a <a href="http://pcnoproblem.twbbs.org/ubuntu-shutter/">link</a> (thank you~). Then I found out that the site Brother Wei sent me happens to be run by a friend of mine XDD. What a coincidence~


<!--more-->


Shutter's features can't really compare with FSCapture, but for my very basic needs, it is more than enough. It has the basics, such as automatic saving, delayed capture, and saving in various formats. You can also edit images directly, so it is a pretty convenient screenshot program on Ubuntu~
<h2>Shutter Features</h2>
<ul>
	<li>Supports the three common capture modes: full screen, a specific area, and a window</li>
	<li>Can upload directly to web storage or FTP</li>
	<li>Built-in simple image editing</li>
	<li>Can save as JPEG</li>
</ul>

<h2>Shutter Basic Guide</h2>
1. Go to Applications → Accessories → Shutter to open Shutter

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122234.jpg"><img class="alignnone size-full wp-image-4407" title="2011-01-21_122234" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122234.jpg" alt="" width="363" height="456" /></a>

2. You can choose to capture the full screen, a window, or a specific area

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122528.jpg"><img class="alignnone size-large wp-image-4408" title="2011-01-21_122528" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122528-520x298.jpg" alt="" width="520" height="298" /></a>

3. After capturing, click the Edit button in the upper right to start editing

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122709.jpg"><img class="alignnone size-large wp-image-4409" title="2011-01-21_122709" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122709-520x372.jpg" alt="" width="520" height="372" /></a>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122934.jpg"><img class="alignnone size-large wp-image-4410" title="2011-01-21_122934" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_122934-520x366.jpg" alt="" width="520" height="366" /></a>

4. You can also go to Edit → Preferences to make more advanced settings

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123243.jpg"><img class="alignnone size-large wp-image-4411" title="2011-01-21_123243" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123243-520x372.jpg" alt="" width="520" height="372" /></a>

5. On the General tab, I recommend changing the default file format to JPEG, and deciding whether you want the mouse pointer included in your captures

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123401.jpg"><img class="alignnone size-large wp-image-4412" title="2011-01-21_123401" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123401-381x500.jpg" alt="" width="381" height="500" /></a>

6. On the Keyboard tab, you can set keyboard shortcuts for capturing

<a href="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123650.jpg"><img class="alignnone size-large wp-image-4413" title="2011-01-21_123650" src="{{< param imageBase >}}/wp-content/uploads/2011/01/2011-01-21_123650-386x500.jpg" alt="" width="386" height="500" /></a>

7. On the Upload tab, you can set where your screenshots go after capturing. I personally find this feature very useful
