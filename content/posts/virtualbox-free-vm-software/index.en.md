If you ask me which virtual machine program I like best, I'll tell you it's <a href="http://www.virtualbox.org/">VirtualBox</a>. The first reason is that I'm a poor student and can't afford the expensive <a href="http://www.vmware.com/tw/">VMware</a>, and VirtualBox is free. But that alone wouldn't stop me from using VMware, since VMware Player is free too. The other, more important reason is that VirtualBox performs very well. It handles virtual operating systems efficiently, unlike VirtualPC, which gets really laggy = =

In this post, I'll show you how to download and install VirtualBox. I'll cover how to use virtual machines another time, when I have some free time.
<h2>
<!--more-->
What is a virtual machine?</h2>
Simply put, a virtual machine lets you start another operating system while one is already running, so two operating systems exist at the same time. This is useful for hardcore PC gamers who want to play games in two windows, or for testing software. Ordinary computer users rarely need it. Because it runs two operating systems at once, it also uses a lot of performance, so computers with low specs or less than 2G of memory should not run a virtual machine....
<h2>VirtualBox features:</h2>
<ol>
	<li>Free</li>
	<li>Good performance</li>
	<li>Supports Windows, Linux, and Mac OS</li>
	<li>Built-in multiple language support (including Traditional Chinese)</li>
	<li>Small download size; unlike VMware, it doesn't take forever to download</li>
</ol>
<h2>VirtualBox download and installation guide:</h2>
1. First go to the <a href="http://www.virtualbox.org/">VirtualBox website</a>, click Downloads, and choose the version for your operating system. Below I can only demonstrate with Windows.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232515.jpg"><img class="alignnone size-large wp-image-3611" title="2010-08-01_232515" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232515-550x334.jpg" alt="" width="550" height="334" /></a>

2. After the download finishes, open the installer and click Run.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232858.jpg"><img class="alignnone size-large wp-image-3612" title="2010-08-01_232858" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232858-535x400.jpg" alt="" width="535" height="400" /></a>

3. Click Next.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232955.jpg"><img class="alignnone size-full wp-image-3613" title="2010-08-01_232955" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_232955.jpg" alt="" width="499" height="386" /></a>

4. Select I accept the terms in the License Agreement, then click Next.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233114.jpg"><img class="alignnone size-full wp-image-3614" title="2010-08-01_233114" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233114.jpg" alt="" width="499" height="386" /></a>

5. Click Next, unless you want to change the installation location.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233223.jpg"><img class="alignnone size-full wp-image-3615" title="2010-08-01_233223" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233223.jpg" alt="" width="499" height="386" /></a>

6. Click Next.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233243.jpg"><img class="alignnone size-full wp-image-3616" title="2010-08-01_233243" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233243.jpg" alt="" width="499" height="386" /></a>

7. Since I'm writing this on a laptop, a warning appears saying that installing on a laptop may be slow. Click Yes.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233352.jpg"><img class="alignnone size-full wp-image-3618" title="2010-08-01_233352" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233352.jpg" alt="" width="499" height="386" /></a>

8. Click Install.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233410.jpg"><img class="alignnone size-full wp-image-3619" title="2010-08-01_233410" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233410.jpg" alt="" width="499" height="386" /></a>

9. The installation starts. The network may disconnect during installation; this is normal. Once the installation finishes, reconnect and you'll be fine.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233522.jpg"><img class="alignnone size-full wp-image-3620" title="2010-08-01_233522" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_233522.jpg" alt="" width="499" height="386" /></a>

10. Installation complete. Click Finish.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_2344181.jpg"><img class="alignnone size-full wp-image-3622" title="2010-08-01_234418" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-01_2344181.jpg" alt="" width="499" height="386" /></a>

So far the installation is done, but the most important part is registration. The registration I mean here isn't paid registration. It's like Avast: you sign up for an account to activate your VirtualBox. However, since I had installed VirtualBox once before, I couldn't register this time, so you'll have to work out the rest of the registration on your own 0.0 Luckily, the software is in Chinese, so it shouldn't be too hard.
