How do you schedule a post in WordPress? Do you need a plugin? Actually, no — WordPress has a built-in scheduled posting feature, but it is hidden so cleverly that very few people ever find it. I only learned about it after seeing it on someone else's blog.

So how do you use scheduled posting? Follow the tutorial below and you are guaranteed to get it. If anything is unclear, feel free to ask me in the comments.


<!--more-->


1. Go to the post editing page and set the post to "Draft".

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_104942.jpg"><img class="alignnone size-full wp-image-1178" title="2009-05-31_104942" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_104942.jpg" alt="2009-05-31_104942" width="289" height="237" /></a>

2. Change the publish time to the time you want to schedule it for, then click "Schedule" and the post is scheduled.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_105055.jpg"><img class="alignnone size-full wp-image-1179" title="2009-05-31_105055" src="{{< param imageBase >}}/wp-content/uploads/2009/05/2009-05-31_105055.jpg" alt="2009-05-31_105055" width="287" height="325" /></a>

Simple, right? :) You can do it without any plugin at all. Still, WordPress hides it way too well! Do they not want anyone to discover this feature?
