今日は、自分で関数を書く方法を説明します。

まず、関数の文法を知っておく必要があります。また、自作の関数はプログラムの最下部に置かなければなりません。
<pre lang="vb">文法:

Function 関数名(Byval 引数 As 引数の型,Byval 引数 As 引数の型)

関数名=実行する内容

End Function</pre>
簡単に説明します。関数名は自由に決めてかまいません。関数名をダブルクォーテーションで囲む必要もありません。

引数はあってもなくてもかまいません。関数の性質によります。値を受け取る必要がある関数の場合は、引数を設定しなければなりません。


<!--more-->


引数をいくつまで設定できるかは、私もよく分かりません。ただ、各引数の間はカンマで区切る必要があります。

また、関数の中で実行する内容は、必ずしも関数名への代入である必要はありません。

ただし、どの関数も戻り値を持つ必要があります。

戻り値のない関数はエラーになります。

---------------------例----------------------

以下は、入力された数値が20より大きいかどうかを判定する関数です。
<pre lang="vb"> Public Function linroex(Byval x as object)as object

if x &gt; 20 then

linroex = true

else

linroex = false

end if

End Function</pre>
次に、作成した関数の呼び出し方を説明します。

呼び出しの形式は次のとおりです：

変数名=関数名(引数1,引数2)

もちろん、直接呼び出すこともできます。その場合は <span style="font-size: x-small;">"関数名(引数1,引数2)"</span> のようになります。

または、別の関数の中に入れることもできます。

&nbsp;

たとえば、msgbox 関数の中に入れると次のようになります：

msgbox(関数名(引数1,引数2))

先ほどの例の関数を使うと：

<span style="font-size: x-small;"> -------------------------------------------</span>

dim x

x = linroex(11)

msgbox(x)

-------------------------------------------

すると x=false になります。

または、msgbox の中に直接入れると次のようになります：

msgbox(linroex(12))
