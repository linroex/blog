If you're a web designer, or you run your own blog, you've probably cared a lot about how fast your pages load, since slow loading annoys users. And if you use Wretch Photo Album, you've probably worried about image sizes too, right? Wretch Photo Album has space limits, and the only way to get more space is to buy VIP membership. The program I'm introducing today is called RIOT, and it's a lifesaver for all of the people above. RIOT can <strong>batch compress images</strong>, and in my own tests the compression ratio was quite high. RIOT can also <strong>batch resize images</strong>, which is really handy for bloggers~

<h2>RIOT Usage Tutorial:</h2>
In this section, I'll show you how to batch compress images with RIOT.

1. Open the RIOT main program

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_000238.jpg"><img class="alignnone size-full wp-image-3641" title="2010-08-05_000238" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_000238.jpg" alt="" width="406" height="544" /></a>

2. Choose the image format you want to batch compress, then click 【Batch】

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001551.jpg"><img class="alignnone size-large wp-image-3646" title="2010-08-05_001551" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001551-546x400.jpg" alt="" width="546" height="400" /></a>

3. Click the 【Add Images】 button, then select the images you want to compress (you can select many at once)

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_000711.jpg"><img class="size-large wp-image-3644 alignnone" title="2010-08-05_000711" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_000711-550x370.jpg" alt="" width="550" height="370" /></a>

4. Click the 【Additional tasks】 button and choose the action you want. Resize changes the width and height of the image, and Compress to size compresses the image to within a specified size.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001300.jpg"><img class="alignnone size-large wp-image-3645" title="2010-08-05_001300" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001300-550x368.jpg" alt="" width="550" height="368" /></a>

5. Enter the width in the W field and the height in the H field. When an image's width or height exceeds the values you set, it's automatically scaled down to the specified dimensions. Also, enter the compression size in the 【Filesize threshold】 field, and the system will compress every image to that size (in KB).

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001800.jpg"><img class="alignnone size-large wp-image-3647" title="2010-08-05_001800" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_001800-550x368.jpg" alt="" width="550" height="368" /></a>

6. Set where the processed images will be saved in the 【Output Folder】 field, then click 【Start】 to begin processing

<a href="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_002027.jpg"><img class="alignnone size-large wp-image-3648" title="2010-08-05_002027" src="{{< param imageBase >}}/wp-content/uploads/2010/08/2010-08-05_002027-550x368.jpg" alt="" width="550" height="368" /></a>
