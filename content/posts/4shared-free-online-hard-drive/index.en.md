<strong><a href="http://www.4shared.com/">4Shared</a></strong> offers a free online hard drive with 10GB of total storage and a maximum of 200MB per file (I remember it used to be 100MB per file.....). It also supports external sharing links. One annoying thing is that you have to log in once every 30 days. Otherwise, your membership is canceled and all your uploaded files are deleted. 4Shared also uses a membership system, so you have to create an account before you can upload files. But the sign-up process is really simple, with only a few things to fill in~ You can also sign in directly with your Google account. Also, the file upload interface of <a href="http://www.4shared.com/">4Shared</a> is really cool. Take a look at the picture below and you'll see what I mean ^^


<!--more-->


In addition, <a href="http://www.4shared.com/">4Shared</a> supports desktop and mobile apps. That means you can install the 4Shared client on your computer or phone (smartphone) to upload files more conveniently. 4Shared also recently launched a Traditional Chinese interface, which should bring in many more users in Taiwan. By the way, among all the files on my blog, the 4Shared download count is the lowest. I heard it's because 4Shared didn't have a Chinese interface before.
<h2>1. Introduction to 4Shared</h2>
<ul>
	<li>Website: <a href="http://www.4shared.com/">http://www.4shared.com/</a></li>
	<li>Total storage: 10GB</li>
	<li>Max file size: 200MB</li>
	<li>File deletion: files are deleted if you don't log in for 30 days; otherwise, files are not deleted</li>
</ul>

<h2>2. Features of 4Shared</h2>
<ul>
	<li>Supports <a href="http://www.4shared.com/desktop/">desktop apps</a> and mobile apps</li>
	<li>Supports <a href="http://www.4shared.com/faq.jsp#q36">WebDAV</a> (so you can upload files directly from File Explorer on Windows, like Dropbox)</li>
	<li>Files can be shared via external links</li>
	<li>Supports direct login with OpenID and Google accounts</li>
	<li>You can set a password on individual files</li>
</ul>

<h2>3. How to Create a 4Shared Account</h2>
1. First, go to the <a href="http://www.4shared.com/signup.jsp">sign-up page</a>, fill in your details, and then click [Register]. If the interface is in English, you can change the language using the button in the top-right corner (see the picture below).

Note: For the plan, just choose FREE (the free account).

<h2>4. How to Use 4Shared Storage</h2>
This section covers the basics: logging in, uploading files, creating folders, and so on.
<h3>1. Logging in to 4Shared</h3>
By default, you're logged in right after you create your account. But if you ever get logged out, don't panic. Logging in is easy, especially now that there's a Traditional Chinese interface. Go to the home page, click [Log in], and a screen will appear for you to enter your username and password.

<a href="{{< param imageBase >}}/wp-content/uploads/2010/05/2010-05-15_103834.jpg"><img class="alignnone size-large wp-image-3126" title="2010-05-15_103834" src="{{< param imageBase >}}/wp-content/uploads/2010/05/2010-05-15_103834-500x303.jpg" alt="" width="500" height="303" /></a>
<h3>2. Creating a New Folder</h3>
The first thing to do after you enter the 4Shared interface is to create a folder. You don't have to, and things are fine at the beginning without one. But once you have more files, it gets messy, so I recommend creating a folder rather than uploading files to the root directory.

Click [New folder], enter a folder name, and choose whether to share this folder (in other words, whether people can download the files in it).
