アクセスしようとしたサイトがブロックされていた、という経験はありませんか？（たいていはアダルト動画ですが……）あるいは、ログインするときにうっかり打ち間違えて、IP をブロックされてしまったこともあるかもしれません。そんなときは、この記事で紹介する「プロキシ IP」（Proxy）を使えば対処できます。プロキシ IP（Proxy）とは、正確にはウェブプロキシのことで、ウェブを見ているあいだ身元を隠すことができます。魔法のように聞こえるかもしれませんが、仕組みはそれほど難しくありません。まずプロキシ IP（Proxy）のサーバーに接続し、そこから目的のサイトに接続するだけです。つまり、プロキシサーバーを経由してインターネットを使うことになるので、残る IP アドレスは自分のものではなくなります。ただし、これを悪いことに使うのはやめてください。プロキシ会社の多くはユーザーのデータを保存しているので、違法なことをすればきちんと追跡されてしまいますよ XD

<!--more-->


以下では、よく使われているオンラインのプロキシ IP をいくつか紹介します。オンラインのプロキシ IP の特徴は、設定がとても簡単なことです。アクセスしたいサイトの URL を渡すだけで、プロキシ経由で接続できます。こうしたサイトは使い方も簡単で、サイトを開くと URL を入力する欄がすぐに表示されます。そのため、多くのプロキシ IP は海外の会社が提供していますが、使うのは難しくありません。

	<li><a href="http://www.hidemyass.com/">HideMyAss.com</a></li>
	<li><a href="http://www.anonr.com/">Anonr.com</a></li>
	<li><a href="http://www.250.eu/">250.eu</a></li>
	<li><a href="http://www.unblock.biz/">Unblock.biz</a></li>
</ul>
