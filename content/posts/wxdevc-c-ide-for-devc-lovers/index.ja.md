C++ を学ぶ人の多くは、Dev C++ からスタートしています。VC++ は初心者にとって便利ではあるものの、標準的な C 言語（ANSI C）を学ぶことはできません。VC には .NET 専用の関数が多く含まれていて、ほかのコンパイラでコンパイルすると問題が起きてしまうからです。そのため、一般的な初心者は Dev C++ か Code::Blocks を使います。ただ非常に残念なことに、Dev C++ は数年間アップデートされておらず、新しい機能の多くもサポートされていません。一方、Code::Blocks の欠点は、中国語のサポートが弱いことです。コードに中国語が含まれていると問題が起きてしまい、コメントにも中国語を使えません。ここで紹介する wxDev C++ は、Dev C++ の特徴を受け継ぎつつ、新しい機能も追加されたソフトウェアです。Dev C++ のように問題だらけということがありません……。そのため、もし Dev C++ に慣れているなら、wxDev C++ を使うことをおすすめします。ほとんど Dev C++ と同じなので！ 私は引き続き自分の Code::Blocks を使うことにします～

<h2>wxDevC++ インストール手順</h2>
1.インストーラーを実行し、【I Agree】を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235241.jpg"><img class="alignnone size-full wp-image-468" title="2011-05-17_235241" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235241.jpg" alt="" width="503" height="389" /></a>

2.インストールするコンポーネントを選ぶ画面です。初期値のまま【Next】をクリックしてください。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235414.jpg"><img class="alignnone size-full wp-image-469" title="2011-05-17_235414" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235414.jpg" alt="" width="503" height="389" /></a>

3.いつもどおり、そのまま【Next】を押せば OK です。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235507.jpg"><img class="alignnone size-full wp-image-470" title="2011-05-17_235507" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235507.jpg" alt="" width="503" height="389" /></a>

4.インストール先のフォルダーを聞かれます。特に決まりがなければ、【Install】を押せばインストールが始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235619.jpg"><img class="alignnone size-full wp-image-471" title="2011-05-17_235619" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235619.jpg" alt="" width="503" height="389" /></a>

5.インストール中です。しばらくお待ちください。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235703.jpg"><img class="alignnone size-full wp-image-472" title="2011-05-17_235703" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-17_235703.jpg" alt="" width="503" height="389" /></a>

6.インストールが完了したら、【Close】をクリックしてください。

<h2>wxDev C++ の初回起動</h2>
初めて wxDev C++ を使うときは、言語や IDE のスタイルなどの設定が必要です。設定方法は Dev C++ とほぼ同じなので、Dev C++ を使ったことがある方は、この章を読まずに自分で操作しても大丈夫です。

1.wxDev C++ を起動し、【Chinese（TW）】を選んで【Next】を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000056.jpg"><img class="alignnone size-full wp-image-474" title="2011-05-18_000056" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000056.jpg" alt="" width="422" height="323" /></a>

2.【Yes】を選び、【Next】を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000256.jpg"><img class="alignnone size-full wp-image-475" title="2011-05-18_000256" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000256.jpg" alt="" width="422" height="323" /></a>

3.キャッシュ用の領域を作成するという内容のようです。よく分かりませんが、【Yes】を選び、【Next】を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000344.jpg"><img class="alignnone size-full wp-image-476" title="2011-05-18_000344" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000344.jpg" alt="" width="422" height="323" /></a>

4.設定中です。しばらくお待ちください。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000459.jpg"><img class="alignnone size-full wp-image-477" title="2011-05-18_000459" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-18_000459.jpg" alt="" width="422" height="323" /></a>

5.【OK】を押せば完了です～ 自動的に wxDev C++ が起動します。
