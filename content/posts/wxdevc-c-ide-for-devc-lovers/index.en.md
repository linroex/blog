A lot of people who learn C++ actually start with Dev C++. VC++ is convenient for beginners, sure, but you can't learn standard C (ANSI C) with it, because VC contains far too many functions that belong to .NET — compile that code with another compiler and you'll run into trouble. So beginners generally go with Dev C++ or Code::Blocks. Unfortunately, Dev C++ hasn't been updated for several years, and it no longer supports many newer features. Code::Blocks, on the other hand, has poor Chinese support: if there's Chinese anywhere in your code you'll run into problems, and that includes not being able to use Chinese in comments. The one I want to recommend here, wxDev C++, actually carries on Dev C++'s characteristics while adding some new features, unlike Dev C++ which has no end of problems... So if you're comfortable with Dev C++, I'd suggest giving wxDev C++ a try, because it's almost identical to Dev C++! As for me, I'll just keep using my Code::blocks～

<h2>Using wxDev C++ for the first time</h2>
The first time you use wxDev C++ you'll need to configure a few things, such as the language and the IDE style. The setup is almost identical to Dev C++, so if you've used Dev C++ before you can skip this section and just do it yourself.

1. Start the wxDev C++ main program, select 【Chinese（TW）】, then click 【Next】

2. Select 【Yes】, then click 【Next】
