The Jeremy Brand Answer Machine, an auto-answering program for instant messengers, is yet another program by my good friend Jeremy, as the name suggests. The biggest feature of <span style="font-size: 13px;">Jeremy Brand Answer Machine</span> is that it supports automatic replies on any version of an instant messenger. I think most people who have used an instant messenger have rarely seen an auto-reply tool for one. Usually only MSN has one. My guess is that's because Yahoo doesn't open up its plugin interface, so there are almost no plugins for its instant messenger. So how does Jeremy Brand Answer Machine send auto-replies? The principle is simple, somewhat like a "craftsman's philosophy" (a plain, hands-on, brute-force approach): when the instant messenger window pops up, the program just sends a message to that window to produce the reply. And because Jeremy Brand Answer Machine doesn't use any instant messenger API, it works with any version. Below, let me introduce the Jeremy Brand Answer Machine!

<h3>Tutorial</h3>
1. Pick any download link from the Program Information section, download the Jeremy Brand Answer Machine, and unzip it.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111318.jpg"><img class="alignnone size-large wp-image-2374" title="2009-12-13_111318" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111318-500x375.jpg" alt="2009-12-13_111318" width="500" height="375" /></a>

2. Open the main program (the one with the microphone icon).

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111512.jpg"><img class="alignnone size-large wp-image-2375" title="2009-12-13_111512" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111512-500x375.jpg" alt="2009-12-13_111512" width="500" height="375" /></a>

3. The first time you use it, you may see the window shown below. Just click Continue. V1.8 fixes this bug.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111649.jpg"><img class="alignnone size-full wp-image-2376" title="2009-12-13_111649" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_111649.jpg" alt="2009-12-13_111649" width="439" height="167" /></a>

4. Next, click the downward arrow in the lower-left corner and select Coordinate Settings.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_113204.jpg"><img class="alignnone size-full wp-image-2377" title="2009-12-13_113204" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_113204.jpg" alt="2009-12-13_113204" width="489" height="522" /></a>

5. Open your instant messenger or MSN, open any chat window, and maximize it. Then click in the text input box and press <span style="text-decoration: line-through;">the End or Home key</span> (press Home to auto-reply on the instant messenger, and End to auto-reply on MSN). Once you've made the settings, click Save Settings.

<span style="color: #ff0000;"><strong>Note: In fact, you need to press both the Home and End keys. Also, if your instant messenger has been updated, you need to set it up again.</strong></span>

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_113723.jpg"><img class="alignnone size-full wp-image-2378" title="2009-12-13_113723" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_113723.jpg" alt="2009-12-13_113723" width="605" height="368" /></a>

6. Next, enter the messages you want to send as auto-replies in the auto-reply message fields for the instant messenger and MSN. You can enter up to three sets. (If you can't type Chinese, copy and paste the text in instead.)

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_114216.jpg"><img class="alignnone size-full wp-image-2379" title="2009-12-13_114216" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_114216.jpg" alt="2009-12-13_114216" width="489" height="522" /></a>

7. After setting up the auto-reply section, you can go to the Options section. You can basically leave the defaults. When everything is set, click Start Answering, and the program will close all other windows. Have a friend message you to test it.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_114551.jpg"><img class="alignnone size-full wp-image-2380" title="2009-12-13_114551" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-13_114551.jpg" alt="2009-12-13_114551" width="489" height="522" /></a>

8. The program also automatically logs your replies and shows them in the detailed log.
