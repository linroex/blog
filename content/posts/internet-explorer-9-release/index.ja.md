ついに Microsoft がまともなものを出してきました。Microsoft のアップデートはいつも少しずつ進歩してきたのは確かですが、その進歩はほとんど小さなものでした。IE でいえば、IE7、IE8、IE6 の違いはごくわずかでした。Firefox や Chrome のように、アップデートのたびにショックを与えてくれるものとは違いました。しかし今回の IE9 は、正直に言ってかなり進歩しています。少なくとも速度は十分に速くなりました。セキュリティも向上しています。そして、IE8 で大きく批判されていたタブ機能も、ずっと使いやすくなりました。IE8 でタブを開くと、クラッシュしてしまうこともあったのですが…。


<!--more-->
実のところ、IE9 はパフォーマンスが向上しただけではありません。HTML5 やハードウェアアクセラレーションなど、新世代のブラウザーの機能もサポートしています。さらに、トラッキング防止機能を先駆けて内蔵しています。トラッキング防止とは、Web サイトを閲覧している間に、IP アドレスやブラウザー、都市などのデータを収集されないようにする機能です。この機能は Web の世界に大きな影響を与えると思います…。メリットもデメリットもあります。プライバシーの保護を大きく強化する一方で、サイト運営者が訪問者のデータを分析して、サイトを改善することが難しくなるかもしれません。広告業者も影響を受けるでしょう。機能面の進歩だけでなく、IE 9 はついにトレンドに合わせて、ブラウザーのインターフェースをすっきりとデザインしました。このトレンドは Chrome が火をつけたものだったと記憶しています。今では Firefox 4 と IE 9 もその道を歩んでいますね〜。ただ、古いインターフェースに慣れている方にとっては、戸惑うというデメリットもあります。

ここまでは一般のユーザーへの影響でした。では、開発者や Web デザイナーにとって新しい機能はあるのでしょうか？ 答えは「あります」です〜。IE9 では F12 キーを押すだけで開発者モードを開き、CSS や JavaScript に問題がないかチェックできます。機能もかなり充実していますよ〜。

<h2>IE9 のダウンロードとインストール手順</h2>
1. まず Internet Explorer 9 の公式サイトにアクセスして、繁体字中国語版のインストーラーをダウンロードします。お使いのバージョンを選んで【今すぐダウンロード】をクリックしてください。現在は Windows 7 のユーザーのみ利用できます。

ダウンロードページ：<a href="http://windows.microsoft.com/zh-TW/internet-explorer/downloads/ie">http://windows.microsoft.com/zh-TW/internet-explorer/downloads/ie</a>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_190749.jpg"><img class="alignnone size-large wp-image-4919" title="2011-03-19_190749" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_190749-520x323.jpg" alt="" width="520" height="323" /></a>

2. インターネットに接続した状態でインストーラーを実行してください。自動的にダウンロードが始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_190952.jpg"><img class="alignnone size-full wp-image-4920" title="2011-03-19_190952" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_190952.jpg" alt="" width="486" height="190" /></a>

3. ダウンロードが完了すると、下の画像のウィンドウが表示されます。インストールを続けるには一部のプログラムを閉じる必要があると表示されます。または再起動することもできます。どちらか好きな方を選んでください。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191259.jpg"><img class="alignnone size-large wp-image-4921" title="2011-03-19_191259" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191259-504x500.jpg" alt="" width="504" height="500" /></a>

4. 自動的にインストールが進みます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191623.jpg"><img class="alignnone size-full wp-image-4923" title="2011-03-19_191623" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191623.jpg" alt="" width="486" height="190" /></a>

5. インストールが完了すると、コンピューターを再起動するかどうか尋ねられます。どちらにするかはお好みでどうぞ〜

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191921.jpg"><img class="alignnone size-full wp-image-4924" title="2011-03-19_191921" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-19_191921.jpg" alt="" width="492" height="162" /></a>

<strong>まとめ：</strong>Internet Explorer 9 は大きく進歩しましたが、Chrome や Firefox と比べると、まだ大きな差があります。表示速度は向上したものの、ほかのブラウザーと比べるとまだ大きく見劣りします。HTML5 のサポート状況も、有名なブラウザーの中で最も低いです。そのため、IE に特別な思い入れがない限りは、Firefox か Chrome を試してみることをおすすめします。待つことなくインターネットができることに気づくはずです。ページの読み込みが一瞬なんですよ！
