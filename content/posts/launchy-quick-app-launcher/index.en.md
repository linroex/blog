I introduced Google Desktop to you before. It can quickly open files and programs. Launchy works in a similar way, but it focuses on quickly launching programs, so it doesn't have as many features as Google Desktop. Google Desktop can search files and has a sidebar, while Launchy only does file search. Its file search works differently, though. You specify folders, and Launchy builds an index of the files in those folders before you search. Google Desktop indexes the files on every hard drive. The difference is that when you type a keyword, Launchy may show more accurate results, while Google Desktop may show results you don't want.


<!--more-->


What does quickly opening a program mean? For example, if your computer has all kinds of strange programs and games installed, like mine does, then when you need to open a program you usually have two options: go to Start -> All Programs and look through them one by one, or search on the desktop. Now that you have Launchy, you have a faster option: press a keyboard shortcut to bring up the Launchy search box, type a keyword, and you're done~

<h2>Launchy Usage Guide</h2>
1.Open the Launchy main program (look under Start → Programs)

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004147_thumb.jpg"><img style="background-image: none; padding-left: 0px; padding-right: 0px; display: inline; padding-top: 0px; border: 0px initial initial;" title="2011-03-01_004147" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004147_thumb.jpg" border="0" alt="2011-03-01_004147" width="411" height="518" /></a>

2.Right-click the Launchy window → 【Options】

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004256_thumb.jpg"><img style="background-image: none; padding-left: 0px; padding-right: 0px; display: inline; padding-top: 0px; border: 0px initial initial;" title="2011-03-01_004256" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004256_thumb.jpg" border="0" alt="2011-03-01_004256" width="473" height="211" /></a>

3.Click 【Catalog】, and you can set which folders Launchy should index. You can also set it to index only files with certain extensions.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004350_thumb.jpg"><img style="background-image: none; padding-left: 0px; padding-right: 0px; display: inline; padding-top: 0px; border: 0px initial initial;" title="2011-03-01_004350" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004350_thumb.jpg" border="0" alt="2011-03-01_004350" width="520" height="399" /></a>

If you want to launch programs quickly, add the folder where you usually install programs to Launchy and set the file extension to exe. Or you can keep the default settings. If you want to quickly open Word and Excel documents, set the extensions to doc and xls.

4.After setting the folders to index, click 【Scan Directories】, then click 【OK】 to save the settings.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004820_thumb.jpg"><img style="background-image: none; padding-left: 0px; padding-right: 0px; display: inline; padding-top: 0px; border: 0px initial initial;" title="2011-03-01_004820" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004820_thumb.jpg" border="0" alt="2011-03-01_004820" width="520" height="399" /></a>

5.You can also set the hotkey that opens Launchy under 【General】→【hotkey】. When you press the hotkey, Launchy runs, and then you can type a keyword to open programs.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004927_thumb.jpg"><img style="background-image: none; padding-left: 0px; padding-right: 0px; display: inline; padding-top: 0px; border: 0px initial initial;" title="2011-03-01_004927" src="{{< param imageBase >}}/wp-content/uploads/2011/03/2011-03-01_004927_thumb.jpg" border="0" alt="2011-03-01_004927" width="520" height="399" /></a>

6.Type a keyword and Launchy shows the files it found. It works a lot like Google Desktop.
