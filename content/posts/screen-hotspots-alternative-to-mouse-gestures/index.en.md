If you're still using old-fashioned mouse gestures, you're behind the times! In this article I'd like to introduce a program called <strong>Screen Hotspots</strong>. It was designed by Jeremy (Cang Hai), a friend of the site owner, and it's modeled on the <strong>Screen Hotspots</strong> feature on Mac OS. <strong>Screen hotspots</strong> work a lot like mouse gestures, except that with mouse gestures you have to draw a shape with the mouse, while with <strong>screen hotspots</strong> you just move the mouse to a certain spot on the screen to run a preset action. Screen hotspots were never available on Windows before, but now Cang Hai has developed this <strong>Screen Hotspots</strong> program, so Windows users can enjoy this fun feature too!


<!--more-->


For now, Screen Hotspots can only be used for functions like logging out, shutting down, and turning off the screen. Cang Hai may add more features in the future, and anyone with suggestions for this program is welcome to leave a comment on this article.

<h3>Tutorial</h3>
1. First, download the file, extract it, and double-click the main Screen Hotspots program.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_144932.jpg"><img class="alignnone size-large wp-image-2362" title="2009-12-12_144932" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_144932-500x375.jpg" alt="2009-12-12_144932" width="500" height="375" /></a>

2. By default, the program minimizes to the system tray (the lower-right corner of the screen). Right-click the logo and choose Settings to open the settings window.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_145839.jpg"><img class="alignnone size-full wp-image-2363" title="2009-12-12_145839" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_145839.jpg" alt="2009-12-12_145839" width="281" height="148" /></a>

3. Screen Hotspots can be set up in each of the four corners of the screen. In this example, I'll use the upper-left corner. First, open the drop-down button at the upper left, then choose the action you want to run (log out, shut down, show desktop, screen saver, and so on).

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_150702.jpg"><img class="alignnone size-large wp-image-2364" title="2009-12-12_150702" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_150702-304x400.jpg" alt="2009-12-12_150702" width="304" height="400" /></a>

4. Next, decide whether to confirm before the action runs. Sometimes your mouse may happen to rest inside a hotspot, and if that hotspot is set to shut down, your computer will suddenly show a "shutting down" message XD

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_151123.jpg"><img class="alignnone size-large wp-image-2366" title="2009-12-12_151123" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_151123-304x400.jpg" alt="2009-12-12_151123" width="304" height="400" /></a>

5. After choosing whether to confirm, click Save. If the settings window doesn't hide itself after saving, click the minimize button in the upper-right corner of the window to hide it. Whatever you do, don't click the close button~

<a href="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_151442.jpg"><img class="alignnone size-large wp-image-2367" title="2009-12-12_151442" src="{{< param imageBase >}}/wp-content/uploads/2009/12/2009-12-12_151442-304x400.jpg" alt="2009-12-12_151442" width="304" height="400" /></a>

6. After saving your settings, move your mouse to the upper-left corner and give it a try ^^

Summary: According to the site owner's own testing, this program is quite useful, but it has some bugs. For example, the show-desktop feature works only some of the time when Chrome is open, and the turn-off-screen feature doesn't work on older monitors. The program also has rather few features, so it can't really be compared with mouse gestures yet.
