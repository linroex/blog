Terminal で実行するコマンドの実行時間を計測しようと考えたことはありますか？ 最近、仕事の必要から、さまざまなコマンドを組み合わせてファイル分類ツールを作りました。しかし、性能に厳しい要件があり、指定された時間内に終わらせる必要がありました。そこで、コマンドの実行時間を計測できる便利な time コマンドを調べました。


<!--more-->


実行時間を計測するには、プログラムの終了時刻から実行前の時刻を引くのが直感的な方法でしょう。しかし、この方法は少し面倒です。Linux や macOS では、実行時間を計測したいコマンドの前に time を付けるだけで、そのコマンドが消費した CPU 時間と実行にかかった時間がわかります。たとえば、curl にどれくらい時間がかかるかを知りたいとします：
<pre>time curl -XGET "https://coder.tw"</pre>
一番下に、次のような一行が表示されます：「curl -XGET "https://coder.tw" 0.01s user 0.02s system 2% cpu 1.325 total」

これは、curl が実行に合計 1.325 秒かかり、CPU 時間の 2% を使ったことを意味します。
