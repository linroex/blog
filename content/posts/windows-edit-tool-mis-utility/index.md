Windows Edit Tool這套程式內鍵很多修改功能,可以幫助你設定你的電腦的登錄檔資料,Windows Edit Tool這套程式裏面我個人比較喜歡的功能有自動登陸XP帳戶,還有Windows Edit Tool的基本優化功能,這些功能都是站長試過沒有問題的功能,因為都只是單純修改登錄檔而已,還有Windows Edit Tool裡面有一個功能是隱藏磁碟機,其實說白一點就是你下載了一些不可告人的東西時~可以把它存在隱藏磁碟機裡面,防止不該看到的人看到

<h2>Windows Edit Tool主要功能:</h2>
<ol>
	<li>禁用USB/禁用IE下載/禁用登陸檔編輯器(Regedit)</li>
	<li>將USB設唯獨</li>
	<li>Windows自動登入</li>
	<li>關閉資訊安全中心的警示</li>
	<li>電腦優化與L2快取修改(L2 Cache)</li>
</ol>
