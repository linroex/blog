Windows Edit Tool has many built-in tweaks that let you configure your computer's registry settings. The features I personally like best in Windows Edit Tool are automatic logon for XP accounts and its basic optimization functions. I've tested these myself and they work fine, since they only make simple changes to the registry. Windows Edit Tool also has a drive-hiding feature. Put simply, if you've downloaded some things you'd rather keep private~ you can store them on a hidden drive so the wrong people won't see them.
