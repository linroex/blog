Windows Edit Tool には、パソコンのレジストリ設定を変更できる機能が数多く備わっています。私が個人的に気に入っている機能は、XP アカウントの自動ログインと、基本的な最適化機能です。どちらもレジストリを少し変更するだけのものなので、私自身が試して問題がなかったものです。また、Windows Edit Tool にはドライブを隠す機能もあります。平たく言えば、人に見られたくないものをダウンロードしてしまったときに、隠しドライブに保存しておけば、見られてはいけない人の目に触れずに済む、というわけです。

<h2>Windows Edit Tool の主な機能：</h2>
<ol>
	<li>USB・IE のダウンロード・レジストリエディタ（Regedit）の無効化</li>
	<li>USB を読み取り専用に設定</li>
	<li>Windows の自動ログイン</li>
	<li>セキュリティセンターの警告を無効化</li>
	<li>パソコンの最適化と L2 キャッシュの変更（L2 Cache）</li>
</ol>
p.s. このプログラムを使うには .NET Framework 2.0 以降のインストールが必要です。
