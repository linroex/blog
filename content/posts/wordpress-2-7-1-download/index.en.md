Today I'd like to introduce a package for building blogs — WordPress.

It's a program that lets you set up a blog very easily.

It's written in PHP.

In the future, this site will publish more related tutorials.

Its latest version right now is 2.7.1.

One of my favorite features is its heavy use of Ajax.

You don't have to reload the page every time you organize it.

It also supports a lot of plugins and themes.

So you don't have to figure out how to lay out your interface yourself.

For people who don't know CSS, this is a real blessing.

Also, it's an open-source package.

That means if there's anything inside it you're not happy with, you can modify it yourself.

In effect, it gives me a great place to practice web programming.

Here are some things to note when setting up WP.

If you want to set it up on your own host, you just need to install AppServ.

But if you want to put it on a web hosting space,

you first have to make sure the provider offering the space provides PHP and MySQL services.

Without these services, you can't set it up at all.
