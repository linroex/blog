今日は、ブログを作るためのパッケージソフト「WordPress」をご紹介します。

WordPress は、とても簡単にブログを立ち上げられるプログラムです。

PHP で書かれています。

今後、このサイトでも関連するチュートリアルを順次公開していく予定です。

現在の最新バージョンは 2.7.1 です。

私が特に気に入っている特徴は、Ajax 技術が多用されている点です。

ページを整えるたびに再読み込みする必要がありません。

さらに、多くのプラグインやテーマに対応しています。

そのため、インターフェースのレイアウトを自分で考える必要がありません。

CSS がわからない人にとっては、非常にありがたい存在です。

また、オープンソースのパッケージです。

つまり、内部に不満な点があれば、自分で手を加えて修正できます。

私にとっては、Web プログラミングを練習するのにちょうどよい場所でもあります。

以下は WordPress を設置する際の注意事項です。

自分のサーバーに設置する場合は、AppServ をインストールするだけで十分です。

一方、インターネット上のレンタルスペースに置く場合は、

まず、そのスペースを提供している会社が PHP と MySQL のサービスを提供しているかを確認する必要があります。

これらがなければ、そもそも WordPress を設置できません。
