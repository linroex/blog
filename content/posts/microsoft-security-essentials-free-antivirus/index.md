<a href="http://gordon168.tw/?p=322">Microsoft Security Essentials </a>是由微軟提供的一套「免費」防毒軟體，他的最大特色就在於他是免費的！而且他還是俗稱M$提供的～ Microsoft Security Essentials 這套防毒軟體的的效能還算可以，防毒能力也算堪用，如果你電腦剛安裝好，然後又對微軟的東西情有獨鍾，那我建議妳可以來是看看這套防毒軟體

<!--more-->


最近微軟一直在發展防毒軟體，像Microsoft Security Essentials其實很早就出現了，只是它最早的版本說實話並不好用（1.0），一直到現在2.0版本才比較好用，我想再不久的將來可能連Windows作業系統都會內建這套防毒軟體吧？
<h2>Microsoft Security Essentials 特色</h2>
<ul>
	<li>與IE整合完整</li>
	<li>內建網路檢查系統</li>
	<li>動態病毒碼技術</li>
	<li>與Windows內建防火牆整合... （也就是說它沒有內建防火牆）</li>
</ul>
<h2>Microsoft Security Essentials 資訊</h2>

<h2>掃描教學</h2>
1.開啟Microsoft Security Essentials，然後選擇妳要使用的掃描模式，例如：快速、完整、自定
<ul>
	<li>快速：用最快的速度檢查一次電腦</li>
	<li>完整：仔細的檢查，但是速度慢</li>
	<li>自定：自行設定要掃描哪些資料夾、硬碟</li>
</ul>
2.按下立即掃描就會開始掃描了

<h2>結語：</h2>
跟我平常習慣使用的Avast比起來，Microsoft Security Essentials仍然太弱了些，但是跟一些其他的免費防毒軟體比起來它已經算是可以了，但是說真的，Microsoft Security Essentials的功能太少了，雖然基本的防毒軟體該有的功能都有，但更進階就沒有了，例如沙盒、防火牆等功能，而且掃描時它的選項也只有三種，不像其他防毒軟體的掃描選項很細，所以總體來說我只會給它70分
