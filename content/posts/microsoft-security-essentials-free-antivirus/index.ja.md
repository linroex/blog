<a href="http://gordon168.tw/?p=322">Microsoft Security Essentials </a>は Microsoft が提供している「無料」のアンチウイルスソフトです。最大の特徴は、もちろん無料であることです！ 通称 M$ と呼ばれる会社が提供しているソフトでもあります～ Microsoft Security Essentials の性能はそれなりに良く、ウイルス対策の能力も十分実用的です。パソコンを買ったばかりで、Microsoft の製品が好きな方なら、このソフトをチェックしてみることをおすすめします。


<!--more-->


最近、Microsoft はアンチウイルスソフトの開発に力を入れています。Microsoft Security Essentials も実はかなり前から存在していましたが、最初のバージョン（1.0）は正直なところあまり使いものになりませんでした。2.0 になってようやく使いやすくなりました。近い将来、Windows 自体にこのウイルス対策ソフトが組み込まれる日も来るかもしれません～
<h2>Microsoft Security Essentials の特徴</h2>
<ul>
	<li>IE との統合がしっかりしている</li>
	<li>ネットワークのチェック機能を内蔵</li>
	<li>動的なウイルス定義（ウイルスシグネチャ）技術</li>
	<li>Windows 標準のファイアウォールと統合……（つまり、独自のファイアウォールは含まれていません）</li>
</ul>
<h2>Microsoft Security Essentials の情報</h2>
<ul>
	<li>公式サイト：<a href="http://www.microsoft.com/zh-tw/security_essentials/Default.aspx">http://www.microsoft.com/zh-tw/security_essentials/Default.aspx</a></li>
	<li>バージョン：2.0</li>
	<li>ダウンロードリンク：<a href="http://www.4shared.com/file/BdBZWEVJ/mseinstall.html ">4Shared</a>｜<a href="http://www.box.net/shared/iqupv4pzap">Box.net</a> ｜<a href="http://www.microsoft.com/zh-tw/security_essentials/Default.aspx">公式ダウンロードページ</a></li>
</ul>
<strong>P.S. こちらで用意したダウンロードリンクは、Vista / Win 7 の 64 ビット版です</strong>
<h2>Microsoft Security Essentials の使い方</h2>
ここでは、インストールとウイルス定義の更新方法を紹介します。インストーラーにはウイルス定義が含まれていないので、インストールの直後に必ず更新が必要です。更新しないと、ソフトが使えないので注意してください……。

1. インストーラーを実行し、【次へ】を押します。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_183228.jpg"><img class="alignnone size-large wp-image-5062" title="2011-04-30_183228" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_183228-520x323.jpg" alt="" width="520" height="323" /></a>

2. 【同意する】を選びます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_183359.jpg"><img class="alignnone size-large wp-image-5063" title="2011-04-30_183359" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_183359-520x323.jpg" alt="" width="520" height="323" /></a>

3. 「顧客エクスペリエンス向上プログラム」に参加するかどうか聞かれます。つまり、ソフトを改良するために、パソコン内のデータの一部が Microsoft に送信される仕組みです。プライバシーが気になる方は、「プログラムには参加しない」をクリックしてください~

4. ここでは、Windows のファイアウォールを有効にするよう促されているだけです。【次へ】をクリックします。

<h2>スキャンの使い方</h2>
1. Microsoft Security Essentials を開き、「クイック」「フル」「カスタム」など、使いたいスキャンモードを選びます。
<ul>
	<li>クイック：できるだけ速くパソコンを一度チェックします</li>
	<li>フル：念入りにチェックしますが、時間がかかります</li>
	<li>カスタム：スキャンするフォルダやドライブを自分で指定できます</li>
</ul>
2. 【今すぐスキャン】を押すと、スキャンが始まります。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_191613.jpg"><img class="alignnone size-large wp-image-5074" title="2011-04-30_191613" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_191613-520x364.jpg" alt="" width="520" height="364" /></a>

先ほど「カスタム」を選んでいた場合は、【今すぐスキャン】を押すと、どこをスキャンするか聞かれます。

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_191710.jpg"><img class="alignnone size-full wp-image-5075" title="2011-04-30_191710" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-30_191710.jpg" alt="" width="490" height="382" /></a>

3. スキャン中～

<h2>まとめ：</h2>
普段使っている Avast と比べると、Microsoft Security Essentials はまだ少し物足りないと感じます。ただ、ほかの無料のウイルス対策ソフトと比べれば、十分に使えるレベルです。とはいえ正直に言うと、Microsoft Security Essentials は機能が少なすぎます。ウイルス対策ソフトとして基本的な機能は揃っていますが、サンドボックスやファイアウォールといった、より高度な機能はありません。また、スキャンの選択肢も3種類しかなく、ほかのウイルス対策ソフトのように細かく設定できるわけではありません。そのため、総合的に見ると 70 点あげるのが精一杯です。
