<a href="http://gordon168.tw/?p=322">Microsoft Security Essentials </a>is a "free" antivirus program offered by Microsoft. Its biggest feature is that it's free! It's also from the company that people affectionately call M$. Microsoft Security Essentials performs reasonably well, and its virus protection is decent. If you've just set up a new computer and you're a fan of Microsoft products, I suggest you take a look at this antivirus.


<!--more-->


Microsoft has been developing antivirus software recently. Microsoft Security Essentials has actually been around for a while, but its earliest version (1.0) was honestly not very good. It only became useful with version 2.0. I think in the not-too-distant future, even Windows itself might come with this antivirus built in~
<h2>Microsoft Security Essentials Features</h2>
<ul>
	<li>Fully integrated with IE</li>
	<li>Built-in network inspection system</li>
	<li>Dynamic virus signature technology</li>
	<li>Integrated with the Windows built-in firewall... (in other words, it doesn't include a firewall of its own)</li>
</ul>

<h2>Scanning Tutorial</h2>
1. Open Microsoft Security Essentials, then choose the scan mode you want, such as Quick, Full, or Custom.
<ul>
	<li>Quick: checks your computer once, as fast as possible</li>
	<li>Full: a thorough check, but slow</li>
	<li>Custom: lets you choose which folders and drives to scan</li>
</ul>
2. Click [Scan now] to start scanning.

<h2>Conclusion:</h2>
Compared with Avast, which I usually use, Microsoft Security Essentials is still a bit weak. But compared with some other free antivirus programs, it's decent enough. Honestly, though, Microsoft Security Essentials has too few features. It has all the basic functions an antivirus should have, but it lacks more advanced features such as a sandbox or a firewall. Its scan options are also limited to three, while other antivirus programs offer much more detailed scan options. So overall, I'd only give it 70 points.
