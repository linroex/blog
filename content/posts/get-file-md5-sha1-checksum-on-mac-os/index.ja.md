以前は Windows で、何をするにも別途プログラムをインストールする習慣がありました。画像を見るにも、PDF を開くにも、さらにはファイルの MD5 や SHA1 を計算するにも、別のソフトが必要でした。しかし Mac OS X ではそこまで面倒ではありません！ ファイルの MD5 や SHA1 チェックサムを計算したい場合も、標準で使える小さなツールがあります。


<!--more-->


チェックサムは、ファイルが完全であることを確認するために使われます。こんな場面を想像してください。Apple の公式サイトからファイルをダウンロードしたのに、あなたのネットワークはすでにハッカーに狙われていて、そのファイルが改ざんされたものにこっそり差し替えられている……。そして、あなたのパソコンは感染してしまうのです。

チェックサムは、こうした問題の一部を防ぐのに役立ちます。通常、ファイルの提供者はあらかじめチェックサムを計算し、それをウェブサイトに掲載しておきます。ファイルをダウンロードしたら、もう一度チェックサムを計算して比較します。自分で計算した値がウェブサイトの値と一致すれば、ファイルは改変されていないと判断できます。MD5 のハッシュ値は 1 ビットでも変わると変化するからです。もちろん、ウェブサイト自体が攻撃されていたら、その限りではありませんが……。

では、どうやって計算するのでしょうか？ もちろん手で計算するわけではありません！ コンピュータに任せましょう！
<h2>MD5 チェックサムを計算する</h2>
<pre>openssl md5 file_path</pre>
<h2>SHA1 チェックサムを計算する</h2>
<pre>openssl sha1 file_path</pre>
