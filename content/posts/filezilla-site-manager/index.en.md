FileZilla is an FTP client that many people use today, and one handy feature is Site Manager. Because I manage websites myself, I often need FTP. Every time I wanted to connect, I had to enter the address, username, password, and other details, which wasted a lot of time. But once I set up Site Manager, I only need to fill in the details once, and from then on I can connect directly without typing all that information again~
<h2>
<!--more-->
Site Manager Tutorial</h2>
1. After opening FileZilla, click "File" → "Site Manager" in the upper-left corner.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_013702.jpg"><img class="alignnone size-large wp-image-5109" title="2011-05-21_013702" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_013702-520x431.jpg" alt="" width="520" height="431" /></a>

2. Click "New Site" and set up your FTP connection details. For Host, enter your FTP address. The protocol and port usually don't need to be changed.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_013811.jpg"><img class="alignnone size-large wp-image-5110" title="2011-05-21_013811" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_013811-520x416.jpg" alt="" width="520" height="416" /></a>

3. The thing to watch out for is the "Logon Type" section. The default is Anonymous, but usually we want FileZilla to log in automatically for us. So choose "Normal," then enter your username and password below.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014102.jpg"><img class="alignnone size-large wp-image-5111" title="2011-05-21_014102" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014102-520x416.jpg" alt="" width="520" height="416" /></a>

4. You can also click "Rename" to give the site a name so it's easy to pick out, for example "Blog 1," "Blog 2," and so on~

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014313.jpg"><img class="alignnone size-large wp-image-5113" title="2011-05-21_014313" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014313-520x416.jpg" alt="" width="520" height="416" /></a>

5. When everything is set, click "OK" to save.

<img class="alignnone size-large wp-image-5112" title="2011-05-21_014200" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014200-520x416.jpg" alt="" width="520" height="416" />

6. Once it's set up, there's a small button under "File" that lets you connect quickly. See the image below, and click the button inside the red box.

<a href="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014443.jpg"><img class="alignnone size-large wp-image-5114" title="2011-05-21_014443" src="{{< param imageBase >}}/wp-content/uploads/2011/05/2011-05-21_014443-520x431.jpg" alt="" width="520" height="431" /></a>
