It's been several months since Google Chrome 4 came out, and Chrome 5 has finally arrived! This update brings some changes. For example, <strong>the V8 JavaScript engine has been upgraded again, which makes Chrome 5 browse much faster</strong>. I don't find the difference very noticeable myself, but according to SunSpider tests, it's about 30% more efficient than the previous version. Chrome 5 also extends the Google account bookmark sync feature to more settings (themes, the home page, and so on). And <strong>Chrome 5 also has the Adobe Flash Player built in</strong>. If I remember correctly, it's the first of the three major browsers (IE, Firefox, Chrome) to include a built-in Flash player. Below, I'll walk you through the new features of Google Chrome 5 Beta.

<h2>New Features in Chrome 5</h2>
<h3>1. Interface changes:</h3>
The biggest change in Chrome 5 is the interface, which is very different from earlier versions. When I first installed Chrome 5 beta, I thought I'd downloaded a prank version XD, because the whole color scheme had changed, and it felt very unfamiliar. Beyond the colors, the extensions area has also changed a bit. In Chrome 4, I wondered: if you install too many extensions, won't the interface get ugly, since every extension takes up a button in the same spot? In Chrome 5, you can adjust the length of the extensions area. This is the change I like best, at least compared with something as trivial as changing colors~ Also, in Chrome 5, the bookmarks (My Favorites) feature has been moved to after the address bar, so I'm pointing it out in case you can't find it.

<h3>2. More advanced content settings:</h3>
Previous versions of Google Chrome didn't let users change advanced settings. This release finally lets users choose which sites can use cookies, JavaScript, and loaded images. You can also set which sites are blocked from pop-up windows. So from now on, if you want to quietly take someone's images without them knowing, you can do it right in Chrome :D (<a href="http://briian.com/?p=5183">http://briian.com/?p=5183</a>)

<h3>What is V8?</h3>

<h3>5. Extensions also work in private (Incognito) windows</h3>
Chrome 4 introduced extensions, which let users write their own extension programs and attracted many people who found Chrome too plain to switch to it. In Chrome 5, the extension feature has been improved further, so extensions also work in Incognito windows~ To allow an extension to work in an Incognito window, first click the wrench button, then click Extensions, and check "Allow in incognito" for each extension you want to use in Incognito windows.
