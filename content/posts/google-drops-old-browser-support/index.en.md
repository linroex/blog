According to the latest news on Google's official blog <a href="http://googledocs.blogspot.com/2011/06/our-plans-to-support-modern-browsers.html">(see this page)</a>, Google plans to stop fully supporting old browsers starting on 8/1. The reason is that these older browsers don't support the latest technologies well. For example, HTML5 and CSS3 aren't supported, and they may run JavaScript too slowly. As a result, Google's services (Gmail, Google Reader, and so on) run into many problems on old browsers, so Google has decided to stop supporting them.


<!--more-->
The "old browsers" I'm referring to here are roughly the following (<=):
<ul>
	<li>IE 7 and below</li>
	<li>Firefox 3.5 and below</li>
	<li>Safari 3 and below</li>
</ul>
After 8/1, these browsers may stop working with Google's services entirely. If you're still using any of them, please update as soon as possible~ Especially if you're still on IE6. Even Microsoft has built a tool to nudge you into upgrading...

I doubt anyone would claim that Google is doing this to grow Chrome's market share, right? In fact, Google doesn't require you to use Chrome to access its services. If it did, that would go against its "Don't be evil" principle, and it would be roasted to death. What Google really wants is for you to use a browser that supports new technologies when you access its services. Google uses a lot of new technology these days, and sticking with old browsers would limit the development of Google Apps.
<h2>Which Browser Should You Switch To?</h2>
Here are a few browsers I find decent that support Google's new technologies~

<h3>Internet Explorer 9</h3>

If you're a diehard IE and Microsoft fan, IE9 is the right choice~ It supports many new technologies (HTML5), has a cleaner interface, and its performance is way up. In particular, opening tabs no longer freezes your computer the way it did in earlier versions...

<h3>Firefox 4</h3>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185500.jpg"><img class="alignnone size-large wp-image-5213" title="2011-06-06_185500" src="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185500-520x406.jpg" alt="" width="520" height="406" /></a>

Firefox 4 is hot off the press. Like IE9, it has a simpler interface, and it also supports new technologies (HTML5, CSS3, and more). The downside is that its performance is still a bit weak. In my testing, Firefox 4 is much slower than IE9. But Firefox's real strength is its extensibility. With Firefox you can do many things that are hard to imagine, such as installing an SSH add-on so you can make SSH connections right inside the browser. Many browsers support extensions, but Firefox has the most and most complete extension ecosystem!

<h3>Google Chrome</h3>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_191547.jpg"><img class="alignnone size-large wp-image-5214" title="2011-06-06_191547" src="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_191547-520x370.jpg" alt="" width="520" height="370" /></a>

Chrome is the newest of the three browsers covered in this article. Google launched it in September 2008, so it's only been about three years (three years already!?). Although it's relatively new, Chrome is actually the fastest and best-performing of the three browsers in this article, and its support for CSS3 and HTML5 is excellent. It's the browser I use most these days. It also led everyone else (IE, Firefox) toward a cleaner, minimalist style~ It supports extensions too, which can add many features that browsers don't have built in. Of course, since it's newer, its number of extensions can't compare with Firefox's.

P.S. Chrome is Google's own browser, so many of Google's exclusive new technologies are tested in Chrome first, such as some protocols that speed up browsing. In other words, logging into Google's services with Chrome is the smartest choice~
