Google 公式ブログの最新情報（<a href="http://googledocs.blogspot.com/2011/06/our-plans-to-support-modern-browsers.html">こちらのページ</a>）によると、Google は 8/1 から古いブラウザのサポートを全面的に終了する予定です。古いブラウザは HTML5 や CSS3 などの最新技術への対応が不十分で、JavaScript の実行も遅すぎることがあるからです。その結果、Google のサービス（Gmail、Google Reader など）が古いブラウザでは多くの問題を起こすため、サポートをやめることに決めたのです。


<!--more-->
ここでいう「古いブラウザ」はおおむね次のものを指します（<=）。
<ul>
	<li>IE 7 以下</li>
	<li>Firefox 3.5 以下</li>
	<li>Safari 3 以下</li>
</ul>
8/1 以降、これらのブラウザでは Google のサービスが完全に使えなくなる可能性があります。今もこれらを使っている方は、今すぐアップデートすることをおすすめします～ 特に IE6 を使っている方は要注意です。マイクロソフトまでアップデートを促すツールを作ったほどですから……

まさか Google が Chrome のシェアを伸ばすためにこんなことをしている、とは言わないでしょうね？ 実際、Google は Chrome を使わないと Google のサービスを利用できないとはしていません。もしそんなことをすれば、Google の行動原則である「Don't be evil」に反しますし、間違いなく袋叩きにされるでしょう。Google が求めているのは、サービスにアクセスする際に新しい技術に対応したブラウザを使ってもらうことなのです。今の Google は多くの新技術を活用しており、古いブラウザを使い続けると Google Apps の発展が妨げられてしまいます。
<h2>どのブラウザに乗り換えるべき？</h2>
Google の新技術に対応していて、個人的におすすめできるブラウザをいくつか紹介します～

<a href="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185401.jpg"><img class="alignnone size-large wp-image-5212" title="2011-06-06_185401" src="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185401-520x312.jpg" alt="" width="520" height="312" /></a>

<h3>Firefox 4</h3>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185500.jpg"><img class="alignnone size-large wp-image-5213" title="2011-06-06_185500" src="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_185500-520x406.jpg" alt="" width="520" height="406" /></a>

Firefox 4 は出たばかりのブラウザです。IE9 と同じくインターフェースがシンプルになり、HTML5 や CSS3 などの新技術にも対応しています。ただ、パフォーマンスはまだ少し弱く、私のテストでは IE9 よりかなり遅いという結果でした。しかし Firefox の本当の強みは拡張性にあります。Firefox なら想像もつかないようなことができます。たとえば SSH のアドオンを入れれば、Firefox 上で直接 SSH 接続ができます。拡張機能に対応しているブラウザは多いですが、Firefox は拡張機能の数も完成度も最も高いのです！

<h3>Google Chrome</h3>

<a href="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_191547.jpg"><img class="alignnone size-large wp-image-5214" title="2011-06-06_191547" src="{{< param imageBase >}}/wp-content/uploads/2011/06/2011-06-06_191547-520x370.jpg" alt="" width="520" height="370" /></a>

Chrome は、この記事で紹介する 3 つのブラウザの中で最も新しいものです。Google が 2008 年 9 月にリリースしたので、まだ約 3 年です（もう 3 年なんですね！？）。比較的新しいブラウザですが、実はこの記事で紹介する 3 つの中で最も速く、性能も最も優れています。CSS3 と HTML5 への対応も完璧です。今いちばんよく使っているブラウザでもあります。また、IE や Firefox をシンプルなデザインへと導いたのも Chrome です～ 拡張機能にも対応していて、ブラウザに標準で入っていない多くの機能を追加できます。もちろん、歴史が浅いぶん、拡張機能の数は Firefox には及びません。

P.S. Chrome は Google 自身のブラウザなので、Google の独自の新技術は Chrome で先に試されることが多く、たとえばブラウジングを速くするプロトコルなどがあります。つまり、Google のサービスには Chrome でログインするのが最も賢い選択なのです～
