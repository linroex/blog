プログラムを書くときに一番いやなことといえば、ファイルパスの入力がきっと上位に入るでしょう。HTML で JS や CSS を読み込むとき、あるいは Python でファイルを開くときなど、そのたびに Finder に切り替えてファイル名をコピーしなければなりません。でも、私と同じように Sublime Text のファンで、さまざまなプログラミング言語を Sublime Text で書いているなら、<a href="https://packagecontrol.io/packages/AutoFileName">AutoFileName</a> にお任せしましょう！


<!--more-->


<a href="https://packagecontrol.io/packages/AutoFileName">AutoFileName</a> は Sublime Text のプラグインで、ST2 と ST3 の両方に対応しています。パスを入力する可能性がある場所では、現在のファイルの位置を起点とした相対パスの候補を表示してくれます。キーボードの矢印キーと Enter だけで、すばやくファイルパスを入力できます。

<a href="https://packagecontrol.io/">Package Control</a> を使えば、<a href="https://packagecontrol.io/packages/AutoFileName">AutoFileName</a> を簡単にインストールできます。

使うときは、ファイルを先に保存するのも忘れないでください。そうしないと AutoFileName は有効になりません！ 理由は簡単で、保存されていなければ、どこにいるのかわからないからです！
