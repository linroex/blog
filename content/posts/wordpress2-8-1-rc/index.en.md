Yesterday when I logged into 逐風者, I was surprised to find that WordPress 2.8.1 RC was already out. It's only an RC release, but at least it's better than a beta. This time it doesn't add many features — it just brings the visual editor back from the dead (in 2.8 the visual editor would disappear). Other than that, I didn't notice any particularly special updates. If you want to try it out, go download it now.

Download page <a href="http://wordpress.org/wordpress-2.8.1-RC1.zip">http://wordpress.org/wordpress-2.8.1-RC1.zip</a>

↑↑↑ The cute visual editor is back from the dead.

Speaking of which, I used to have to downgrade to WordPress 2.7 just to use the visual editor, because WordPress 2.8's visual editor had problems. Now that WordPress 2.8.1 has fixed that issue, I finally don't have to put up with WordPress 2.7's super slow speed anymore XD.

If you're going to update, remember to disable your plugins and themes in the admin panel. I forgot to do that yesterday, but luckily nothing happened :) (Thank God~)
