<h2>VPS とは？</h2>
前置きが長くなりましたが、まだ何の話かよくわからない方も多いと思うので、まずは VPS とは何かを説明しますね。VPS は、レンタルサーバーに似たサービスです。形式としては、最近人気のクラウドホスティングに近いものです。一般的なレンタルサーバー（共有ホスティング）は、ホスティング業者が 1 台のコンピューターを数十、ときには数百のアカウントに分割し、利用者はそのハードウェアのリソースを分け合って使います。そのため、レンタルサーバーのスペック表を見ると、通常は<strong>個人専用の容量と転送量</strong>しか書かれておらず、個人専用のメモリや CPU の量は書かれていません。これは、レンタルサーバーのハードウェアリソースが全利用者で共有されているからです。同じサーバー上のほかのサイトがリソースを多く使うと、自分のサイトが使えるリソースは相対的に減ってしまいます。また、レンタルサーバーはウェブサイトを作るための専用サービスなので、<strong>使えるのは業者があらかじめサーバーにインストールしている SQL、FTP、Apache、Mail などのサービスだけ</strong>です。一部のレンタルサーバーではスケジュールタスクの権限がもらえることもありますが、自分でプログラムをインストールしたり、システム全体を管理したりすることは、レンタルサーバーでは絶対にできません。

一方、VPS は違います。VMware や VirtualBox などの仮想マシンを使ったことがある方もいるかもしれませんが、VPS はまさに仮想マシン技術の応用です。VPS の業者は、1 台の物理マシンをいくつかの仮想マシンに分割します。<strong>ハードウェアのリソースはすべて専有</strong>なので、ほかの人が使いすぎても、自分のリソースが減ることはありません。<strong>さらに権限も高く、必ず root 権限があるので、どんなプログラムでも自分でインストールできます</strong>。腕に自信があれば、自分でプログラムを書いてアップロードすることもできます。レンタルサーバーでは、業者が特定の PHP の関数をブロックしたり、何らかの設定をしていたりすることがありますが、VPS ではそのような問題は起きません。すべての設定を自分で決められるからです！ また、現在の VPS には <a href="http://zh.wikipedia.org/zh-tw/OpenVZ">OpenVZ</a> と <a href="http://zh.wikipedia.org/zh-tw/Xen">Xen</a> の 2 種類があります。違いは使われている仮想化技術にあります。詳しく知りたい方は、下の 2 つのページを見てください。技術的な説明は面倒なので、実際の面から説明しておきますね。

P.S. 一部のレンタルサーバー業者は、データセンターのネットワーク速度がどれほど速いか、ハードウェアがどれほど優れているかを宣伝しています。しかし、その説明はあまり明確ではありません。サーバーが優れていてネットワークが速くても、何百人もの利用者で分け合ってしまえば、一人ひとりが使える量はとても少なくなるからです。

<h2>VPS には 2 種類の技術がある？</h2>
<strong>OpenVZ の仮想化技術を使う VPS は、通常、Xen の仮想化技術を使う VPS より安く売られています</strong>。これには理由があります。OpenVZ はオーバーセールができるのです。つまり、コンピューターが 10 台の仮想マシンしか動かせなくても、少しだけ多く、12 台か 13 台まで作らせてくれます。言い換えれば、<strong>OpenVZ の仮想化は完全ではなく、ほかの人の VPS がある程度あなたの VPS に影響することがあります</strong>。一方、Xen は仮想化がとても完全です。ハードウェアの性能が最大で 10 台までなら、10 台しか作れず、業者がこっそり余分に詰め込むこともできません。そのため、価格は当然高くなります。ただ、私の印象では、OpenVZ も確かにほかの人に一定の影響を与えますが、その影響はとても小さいです。ですから、特別な好みや要件がなければ、<a href="http://zh.wikipedia.org/zh-tw/OpenVZ">OpenVZ</a> 型の VPS を買えば十分だと思います。

<h2>セミマネージドとアンマネージドの違い</h2>
VPS の価格表やスペック表を見ると、レンタルサーバーにはない「セミマネージド」というオプションがあることに気づくと思います。一部の VPS はセミマネージドで、一部はアンマネージドです。簡単に言うと、アンマネージドの VPS はとても安いです。私が今使っている VPS は年間 3800 ですが、アンマネージドなら 1700 ほどです…… 理由は、アンマネージドの場合、VPS を売ったあとは一切面倒を見ないからです。サーバーにトラブルが起きて業者にメールを送っても、ハードウェアの問題でない限り、返事がもらえないこともあります。一方、セミマネージドでは、IP の変更、データセンターの移転、再インストールなど、一部のことを手伝ってもらえます。セミマネージドなら、業者にメールで連絡すれば対応してもらえます。ほかにフルマネージドもありますが、その価格は恐ろしいほど高いです。Linux がまったくわからない人向けです。サーバーを自分で管理できないからです。私は少しだけ Linux がわかりますが、全部わかるとは言えないので、セミマネージドを買いました xD
<h2>VPS で何ができる？</h2>
VPS でもっともよく使われるのは、ウェブサイトを立てることです。ただ、前に説明したように、VPS は独立した仮想マシンなので、すべての権限を持ち、好きなプログラムをインストールできます。つまり、VPS を BBS やネットニュースの転信站（中継サーバー）として使ったり、Proxy として使ったりすることもできます。また、中国本土のようにグレートファイアウォールがある地域の方なら、アメリカの VPS に VPN を立てることもできます。BT（BitTorrent）が使える VPS もあります。さらに、プライベートサーバーを運営している人もいて、そのプライベートサーバーを VPS 上に置くこともできます。
<h2>まとめ：VPS を使うメリット</h2>
上では VPS について紹介しましたが、かなり長くなってしまいました。面倒くさがりな方は、このまとめだけ読んでください～

レンタルサーバーと比べたときの VPS は：

<strong>1. VPS のネットワーク速度は、一般的にレンタルサーバーより速い</strong>

これは明らかなことです。たとえば、同じネットワーク速度の環境で、家のパソコン 1 台だけがネットに接続している場合と、10 台が接続している場合、どちらのほうが使える帯域幅が多いでしょうか？ 1 台のほうに決まっています。VPS も同じ理屈です。ただ、数字を見ないと納得できない方もいるでしょうから、私の例を挙げます。以前は捕夢網のレンタルサーバーを使っていて、年間 4000 元かかっていました。捕夢網のデータセンターは台湾にあるので、理論的にはネットワーク速度がとても速いはずで、当時は私もそう思っていました。ところが、アメリカの VPS に切り替えたら、年間 3800 ほどなのに、ネットワーク速度は捕夢網の何倍も速くなりました。これは私の感覚ではなく、Google の統計データにも表れているのです！

<strong>2. サーバー上のすべてを自分で管理できる</strong>

レンタルサーバーで本当に困るのは、セキュリティ上の理由で業者が PHP の一部の機能をブロックしていることがある点です。あるいは、PHP のホスティングはあるけれど JSP の練習をしたい場合は、JSP のホスティングを別に買わなければなりません。VPS ではそのような問題は起きません。最初は PHP を入れていても、今度は JSP で遊びたいなら、VPS に JSP をインストールすればいいのです。PHP で 20MB までしかアップロードできないよう制限されている？ 大丈夫、自分で 50MB に変えればいいのです。

<strong>3. Linux システムの使い方を練習できる</strong>

レンタルサーバーでは、インストールするオペレーティングシステムを選べます。業者によっては多くの OS が標準で用意されていて選べるものもあれば、自分で ISO ファイルをアップロードしてインストールできるものもあります。ただ、VPS は一般的にウェブサイト用として使われるので…… ほとんどの場合は Linux をインストールします。また、前にも説明したように、最高権限も得られます。つまり、サーバー管理に興味があるなら、VPS を 1 台買って Linux を練習すればいいのです～ もちろん、自宅で仮想マシンを立ててもいいですよ XDD。ただ、ウェブサイトを立てるつもりなら、VPS を買えば Linux の練習も同時にできます。

<strong>4. システムがダウンする頻度は、レンタルサーバーより何千倍も少ない</strong>

そもそも VPS に乗り換えたのは、この嫌な理由があったからです。捕夢網はダウンの頻度が高すぎて、稼働率が 98% にも届いていないのではないかと疑ってしまうほどでした。ダウンがこれほど多い原因は、業者が 1 台のサーバーにユーザーを詰め込みすぎているからだと思います。台湾は人件費や地代が高いので、業者がこうした方法をとるのも仕方がないのかもしれません…… ただ、仕方がないかどうかは私には関係ありません。ダウンのたびに 10〜20 分以内には復旧してくれましたし、サポートスタッフの態度も悪くはありませんでした。メールを送れば、すぐにサーバーを直してくれました。ただ、メールを送らなかった場合は…… 業者の管理者が自分で気づくまで待つしかありません＝＝ それに、たった 5 分の切断でも私には耐えられませんでした。特に、ダウンはいつも私が記事を投稿しているときに起きるので、せっかく書いた文章を打ち直すはめになって、本当に困りました……

<strong>5. レンタルサーバーより安い……</strong>

ここでは、アメリカの VPS の価格を台湾のレンタルサーバーと比べてみます。台湾で 4000 元のスペックは、アメリカでは 3800 ほどで手に入り、さらに良いスペックを得られることもあります。しかも、1 か月ごと、半年ごと、年ごとの支払いが選べます。私は今、アメリカの VPS を年間 3800 ほどで借りていますが、友人と一緒に借りているので、1 人あたり年 1900 元で済んでいます。これは、アメリカの一般的なレンタルサーバーの価格とほぼ同じです。しかも 2 人で使っている状態では、システムのパフォーマンスはまだ安全の基準を超えていません（私が自分で決めた安全基準は、メモリ使用量が 250MB 以内で、現在は 200MB あたりを行き来しています）。今のところ、この VPS には、私と同じくらいのトラフィックのサイトをあと 2〜3 個置けると見積もっています（現在、1 日に約 400 の IP からのアクセスがあります）。

<h2>VPS を使うデメリット</h2>
ここまで読むと、VPS があらゆる面でレンタルサーバーに勝っているように見えるかもしれません。では、なぜ多くのウェブサイト運営者は VPS ではなく、レンタルサーバーを選ぶのでしょうか。理由は、レンタルサーバーはサービスがよいからです。サイトに問題が起きてメールで伝えれば、きちんと対応してくれます。必要なプログラムがサーバーにすでに入っていれば、すぐに使えます。VPS はそうではありません…… 一定の Linux の知識が必要なのです。VPS を買ったら、Web サーバーや FTP サーバーなど、必要なサービスをすべて自分でインストールしなければならず、DNS も自分で設定する必要があります。これだけでも、パソコンに詳しくない多くの人は尻込みしてしまい、お金を余分に払ってもレンタルサーバーを選びます。ただ、今では VPS のハードルはずいぶん下がりました。セミマネージドの場合、私が最初に設定したときは LNMP を使い、Web サーバー、FTP、データベースなどを一度にまとめてインストールしました。以前ほど面倒ではありませんでしたが、それでもかなり時間はかかりました。また、今ではセミマネージドの VPS なら、トラブルが起きて業者にメールすれば、かなりしっかり対応してもらえます。ですから、もう上級者しか触れないものではなくなりました。買ってみたけれど使い方がわからないという心配があっても、大丈夫です。VPS もレンタルサーバーと同じく、一定期間内であれば返金してもらえます。

P.S. ただし、VPS はやはりパソコンに詳しくない人や、少しだけ詳しい人が手を出せるものではありません……
