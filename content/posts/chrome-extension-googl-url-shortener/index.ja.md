「<a href="http://goo.gl/">goo.gl</a>」のような形式の URL を見かけたことのある方は多いと思います。これは Google が提供している URL 短縮サービスです。たとえば掲示板で面白い投稿を見つけて、友人に見せたいことがあるでしょう。そのときは URL をコピーする必要がありますが、掲示板の URL は通常とても長く、コピーするだけで一苦労です……。そんなときに役立つのが短縮 URL です。goo.gl の短縮サービスを使えば、数十文字の URL を 10 文字未満に短くできます。ファイルを友人と共有するときにも便利です。では、goo.gl の短縮 URL はどのように作成するのでしょうか。短縮したいサイトを開いて、Chrome 拡張機能「goo.gl URL Shortener」のボタンを押すだけです。さらに「goo.gl URL Shortener」では、短縮 URL のコピーや、短縮 URL の情報の確認、QR コードの表示もできます。

↑↑ 短縮 URL から元の URL を調べることができます
<h2>goo.gl URL Shortener の使い方</h2>
1.まず <a href="https://chrome.google.com/extensions/detail/iblijlcdoidgdpfknkckljiocdbnlagk">goo.gl URL Shortener</a> のインストールページを開き、拡張機能をインストールします

<a href="https://chrome.google.com/extensions/detail/iblijlcdoidgdpfknkckljiocdbnlagk">https://chrome.google.com/extensions/detail/iblijlcdoidgdpfknkckljiocdbnlagk</a>

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-27_233756.jpg"><img class="alignnone size-large wp-image-3904" title="2010-10-27_233756" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-27_233756-520x283.jpg" alt="" width="520" height="283" /></a>

2.次に、短縮したいサイトを開きます。たとえば https://coder.tw/ の短縮 URL を作りたい場合は、まず https://coder.tw/ を開いて、goo.gl URL Shortener のボタンを押すと短縮 URL が作成されます

<a href="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-27_234117.jpg"><img class="alignnone size-large wp-image-3905" title="2010-10-27_234117" src="{{< param imageBase >}}/wp-content/uploads/2010/10/2010-10-27_234117-520x287.jpg" alt="" width="520" height="287" /></a>

3.短縮 URL を QR コードの形で友人と共有したい場合は、Details をクリックします。別のページが開くので、QR コードを右クリックして保存すれば完了です
