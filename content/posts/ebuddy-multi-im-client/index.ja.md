<strong></strong><strong>e</strong><strong>buddy</strong> は、これまで見てきた中でかなり良いと感じた、ウェブベースのインスタントメッセージサービスです。Yahoo メッセンジャー、MSN、GTalk、QQ（中国本土で使われています）など、有名なインスタントメッセンジャーに多数対応しています。さらに <strong>ebuddy </strong>は Facebook にも対応していますが、Facebook がインスタントメッセージとどう関係するのかは、正直よくわかりません＝＝ 多くのメッセンジャーに対応しているだけでなく、<strong>ebuddy</strong> は繁体字中国語、簡体字中国語、英語などさまざまな言語にも対応しているので、インターフェースが読めなくて困ることもありません。そして私が一番気に入っているのは、<strong>ebuddy</strong> で 1 つのアカウントを作成し、さまざまなメッセンジャーのアカウントをまとめて管理できることです。そうすれば、覚えるアカウントは 1 つだけで済み、たくさんのアカウントを覚えているのと同じになります ^^

この記事では、<strong>ebuddy</strong> へのログイン、言語の変更、ebuddy ID の使い方を紹介します。


<!--more-->

<h2>ebuddy の特徴</h2>
<ul>
	<li>Yahoo、MSN、GTalk、QQ に対応</li>
	<li>Flash をインストールしなくても使える</li>
	<li>ebuddy アカウントを作成して、各種メッセンジャーのアカウントを管理できる</li>
	<li>多言語に対応（繁体字中国語を含む）</li>
	<li>複数人でのチャットに対応</li>
	<li>ビデオチャットに対応</li>
</ul>
公式サイト：<a href="http://www.ebuddy.com/">http://www.ebuddy.com/</a>
<h2>インターフェースの言語を繁体字中国語に変更</h2>
<a href="http://www.ebuddy.com/">ebuddy</a> の標準の言語は簡体字中国語なので、初めて <a href="http://www.ebuddy.com/">ebuddy</a> のサイトを開いたら、まず右上の「Site Languages」を選び、繁体字中国語を選択してください。ページが繁体字に切り替わります～

<h2><span style="color: #ffffff;"><span style="color: #000000;">ebuddy アカウントの作成</span></span></h2>
この記事の最初で紹介したように、ebuddy では、ebuddy のアカウントを作成して、ほかのインスタントメッセンジャーのアカウントを 1 か所にまとめて管理できます。多くのメッセンジャーを使っている人にとって、これはとても便利です。このセクションでは、ebuddy を使ってアカウントを管理する方法を紹介します。ただし、ebuddy ID にはすべてのメッセンジャーのアカウントが含まれるので、パスワードは絶対に他人に知られないよう注意してください！

注：ここで言う「管理」とは、「ebuddy のサイトで ebuddy ID を入力するだけで、各種メッセンジャーに自動的にログインできる」ことを指します。

1.左側のメニューで【ebuddy ID】を選び、【<span style="color: #ff3300;">無料で自分だけの eBuddy ID を申し込む</span>】をクリックします

<h2>ebuddy ID の使い方</h2>
前の記事では、ebuddy ID の申し込みと設定を行いました。この記事では、設定したすべてのメッセンジャーにログインする方法を紹介します。

1.いつものように、まず ebuddy にログインし、【設定】→【アカウント】を選んで、ログインしたいメッセンジャーサービスの「Log in」を押します。1 つずつ押すのが面倒なら、【すべてログイン】を押して、「OK」で元の画面に戻ることもできます。

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-25-11-43-00.jpg"><img class="alignnone size-full wp-image-2106" title="2009-10-25 11 43 00" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-25-11-43-00.jpg" alt="2009-10-25 11 43 00" width="520" height="487" /></a>

2.元の画面に戻ると、連絡先の数が以前の何倍にも増えていることに気づくはずです。これは、すべてのメッセンジャーにログインしたからです。この機能は本当に便利ですよね！！

<a href="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-25-11-46-59.jpg"><img class="alignnone size-full wp-image-2107" title="2009-10-25 11 46 59" src="{{< param imageBase >}}/wp-content/uploads/2009/10/2009-10-25-11-46-59.jpg" alt="2009-10-25 11 46 59" width="520" height="487" /></a>

3.残念な点として、ebuddy は名前を表示せず、相手のアカウント名だけを表示するため、誰なのかを見分けるのがちょっと大変です＝＝
