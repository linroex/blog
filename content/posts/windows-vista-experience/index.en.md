I've always heard people say Vista is terrible.

Today Mom bought a new laptop, and now I finally see where Vista falls short!

The speed is fine, though my computer was already fast to begin with.

But there's one thing that's really annoying.

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/02.jpg"><img class="alignnone size-medium wp-image-1139" title="02" src="{{< param imageBase >}}/wp-content/uploads/2009/05/02-300x88.jpg" alt="02" width="300" height="88" /></a>

Every time I install a program, it pops up and bugs me. It's something called UAC, I think. And I'm not used to the new operating system at all.

There are a lot of things I don't know how to do. When I first started downloading files with IE7, I couldn't even find the button to set the save location. I was about to lose it!!

And it seems Vista wasn't satisfied with that. I couldn't even install Unicode, because it doesn't support Vista..................

So in the end I had to let the computer display a bunch of garbled characters @@

<a href="{{< param imageBase >}}/wp-content/uploads/2009/05/03.jpg"><img class="alignnone size-full wp-image-1140" title="03" src="{{< param imageBase >}}/wp-content/uploads/2009/05/03.jpg" alt="03" width="404" height="574" /></a>

Sure, Vista's interface is very pretty, with frosted-glass effects, but it shouldn't have to sacrifice so many of XP's advantages to get there~~~~

That said, Vista did make some changes to Paint. In the past, Paint saved files with very poor image quality, because it could only save BMP files. The new version can save JPEG, though, so the colors are much richer!

Vista has its fun parts too, but I think I'll just reinstall XP. Using Vista would probably drive me crazy. It's an operating system with no humanity at all :(( angry

I hope the new W7 turns out better, and at least has some humanity xD (By the way, I haven't used the new W7 yet. I'll try it out someday.)
