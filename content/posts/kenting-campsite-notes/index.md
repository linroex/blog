前陣子跨年和朋友去墾丁露營，行前準備時爬了很多露營地相關的文章，這邊整理給大家參考，以下所列的資料大多都是從網路上參考網路上的遊記、Google Map 評價整理而來，僅供參考，有興趣的朋友建議在電話詢問一下！ 之後如果有機會去體驗，會再更新資訊，也歡迎大家回饋相關資訊我會再作修改。


<!--more-->


我個人在選擇露營區時會注意以下幾件事情，並非沒有就絕對不好，比如衛浴設備如果很差我可以接受，畢竟出來露營已經不期待洗澡了，但要事先規劃如果衛浴設備差需要準備什麼，又或是落山風強要準備些什麼等等：
<ul>
 	<li>擁擠程度：不太喜歡在塞滿人的露營區露營，打開帳篷就看到一堆人，露營都不露營了。</li>
 	<li>海景：打開帳篷就能看到大海，超感動的不是嗎！！！！</li>
 	<li>管理：例如設備是否會整修、是否有管制人數、是否能預先訂位等等，有少數露營地基本上就是擺爛狀態，一塊地在那邊給你露營，還要跟你收費，但除了那塊地以外什麼都沒有。</li>
 	<li>環境：露營地是否會有蛇、蟲出沒，如果會有這些小傢伙，那就要事先做好準備。</li>
 	<li>衛浴：有沒有熱水、浴室乾不乾淨等等。</li>
 	<li>電源：有沒有提供電源、電源距離帳篷多遠這些可要先查清楚阿！ 對應措施像是自備一堆行動電源、帶延長線等等。</li>
</ul>
如果是冬天去墾丁露營，要小心落山風哦，基本上遇到落山風還是可以露營，但是帳篷要租堅固一點的，此外可以用汽車來擋風（笑）
<h2>石牛溪農場露營區</h2>
<ul>
 	<li>電話：08-886-1281</li>
 	<li>地址：屏東縣恆春鎮墾丁路石牛巷1-1號</li>
 	<li>親身體驗：是</li>
</ul>
很大很大超級大，為什麼這樣說呢？ 因為在熱鬧的跨年，沒預約竟然還有營位，而且進去後發現每個人可以分到的空間很大，不像快樂白沙露營區，有種軍隊旌旗相連的感覺，打開帳篷就是別人的帳篷，在石牛溪我最開心的就是可以擁有自己的營地；此外石牛溪農場距離墾丁大街超級近！走路只需要約 20 分鐘就可以到墾丁大街，衛浴設施完善乾淨，半夜三點有熱水；不過這裡有幾個缺點，沒有電源、不能租露營設備，如果要來這的話，建議行動電源多帶幾顆哦！

最有趣的是，小時候媽媽帶我們去墾丁玩，就是住在這裏，但去之前其實不知道，而是當我車開進去時，才發現這場景竟然是如此的熟悉！！

<strong>資訊</strong>
<ul>
 	<li>擁擠：十分滿意，不壅擠。</li>
 	<li>海景：旁邊有海但看不到。</li>
 	<li>管理：十分滿意，連草皮都有在維護。</li>
 	<li>環境：身為一個捕蚊燈，我竟然沒被咬，你說呢？</li>
 	<li>衛浴：半夜三點有熱水，浴室每天早上會清潔，個人覺得十分乾淨。</li>
 	<li>電源：可以視為完全沒有。</li>
 	<li>設備租借：無，這裡只提供營地，不提供租用設備。</li>
</ul>

<h2>快樂白沙露營區</h2>
<ul>
 	<li>電話： 08-886-7888</li>
 	<li>地址： 屏東縣恆春鎮白砂路31-2號</li>
 	<li>官網： <a href="http://www.happy-bs.com.tw/camping.php">http://www.happy-bs.com.tw/camping.php</a></li>
 	<li>親身體驗：路過</li>
</ul>
快樂白沙就在墾丁白沙灣的旁邊，入口蠻好找的，可以事先電話訂位，對於人數也有在做管控，所以如果能訂到位就一定有地方可以露營，這裡大概是墾丁地區設備、服務最完善的露營區，也有花心血在做管理，不過價格不便宜大約是別的露營區兩倍左右，此外從外面看過去，空間略嫌壅擠。

快樂白沙露營區也就是快樂熊貓露營區，他們是同一個哦！

<strong>資訊</strong>
<ul>
 	<li>擁擠：沒有進去過，但從外面看十分擁擠。</li>
 	<li>海景：打開帳篷就可以看到白沙灣跟大海。</li>
 	<li>管理：十分滿意，收費貴但管理超好。</li>
 	<li>環境：沒看到這方面的負評。</li>
 	<li>衛浴：有熱水，晚上六點到早上八點。</li>
 	<li>電源：木棧板營位旁有附電源插座，但不確定是否每個營位都有。</li>
 	<li>設備租借：有！！！包含帳篷、睡袋、充氣床墊等等。</li>
</ul>
<strong>參考</strong>

<h2>白沙露營區</h2>
<ul>
 	<li>電話：0955-525-945</li>
 	<li>地址：就在快樂白沙的旁邊，往左是快樂白砂，往右就是白沙露營區，可以問問當地人，不太好找。</li>

<strong>資訊</strong>
<ul>
 	<li>擁擠：目測感覺蠻壅擠的。</li>
 	<li>海景：打開帳篷就可以看到白沙灣跟大海。</li>
 	<li>管理：我去的時候找不到老闆（笑） 基本上可以視為無管理吧。</li>
 	<li>環境：無資訊</li>
 	<li>衛浴：無資訊</li>
 	<li>電源：無資訊</li>
</ul>
<h2>紅柴水鄉</h2>
<ul>

<h2>巨石咖啡</h2>
<ul>
 	<li>電話：08-886-9192</li>
 	<li>地址：屏東縣恆春鎮萬里路34之5號</li>
 	<li>親自體驗過：未體驗</li>
</ul>

<strong>資訊</strong>
<ul>
 	<li>擁擠：旺季 巨石咖啡露營區 會很擁擠。</li>
 	<li>海景：這裡的唯一好處就是海景超級棒！</li>
 	<li>管理：個人認為老闆服務態度很差</li>
 	<li>環境：2014 年有兩篇文章提到大螞蟻問題</li>
 	<li>衛浴：有，但只有男女各兩間，很基本的搭建。</li>
 	<li>電源：有，但需要延長線。</li>
</ul>
