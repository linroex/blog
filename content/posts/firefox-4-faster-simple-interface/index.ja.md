Firefox 4 もついにインターフェースがシンプルなブラウザーの仲間入りを果たしました～ これで市場の三大ブラウザー、Chrome、IE、Firefox はどれもインターフェースをかなりシンプルにしたことになります。ただ、Firefox は少し遅かったですね。かつて私が Firefox から Chrome に乗り換えた大きな理由は、Google Chrome のインターフェースが新しくて洗練されていて、速そうに見えたからです（心理的なプラス効果……）。とはいえ、Firefox にも多くの利点があります。たとえばカスタマイズ性です！Chrome も拡張機能をインストールできますが、Chrome の拡張機能の数は Firefox には遠く及びません。そのため、Firefox ならできることがずっと多いのです XD


<!--more-->
今回の Firefox 4 のアップデートでいちばん大きな違いはインターフェースです。これまでのどのバージョンとも違い、Firefox の見た目がすっかり変わりました！！ また、速度は Firefox 3.6 より六倍速くなったそうです（公式サイトによる）。でも、Chrome にはまだ負けていますね……。それから、これが Firefox 4 で新しく追加された機能かどうかは確信がありませんが、Firefox Sync、つまり Firefox の同期機能があります。ブックマーク、閲覧履歴、パスワードなどのデータを、別の Firefox 間で同期できます。今では Firefox に組み込まれていて、Chrome と同じように直接使えます。

<h2>Firefox 4 のインストール手順</h2>
1. まず Firefox 4 のインストーラーをダウンロードし、実行します

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000646.jpg"><img class="alignnone size-large wp-image-4977" title="2011-04-05_000646" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000646-520x356.jpg" alt="" width="520" height="356" /></a>

2. インストール画面はこれまでどおりです……【次へ】をクリックします

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000828.jpg"><img class="alignnone size-full wp-image-4978" title="2011-04-05_000828" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000828.jpg" alt="" width="503" height="389" /></a>

3. 通常は【次へ】をクリックするだけで大丈夫です。特別な設定をしたい場合は別ですが

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000923.jpg"><img class="alignnone size-full wp-image-4979" title="2011-04-05_000923" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_000923.jpg" alt="" width="503" height="389" /></a>

4. 私と同じように Firefox 4 をお試しで入れるだけで、普段使っているブラウザーが Firefox ではない場合は、【Firefox を既定のブラウザーに設定】にチェックを入れず、【インストール】をクリックしてください

<a href="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_001302.jpg"><img class="alignnone size-full wp-image-4980" title="2011-04-05_001302" src="{{< param imageBase >}}/wp-content/uploads/2011/04/2011-04-05_001302.jpg" alt="" width="503" height="389" /></a>

5. インストール中です。少々お待ちください（数秒で終わります XD）
