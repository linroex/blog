Firefox 4 has finally joined the ranks of browsers with streamlined interfaces~ Now the three major browsers on the market, Chrome, IE, and Firefox, have all made their interfaces quite minimal. But Firefox was a bit late. A big reason I switched from Firefox to Chrome back then was that Google Chrome's interface was fresh, stylish, and clean, which made it feel fast (a psychological bonus...). Still, Firefox has many advantages. For example, customizability! Although Chrome can install extensions, Chrome's extension library is nowhere near the size of Firefox's, so with Firefox you can do so much more XD


<!--more-->
The biggest change in this Firefox 4 update is the interface. Unlike all previous versions, Firefox looks completely different! It's also six times faster than Firefox 3.6 (according to the official site), but it still loses to Chrome... I'm not sure whether this is new in Firefox 4, but there's Firefox Sync, which syncs bookmarks, browsing history, passwords, and other data across different Firefox installs. It's now built into Firefox, and you can use it just like Chrome's sync.
